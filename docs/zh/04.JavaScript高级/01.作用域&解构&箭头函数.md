# 第一章：作用域（Scope）

## 1.1 概述

* `作用域` 决定了 `变量`、`函数` 等标识符的 `可访问范围`，即：决定了它们在哪里可以被使用。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-11-12/2026-11-12-17-57-49.png)

## 1.2 局部作用域（本地作用域）

### 1.2.1 概述

* `局部作用域` （Local Scope，本地作用域）由 `函数作用域` 和 `块级作用域` 组成。

### 1.2.2 函数作用域

* 在函数内部声明的变量只能在函数内部访问，外部无法直接访问。

> [!NOTE]
>
> * ① 函数的参数（形参）也是函数内部的局部变量。
> * ② 函数被调用时，将会形成局部作用域（栈帧）；一旦调用结束，局部作用域（栈帧）将会被销毁，其内部的变量等也随之销毁。
> * ③ 不同函数内部声明的变量无法互相访问。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>
<body>
  
  <script>
    /* 
      函数作用域：函数内部定义的变量，只能在函数内部访问
    */
    function test() {
      // ✅️ 函数内部定义的变量，只能在函数内部访问
      let localVar = "I am local" // [!code highlight]
      console.log(localVar)
    }
    
    test()

    // ❌️ 函数外部无法访问函数内部定义的变量
    // console.log(localVar) // [!code error]
  </script>
</body>
</html>
```

### 1.2.3 块级作用域

* 使用 `{}` 包裹的代码被称为代码块，代码块内声明的变量外部将 `有可能` 无法访问。

> [!NOTE]
>
> * ① let 关键字和 const 关键字声明的变量，都会产生块级作用域。
> * ② ~~var 关键字声明的变量不会产生块级作用域~~（不推荐使用）。
> * ③ 不同代码块之间的变量无法互相访问。
> * ④ 对象字面量没有产生块级作用域，如：`const obj = {...}` 。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <script>
    /* 
      块级作用域：使用{}包裹起来的代码块，称为块级作用域
      块级作用域：在代码块内部定义的变量，只能在代码块内部访问
    */
    {
      let uname = "张三"
      // ✅️ 在代码块内部定义的变量，只能在代码块内部访问
      console.log(uname) // [!code highlight]
    }

    for (let i = 0; i < 5; i++) {
      // ✅️ 在代码块内部定义的变量，只能在代码块内部访问
      console.log('i', i) // [!code highlight]
    }


    // ❌️ 在 {} 外无法访问块级作用域内的变量
    // console.log(uname) // [!code error]
    // console.log(i) // [!code error]
  </script>
</body>

</html>
```

## 1.3 全局作用域

* `<script>` 标签和 `.js` 最外层的就是全局作用域，在此声明的变量等，在局部作用域内也可以访问。

> [!NOTE]
>
> * ① ~~为 window 对象动态添加的属性，默认是全局作用域~~（不推荐使用）。
> * ② ~~函数中未使用任何关键字声明的变量为全局变量~~（不推荐使用）。
> * ③ 尽可能少的声明全局变量，防止全局变量被污染。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>
<body>
  
  <script>
    /* 
      全局作用域：在代码的任意位置都可以访问的变量
    */
    let globalVar = 10

    function test() {
      // ✅️ 全局作用域：在函数内部也可以访问
      console.log(globalVar) // [!code highlight]
    }

    test()

    // ✅️ 全局作用域：在任意地方都可以访问
    console.log(globalVar) // [!code highlight]

  </script>
</body>
</html>
```

## 1.4 作用域链

* `作用域链` 本质上是 `变量的查找机制` 。

> [!NOTE]
>
> * ① 在执行执行的时候，会优先查看 `当前函数作用域` 中的局部变量。
> * ② 如果当前作用域中查找不到，则依次 `逐级查找父级作用域` 中的变量，直到全局作用域。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <script>
    /* 
      作用域链：
        作用域链：是多个执行上下文的变量对象的层级链
        
        块级作用域 --> 函数作用域 --> 全局作用域
    */

    const x = 1 // 全局作用域

    function demo() { // 函数作用域
      const x = 2
      console.log('函数作用域：', x)

      if (true) { // 块级作用域
        let x = 3
        console.log('块级作用域：', x)
      }
      
      console.log('函数作用域：', x)
    }

    demo()

    console.log('全局作用域：', x)
  
  </script>

</body>

</html>
```

* JavaScript 在代码执行前，会将函数声明提升到当前作用域的顶部，使其可以在声明之前调用。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-11-13/2026-11-13-11-43-11.png)

  <script>

    /* 
      函数提升：

      console.log('foo')
    }

  </script>

## 4.2 函数参数

### 4.2.1 概述

* 函数的参数，可以让函数处理不同的数据，提高代码复用性，使其调用时更灵活。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-11-13/2026-11-13-14-40-12.png)

### 4.2.2 动态参数（了解）

* 格式：

```js
function 函数名(形参1,形参2,...){
    // arguments
}

函数名(实参1,实参2,...)
```

> [!NOTE]
>
> * ① 在函数内部有一个特殊的对象，即：arguments 对象，其是一个伪数组（不是真正的数据，无法使用 forEach() 等方法）。
> * ② 默认情况下，`arguments` 对象是 `所有（非箭头）函数` 中都可以使用的 `局部变量`，即：`arguments`  只存在于 function 定义的函数中。
> * ③ arguments 对象是 ES5 之前的写法，在 ES6 之后，推荐使用 `剩余参数` 来代替 arguments 对象了。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <script>

    function foo() {
      // 判断 arguments 是否为对象
      console.log(typeof arguments) // object
      // 判断 arguments 是否为数组
      console.log(Array.isArray(arguments)) // false
      // 遍历 arguments 对象
      for (let i = 0; i < arguments.length; i++) {
        console.log(arguments[i])
      }
    }

    foo(10, 20, 30)
    console.log('-----------------')
    foo(10, 20, 30, 40)

  </script>

</body>

</html>
```

### 4.2.3 默认参数

* 格式：

```js
function 函数名(形参1,形参2 = 值){
    // arguments
}

函数名(实参1,实参2,...)
```

> [!NOTE]
>
> * ① 当形参对应的实参 `缺少` 或为 `undefined` 的时候，默认参数（default parameter）生效。
> * ② 当形参对应的实参为 `null` ，默认参数并不会生效。 



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <script>
    /* 
      默认参数，即：形参的默认值
    */
    function foo(name = "同学") {
      console.log(`你好，${name}！`)
    }

    foo() // 你好，同学！
    foo('小明') // 你好，小明！
    foo(undefined) // 你好，同学！
    foo(null) // 你好，null！

  </script>

</body>

</html>
```

### 4.2.4 剩余参数（其余参数）

* 格式：

```js
// ... parameters 就是剩余参数（其余参数）
function 函数名(形参1,形参2, ... parameters){
    // arguments
}

函数名(实参1,实参2,...)
```

> [!NOTE]
>
> * ① 当参数数量不确定的时候，可以使用 `...` 将剩余实参收集为数组，其就是为了替代 arguments 对象。
> * ② 如果有多个参数，那么剩余参数必须放到形参列表的最后一个位置。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <script>

    /* 
      rest参数，即：剩余参数 
    */
    function sum(...numbers) {
      // 判断剩余参数是否为数组
      console.log(Array.isArray(numbers))

      let total = 0;
      for (let number of numbers) {
        total += number;
      }

      return total;
    }

    console.log(sum(1, 2, 3))       // 6
    console.log('----------------')
    console.log(sum(10, 20, 30, 40)) // 100

  </script>

</body>

</html>
```

## 4.3 箭头函数

### 4.3.1 概述

* `箭头函数` 是 ES6 新增的函数写法，使用 `=>` 表示，写法更简洁，常常用于回调函数。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-11-13/2026-11-13-14-35-46.png)

### 4.3.2 语法

* 格式：

```js
const 函数名 = (参数列表) => {
  // 函数体
  return 返回值;
}
```

> [!NOTE]
>
> * ① 普通函数 VS 箭头函数 VS 箭头函数简写，如下所示：
>
> ```js
> // 普通函数（函数表达式）
> const add = function (a, b) {
>   return a + b
> }
> 
> // 箭头函数
> const add = (a, b) => {
>   return a + b
> }
> 
> // 箭头函数简写
> const add = (a, b) => a + b
> ```
>
> * ② 箭头函数的语法细节，如下所示：
>
> | 箭头函数的组成  | 描述                               |
> | --------------- | ---------------------------------- |
> | :one: `()`      | 声明形参列表                       |
> | :two: `=>`      | 箭头符号，连接参数列表和函数体     |
> | :three: `{}`    | 函数体                             |
> | :four: `return` | 返回函数执行结果，可以根据条件省略 |
>
> * ③ `箭头函数` 也可以被称为 `Lambda 表达式`，并且箭头函数中没有 this ，只会从自己的作用域链的上一层沿用 this 。
> * ④ `箭头函数` 更适用于哪些本来需要 `匿名函数` 的地方。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>
<body>
  
  <button class="btn">点我</button>

  <script>
    /* 获取元素 */
    const btn = document.querySelector('.btn');
    /* 添加事件监听 */
    btn.addEventListener('click', () => {
      alert('按钮被点击了！')
    })
  </script>
</body>
</html>
```

### 4.3.3 简写规则

* 剪头函数的简写规则，如下所示：

::: details 点我查看 具体细节

* ① 箭头函数属于表达式函数，因此没有函数提升。 
* ② 箭头函数如果只有一个参数，可以省略小括号。
* ② 函数体只有一行代码时，可以省略大括号和  `return`。
* ③ 返回对象字面量时，需要用小括号包裹对象。

:::

| 情况       | 完整写法                            | 简写规则                       |
| ---------- | ----------------------------------- | ------------------------------ |
| 无参数     | `() => {}`                          | `()` 不能省略                  |
| 一个参数   | `(x) => {}`                         | 可以省略 `()`                  |
| 多个参数   | `(a, b) => {}`                      | `()` 不能省略                  |
| 单个表达式 | `(a, b) => { return a + b; }`       | 可以省略 `{}` 和 `return`      |
| 返回对象   | `() => { return { name: 'Tom' }; }` | 使用 `() => ({ name: 'Tom' })` |
| 多条语句   | `() => { fn1(); fn2(); }`           | 必须保留 `{}`                  |
