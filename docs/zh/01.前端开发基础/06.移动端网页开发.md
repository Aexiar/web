* ① 视口标签，如下所示：

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

* ② 视口标签的内容，如下所示：

|     属性名      | 作用                   |                 取值                  |                         默认值                         | 示例                                                  | 注意事项                                                     |
| :-------------: | :--------------------- | :-----------------------------------: | :----------------------------------------------------: | :---------------------------------------------------- | :----------------------------------------------------------- |
|     `width`     | 设置视口宽度           | `device-width` 或具体数值（如 `375`） | 通常为 `980px`（移动浏览器布局视口，实际因浏览器而异） | `<meta name="viewport" content="width=device-width">` | 移动端通常使用 `device-width`，使布局视口宽度与设备的 CSS 视口宽度匹配。 |
| `initial-scale` | 页面初始缩放比例       |           数值（如 `1.0`）            |        通常为 `1.0`，具体受浏览器及其他设置影响        | `<meta name="viewport" content="initial-scale=1.0">`  | 通常与 `width=device-width` 配合使用，避免初始缩放异常。     |
| `minimum-scale` | 允许用户缩放的最小比例 |           数值（如 `0.5`）            |                      通常为 `0.1`                      | `<meta name="viewport" content="minimum-scale=0.5">`  | 若设置为 `1.0`，可能限制用户缩小页面。                       |
| `maximum-scale` | 允许用户缩放的最大比例 |           数值（如 `2.0`）            |                     通常为 `10.0`                      | `<meta name="viewport" content="maximum-scale=2.0">`  | 限制放大范围可能影响无障碍访问，部分浏览器会忽略该限制。     |
| `user-scalable` | 是否允许用户手动缩放   |             `yes` 或 `no`             |                         `yes`                          | `<meta name="viewport" content="user-scalable=no">`   | 不建议禁用缩放，可能影响视力障碍用户，部分浏览器也会忽略该设置。 |

::: details 点我查看 具体细节

* ① 移动端设计稿通常以 `750px` 作为标准宽度，尤其是微信小程序、H5 页面等。
  * 早期的移动端设计以 iPhone 为基准，750px（@2x）成为行业默认规范。
  * iphone 6/7/8 的物理分辨率是 750 × 1344 px，设计稿按照 750px 的宽度制作时，能直接对应。 
* ② 这些设备的 1:1 视觉还原，方便设计师精准把控细节，如：字体大小、间距等。

:::

# 第二章：vw 适配方案

## 2.1 概述

* vw（Viewport Width）是视口宽度的 1% ，会随着视口宽度的变化自动适配，如下所示：

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-15/2026-10-15-09-32-58.png)

## 2.2 理解 vw

* 我们可以这样推算，如下所示：

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-15/2026-10-15-09-46-26.png)

* 那么，换算公式就是这样的，如下所示：

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-15/2026-10-15-10-07-29.png)

* 一个盒子在设计稿（375px）中的长度是 60px，其在不同视口宽度下的比例缩放，如下所示：

| 设备视口宽度（px） | 1vw 对应的 px | 盒子宽度（16vw） |
| ------------------ | ------------- | ---------------- |
| 320                | 3.2           | 51.2px           |
| 375                | 3.75          | 60px             |
| 390                | 3.9           | 62.4px           |
| 414                | 4.14          | 66.24px          |
| 750                | 7.5           | 120px            |



* 示例：

## 3.1 概述

* rem（root em）是根据 `根元素`（html）的 `font-size` 来进行动态适配的，如下所示：

 ![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-15/2026-10-15-11-11-35.png)



* 示例：

::: code-group

```html [index.html] 
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    html {
      font-size: 16px;
    }

    body {
      display: grid;
      height: 50vh;
      place-items: center;
    }

    .box {
      width: 2rem;
      height: 2rem;
      background-color: pink;
    }

    .btn {
      width: 250px;
      height: 50px;
      border-radius: 25px;
      border: none;
      /* 去掉边框 */
      outline: none;
      background-color: skyblue;
      /* 去掉点击时的虚线/光晕 */
      outline: none;
      cursor: pointer;
    }
  </style>
</head>

<body>

  <div class="box"></div>

  <button class="btn">点我切换盒子大小</button>


  <script>
    const btn = document.querySelector('.btn')
    btn.addEventListener('click', () => {
      const html = document.documentElement;
      // getComputedStyle 能拿到最终生效值（含样式表里的 16px），返回 "16px"
      const current = parseFloat(getComputedStyle(html).fontSize);
      html.style.fontSize = current + 10 + 'px';  // 26px → 36px → ...
    });

  </script>
</body>

</html>
```

```js [flexible.js]
(function flexible(window, document) {
  var docEl = document.documentElement
  var dpr = window.devicePixelRatio || 1

  // adjust body font size
  function setBodyFontSize() {
    if (document.body) {
      document.body.style.fontSize = (12 * dpr) + 'px'
    }
    else {
      document.addEventListener('DOMContentLoaded', setBodyFontSize)
    }
  }
  setBodyFontSize();

  // set 1rem = viewWidth / 10
  function setRemUnit() {
    var rem = docEl.clientWidth / 10
    docEl.style.fontSize = rem + 'px'
  }

  setRemUnit()

  // reset rem unit on page resize
  window.addEventListener('resize', setRemUnit)
  window.addEventListener('pageshow', function (e) {
    if (e.persisted) {
      setRemUnit()
    }
  })

  // detect 0.5px supports
  if (dpr >= 2) {
    var fakeBody = document.createElement('body')
    var testElement = document.createElement('div')
    testElement.style.border = '.5px solid transparent'
    fakeBody.appendChild(testElement)
    docEl.appendChild(fakeBody)
    if (testElement.offsetHeight === 1) {
      docEl.classList.add('hairlines')
    }
    docEl.removeChild(fakeBody)
  }
}(window, document))
```
