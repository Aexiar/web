# 第一章：响应式布局

## 1.1 概述

* `响应式布局` 能够根据 `用户设备` 的特性自动调整布局，提供一致且优化的用户体验。

::: details 点我查看 具体细节

* ① 响应式布局的核心目前：一次设计，多端适配。
* ② 响应式布局的优缺点，如下所示：

| 响应式布局的优缺点 | 描述                                     |
| ------------------ | ---------------------------------------- |
| :one: 优点         | 一套代码适配多端设备                     |
| ^^                 | 节省开发和维护成本                       |
| ^^                 | 用户体验一致性高                         |
| :two: 缺点         | 复杂布局需要较多调试                     |
| ^^                 | 过度使用媒体查询可能影响性能             |
| ^^                 | 需要精准计算断点（什么屏幕下，怎么显示） |

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-15/2026-10-15-13-58-53.png)

## 1.2 核心技术 & 断点设置

* 响应式布局的核心技术，主要包括：`弹性盒子`（Flexbox）、`网格布局`（CSS Grid）等。

::: details 点我查看 具体细节

* ① 响应式布局的核心技术，如下所示：

| 响应式布局的核心技术   | 主要作用                                                     | 应用场景                             |
| ---------------------- | ------------------------------------------------------------ | ------------------------------------ |
| Flexbox 弹性盒子       | 一维布局，控制元素在行或列方向上的排列、对齐和伸缩           | 导航栏、按钮组、卡片排列             |
| CSS Grid 网格布局      | 二维布局，同时控制行和列，实现复杂的页面结构                 | 页面整体布局、多列卡片、仪表盘       |
| Media Queries 媒体查询 | 根据视口宽度、屏幕方向等条件应用不同的 CSS 样式              | 手机、平板、PC 布局切换              |
| 弹性尺寸单位           | 使用 `%`、`vw`、`vh`、`rem` 等单位，使尺寸能够灵活变化       | 自适应宽度、间距、字体大小           |
| 响应式图片             | 利用 `max-width`、`srcset`、`sizes`、`picture` 等技术适配不同显示环境 | 图片自动缩放、不同设备加载合适的图片 |
| 流式布局               | 使用百分比宽度、`max-width` 等方式，使内容随可用空间调整     | 自适应内容容器、文章、商品列表       |

* ② 其中，`Flexbox 和 CSS Grid 负责布局，媒体查询负责条件切换，弹性单位负责尺寸适配`，三者是现代响应式布局最常用的技术组合。

# 第二章：媒体查询

## 2.1 媒体查询

* `媒体查询` 是 CSS3 中的强大功能，它允许开发者根据设备的特定特性来应用不同的 CSS 样式。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-15/2026-10-15-14-27-09.png)

## 2.2 语法

* 格式：

```css
@media 媒体类型 and (媒体特征){
    /* 样式 */
}
```

> [!NOTE]
>
> * ① `@media` ：媒体查询的起始声明。
> * ② `媒体类型`（可选）：screen、print 等，省略默认 all。
> * ③ `设备特性`：min-width、max-width 等。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    /* 如果当前屏幕尺寸 > 1200 px，背景颜色设置为绿色 */
    @media screen and (min-width: 1200px) {
      body {
        background-color: green;
      }
    }

    /* 如果当前屏幕尺寸 在 768px 到 1200 px，背景颜色设置为橙色 */
    @media screen and (min-width: 768px) and (max-width: 1200px) {
      body {
        background-color: orange;
      }
    }

    /* 如果当前屏幕尺寸小于 768 px，背景颜色设置为红色 */
    @media screen and (max-width: 768px) {
      body {
        background-color: red;
      }
    }
  </style>
</head>

<body>

</body>

</html>
```

# 第三章：BootStrap 响应式

## 3.1 概述

* Bootstrap 是由 Twitter 团队开发的开源前端框架，用于快速构建响应式、移动优先的网站和 Web 应用程序。

::: details 点我查看 具体细节

* ① Bootstrap 提供了一套完整的 HTML、CSS 和 JavaScript 组件，使开发者可以轻松实现现代化的 UI 设计。
* ② Bootstrap 提供大量预定义样式和组件，减少重复代码。
* ③ Bootstrap 使得开发者可以专注于业务逻辑，而不必从零开始写 CSS。

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-15/2026-10-15-15-13-44.png)
