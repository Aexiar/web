# 第二章：初识 HTML 

## 2.1 概述

* `HTML` 是一种 `标记语言`，是用来构建 `网页结构` 和 `网页内容` 的 `标准标记语言`。

::: details 点我查看 具体细节

* ① `HTML`  的全称是 `H` yper `T` ext `M` arkup `L` anguage，即：超文本标记语言。
* ② `超文本标记语言` 中的 `超文本`，指的是文本中含有超链接，而超链接可以将多个网页链接到一起。
* ③ `超文本标记语言` 中的 `标记`，指的是标签（元素），即：带尖括号的文本，如：`<h1></h1>` 。
* ④ 网页的“骨架”：HTML 定义了网页上有哪些元素，如：标题、段落、图片、按钮、链接、表格和表单等。
* ⑤ 配合其他技术，如下所示：

| 其他技术   | 描述                                                        |
| ---------- | ----------------------------------------------------------- |
| CSS        | 负责网页的 **外观样式**，如：字体、颜色、布局、响应式排版。 |
| JavaScript | 负责网页的 **交互逻辑**，如：动态加载、点击事件、数据处理。 |

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-09-14/2026-09-14-11-07-22.png)

### 2.2.2 标签和属性

* 格式：

```html
<标签 属性="值" ...> 内容 </标签>
  │    │             │     └─ 结束标签
  │    │             └────── 内容
  │    └─────────────────── 属性
  └──────────────────────── 开始标签
```

::: details 点我查看 具体细节

* ① HTML 使用标签（Tags）包裹内容，绝大多数标签都是成对出现的，包含开始标签、内容和结束标签。
* ② 标签与属性结构，如下所示：

| 类型               | 描述                                                         |
| ------------------ | ------------------------------------------------------------ |
| 双标签             | `<p>段落内容</p>`                                            |
| 单标签（自闭合）   | `<img src="photo.jpg" alt="描述">`、`<br/>`、`<hr>`          |
| 属性（Attributes） | 在开始标签中以 `key="value"` 形式提供附加信息，如： `id`、`class`、`src`、`href`。 |

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-09-14/2026-09-14-12-54-01.png)



* 示例：

```html {13,16,23}

<head>
  <meta charset="UTF-8">
  <meta content="width=device-width, initial-scale=1.0" name="viewport">
  <title>Document</title>
</head>

<body>
    
  <!-- h1 是双标签 -->
  <h1>什么是 HTML</h1>
    
  <!-- hr 是单标签 -->

    p 是双标签

  </p>

```

## 2.3 HTML 的基本骨架

* 格式：

```html
<!-- 文档类型 -->
<!DOCTYPE html>
<!-- 根标签，表示整个网页 -->
<html lang="en"> 
    
<!-- 头部元素 -->
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>
    
<!-- body元素-->
<body>
  我的第一个页面
</body>

</html>
```

::: details 点我查看 具体细节

* ① `<!DOCTYPE html>` 表示文档类型，即：HTML5 的文档类型声明，它告诉浏览器当前页面使用的是 HTML5 规范编写的。
* ②  `<html> 元素` 表示整个网页，即：该元素包裹了页面中的所有内容，有时也被称为 `根元素`。其中，`lang` 属性用于 `声明网页的主要语言`，帮助浏览器、搜索引擎等正确的处理页面内容，如：en 代表英语，而 zh-CN 代表的是中文。
* ③ `<head> 元素` 表示头部元素，包含了文档的元（meta）数据，主要保存供机器处理的信息，而非人类可读的信息。

```html
<!-- 
	该文档的字符集设置为 UTF-8
	UTF-8 包括绝大多数人类书面语言的大多数字符。
	有了这个设置，页面现在可以处理它可能包含的任何文本内容，如果不加这句话可能会引起乱码。
-->
<meta charset="UTF-8">
```

```html
<!-- 
	移动端页面适配
	开发者能确保网页在移动设备上以最佳状态呈现，提升用户浏览体验。
-->
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

```html
<!-- 
	设置了页面的标题，也就是出现在该页面加载的浏览器标签中的内容
-->
<title>Document</title>
```

* ④ `<body> 元素` 表示主体内容，包含了页面所有显示在页面上的内容，如：文本、图片、视频、游戏、可播放音频轨道等等。

## 2.4 HTML 标签关系

* HTML 的标签关系，分为 `父子关系`（嵌套关系）和 `兄弟关系`（并列关系）。

> [!NOTE]
>
> * ① 学习 HTML 标签关系的作用，如下所示：
>   * :one: 明确标签的书写位置。
>   * :two: 让代码格式更整齐。
>
> * ② HTML 标签关系的代码格式，如下所示：
>
>   * :one: 父子关系：子级标签换行且缩进（Tab 键，需要设置 2 个空格）。
>
>   * :two: 兄弟关系：兄弟标签换行要对齐。



* 示例：

```html
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <!-- 
    父子关系：子级标签换行且缩进
  -->
  <p>
    <span></span>
  </p>

  <!-- 
    兄弟关系：兄弟标签换行要对齐
  -->
  <div></div>
  <p></p>

</body>

</html>
```

## 2.5 HTML 注释

* 语法：

```html
<!-- 注释 -->
```

> [!NOTE]
>
> * ① 注释是对一段代码的解释和说明。注释是给开发者看的，浏览器并不会将注释显示给用户。
> * ② 注释的意义：
>   * 帮助我们自己理清代码的思路，方便以后进行查阅。
>   * 与别人合作开发时，添加注释，可以减少沟通成本。
>   * 开发自己的框架时，加入适当的注释，方便别人使用和学习。
>   * 可以临时注释掉一段代码，方便调试。
> * ③ 注释的快捷键：`Ctrl + /` 。



* 示例：

```html
<!DOCTYPE html>
<html lang="en">
    
<head>
  <meta charset="UTF-8">
  <meta content="IE=edge" http-equiv="X-UA-Compatible">
  <meta content="width=device-width, initial-scale=1.0" name="viewport">
  <title>Title</title>
</head>
    
<body>
  <!-- 这是注释，实际并不会执行，仅仅用来说明代码的含义，方便协同开发。 -->
  <h2>呵呵哒</h2>
</body>
    
</html>
```

### 3.2.4 语义化

* 所谓的 ` 语义化` 就是 `根据内容的结构和含义，选择合适的 HTML 标签` 。

> [!NOTE]
>
> 语义化的好处：
>
> * ① 代码更易读，结构更清晰。。
> * ② 有利于 SEO（对搜索引擎更友好）。
> * ③ 有利于团队开发。
> * ④ ...



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <h1>HTML 的标题和段落</h1>
  <p>
    HTML 的主要工作之一是赋予文本结构，使浏览器能够按照开发者的意图显示 HTML 文档。本文介绍了如何使用 HTML
    通过定义标题和段落来提供基本的页面结构。
  </p>
  <h2>实现结构层级</h2>
  <p>
    所涉及的元素具体代表什么，完全取决于作者编辑的内容，只要层次结构是合理的。在创建此类结构时，只需要记住一些最佳实践。
  </p>
  <h2>为什么我们需要结构化？</h2>
  <p>
    这是因为没有元素给内容结构，所以浏览器不知道什么是标题，什么是段落。用户在阅读网页时，往往会快速浏览以查找相关内容，经常只是阅读开头的标题（我们通常在一个网页上会花费很少的时间)。如果用户不能在几秒内看到一些有用的内容，他们很可能会感到沮丧并离开。
  </p>
  <h2>为什么我们需要语义？</h2>
  <p>
    我们需要确保使用了正确的元素来给予内容正确的含义、作用以及外形。在这里，h1
    元素也是一个语义元素，它所包裹的文本具有“页面上的顶级标题”的作用（或意义）。
  </p>
  <p>
    一般来说，浏览器会给它一个更大的字形来让它看上去像个标题。更重要的是，它的语义值将以多种方式被使用，比如通过上文提到过的搜索引擎和屏幕阅读器。
  </p>

</body>

</html>
```

## 3.4 超链接

### 3.4.1 概述

* 超链接是网页中用于跳转到其他页面或资源的元素，使用 `<a>` 标签来创建超链接。

::: details 点我查看 具体细节

* HTML 的 `中文翻译` 是 `超文本`，其中的 `超` 指的就是 `超链接` 。
* 绝大部分网站都会包含超链接，如下所示：

### 3.4.2 语法

* 格式：

```html
<a href="URL" target="_self">链接文本</a>
```

> [!NOTE]
>
> * ① href 属性指定要跳转的目标 URL，可以是绝对路径（完整的 URL）或相对路径（相对于当前页面的路径）。
> * ② 链接文本是用户点击的可见文本。
> * ③ 可以使用 target 属性指定链接的打开方式，如：`target="_blank"` 表示在新窗口或新标签页中打开链接。
> * ④ 链接可以包含除了自身之外的其它元素，如：文字、图片、标题、音视频等。



* 示例：

::: code-group

```html [index.html]

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <!-- 1. 内部链接 -->
  <a href="./11-图片.html">图片</a>

  <hr>

  <!-- 2. 外部链接 -->
  <a href="https://www.baidu.com">百度一下，你就知道</a>
  <a href="https://www.baidu.com" target="_blank" title="baidu">百度一下，你就知道</a>

</body>

</html>
```

## 3.8 字符实体

* 字符实体是以 `&` 开头，以 `;` 结尾的文本（字符串），常用于显示保留字符或不可见字符。

| 字符 | 实体     | 说明                                                         |
| :--- | :------- | :----------------------------------------------------------- |
| &    | `&amp;`  | 解析为实体或字符引用的开头                                   |
| <    | `&lt;`   | 解析为 [tag](https://developer.mozilla.org/zh-CN/docs/Glossary/Tag) 的开头 |
| >    | `&gt;`   | 解析为 [tag](https://developer.mozilla.org/zh-CN/docs/Glossary/Tag) 的结尾 |
| "    | `&quot;` | 解析为 [attribute](https://developer.mozilla.org/zh-CN/docs/Glossary/Attribute) 的值的开头和结尾 |
|      | `&nbsp; `      | 解析为不换行空格                                             |
| –    | `&ndash;` | 解析为短破折号（等于 em 单位的一半宽度）                     |
| —    | `&mdash;` | 解析为长破折号（等于 "m" 字符的宽度）                        |
| ©    | `&copy;` | 解析为版权符号                                               |
| ®    | `&reg;` | 解析为注册商标符号                                           |
| ™    | `&trade;` | 解析为商标符号                                               |
| ≈    | `&asymp;` | 解析为近似等于符号                                           |
| ≠    | `&ne;`  | 解析为不等于符号                                             |
| £    | `&pound;` | 解析为英镑符号                                               |
| €    | `&euro;` | 解析为欧元符号                                               |
| °    | `&deg;` | 解析为度符号                                                 |

## 3.9 布局标签

* 在 HTML5 之前，我们通常会选择使用 div 作为块级容器来进行布局，而 span 用来包裹内容。

| 无语义标签 | 特点                                          |
| ---------- | --------------------------------------------- |
| div 标签   | 1. 块级元素：默认独占一行，前后会自动换行。   |
| ^^         | 2. 通常用于布局结构，作为其他元素的容器。     |
| ^^         | 3. 可以包含其他块级或行内元素。               |
| ^^         | 4. 默认没有语义。                             |
| span 标签  | 1. 行内元素：不会换行，仅仅包裹内容的一部分。 |
| ^^         | 2. 用于对文本或行内元素的局部样式或操作。     |
| ^^         | 3. 默认没有语义。                             |



* 示例：

::: code-group

## 3.10 标签分类

* 在 HTML 中，`标签` 分为两大类：`块级元素` 和 `行内元素`（内联元素）。

| 标签分类 | 特点                                                         |
| -------- | ------------------------------------------------------------ |
| 块级元素 | 在页面中独占一行。                                           |
| ^^       | 块级元素中可以嵌套其他元素，如：p、div、h1-h6 等。           |
| ^^       | 通常用于布局和结构。                                         |
| 内联元素 | 在页面中不会独占一行。可以一行放多个。                       |
| ^^       | 不能嵌套块级元素，可以嵌套其他内联元素，如：span、a、strong 等。 |
| ^^       | 通常用于文本和内容。                                         |

> [!NOTE]
>
> * ① 块级元素和内联元素的嵌套规则：
>   * 块级元素中可以嵌套块级元素和内联元素。
>   * 内联元素中只能嵌套内联元素，不能嵌套块级元素。
> * ② p 标签的特殊性：
>   * p 标签是块级元素，但它不能嵌套其他块级元素。
>   * 如果在 p 标签中嵌套了块级元素，浏览器会自动关闭 p 标签，导致布局混乱。
>   * p 标签中主要存放文字相关，如：内联元素、文本等。
> * ③ 元素的分类不是一直不可以更改的，后面的 css 中可以通过 display 属性来改变元素的显示类型，从而改变元素的分类。



* 示例：

::: code-group

```html [index.html]

<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <link rel="stylesheet" href="./index.css" >

  <div class="block-example">
    我是块级元素
    <p>我是 div 中的 p 标签</p>
  </div>

  <div class="inline-example">
    我是块级元素
    <span>我是 div 中的 span 标签</span>
    <span>我是 div 中的 span 标签</span>
```

```html
<video controls muted poster="封面路径" src="视频路径" loop autoplay></video>
```

> [!NOTE]
>
> * ① 常见属性，如下所示：
>
> | 视频标签的常见属性 | 描述                                                     | 备注                     |
> | ------------------ | -------------------------------------------------------- | ------------------------ |
> | src                | 指向要插入到页面的视频地址 (相对路径或绝对路径)。         | 必备                     |
> | controls           | 显示浏览器自带播放控件，使用户可以播放、暂停和调整视频。 |                          |
> | width/height       | 设置视频的宽度和高度。                                   |                          |
> | autoplay           | 设置视频在页面加载时自动播放。                           | 需要先静音，才能自动播放 |
> | loop               | 设置视频循环播放。                                       |                          |
> | muted              | 设置视频静音。                                           |                          |
> | poster             | 指定视频封面图像，在视频未播放时显示。                   |                          |
>
> * ② 确保音频和视频文件路径正确，否则无法播放。
>
> * ③ 使用 controls 属性可以提高用户体验，让用户可以控制播放。
> * ④ 音频和视频文件应尽量优化，以减少加载时间，提高网页性能。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    video {
      width: 400px;
    }
  </style>    
</head>

<body>

  <!-- 视频标签 -->
  <h2>视频标签</h2>
  <video controls muted poster="./media/yu7.jpg" src="./media/yu7.mp4"></video>

</body>

</html>
```
