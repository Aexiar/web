# 第一章：变换（transform）

## 1.1 概述

* CSS `transform` 是元素进行 2D/3D 变化的核心属性，支持平移、旋转、缩放、倾斜等效果，且 `不破坏` 原有文档流布局。

::: details 点我查看 具体细节

* ① `transform` 改变的是元素的视觉呈现效果，而不是它在正常文档流中参与布局的位置和尺寸。因此，元素可以看起来移动、旋转或放大，但周围元素仍按照变换前的布局进行排列。
* ② transform 的应用场景非常广泛，其可以通过简洁的语法实现复杂的视觉动态效果。

## 1.3 基础变换函数 - 2D

### 1.3.1 概述

* 格式：

```css
transform: translate | rotate | scale | skew ;
```

* 变化类型及其语法等，如下所示：

| 变化类型 | 函数语法              | 核心描述                                                     | 应用场景                   |
| -------- | --------------------- | ------------------------------------------------------------ | -------------------------- |
| 平移     | translate(x,y)        | 沿 x/y 轴移动元素，参数为像素或百分比（百分比是相对元素自身尺寸） | 微调元素位置、悬停偏移效果 |
| ^^       | translateX(x)         | ^^                                                           | ^^                         |
| ^^       | translateY(y)         | ^^                                                           | ^^                         |
| 旋转     | rotate(angle)         | 以元素中心为基点顺时针旋转，单位为 deg（负值为逆时针旋转）   | 图标旋转、卡片翻转         |
| 缩放     | scale(sx,sy)          | X/Y 轴按比例缩放，单参数时等比例缩放（ >1 放大、<1 缩小，支持百分比） | 悬停放大、焦点突出         |
| ^^       | scaleX(sx)            | ^^                                                           | ^^                         |
| ^^       | scaleY(sy)            | ^^                                                           | ^^                         |
| 倾斜     | skew(x-angle,y-angle) | X/Y 轴扭曲元素形状，参数为倾斜角度（支持负值）              | 斜切导航栏、动态表单       |
| ^^       | skewX(x-angle)        | ^^                                                           | ^^                         |
| ^^       | skewY(y-angle)        | ^^                                                           | ^^                         |

### 1.3.2 位移

* 格式：

```css
/* x 轴和 y 轴同时移动 */
transform: translate(20px,30px);
/* x 轴移动自身宽度的一半 */
transform: translateX(50%);
/* y 轴移动自身宽度的一半 */
transform: translateY(-50%);
```

> [!NOTE]
>
> * ① 位移（translate）沿 x/y 轴移动元素位置，不改变元素的实际布局，原位置依然保留空白。
> * ② 应用场景，如下所示：
>
> | 应用场景           | 描述                                           | 说明                                                         |
> | ------------------ | ---------------------------------------------- | ------------------------------------------------------------ |
> | :one: 悬停元素微调 | 鼠标放入元素上下或左右移动（添加过渡更加优雅） | ![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-09/2026-10-09-09-15-47.gif) |
> | :two: 元素居中     | 元素实现水平垂直居中（子绝父相）               | ![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-09/2026-10-09-09-16-47.gif) |
>
> * ③ 特点，如下所示：
>   * 位移不影响页面布局，仅仅是视觉上的移动。
>   * 添加鼠标经过元素移动，`优先 transform`，而不是通过 left、top 等，性能更佳。
>   * 如果单位是百分比，则是 `相对于元素自身尺寸`，而非父容器（可以结合子绝父相，实现元素水平垂直居中）。



* 示例：

::: code-group

```html [index.html] {25}
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    [class*='box']{
      width: 200px;
      height: 200px;
      background-color: pink;
    }

    .box1 {
      transition: all 0.5s;
    }

    .box1:hover {
      /* 沿着 x 轴平移 100px */
      /* transform: translateX(100px); */
      /* 沿着 y 轴平移 100px */
      /* transform: translateY(100px); */
      /* x 轴平移 100px，y 轴平移 100px */
      transform: translate(100px, 100px);
    }

    .box2 {
      background-color: skyblue;
    }
  </style>
</head>

<body>

  <div class="box1"></div>
  <div class="box2"></div>

</body>

</html>
```

### 1.3.3 旋转

* 格式：

```css
transform: rotate(360deg);
```

> [!NOTE]
>
> * ① 旋转（rotate）通过改变元素在平面或空间中的 `角度` 来实现视觉效果。
> * ② 应用场景，如下所示：
>
> | 应用场景       | 描述         | 说明                                                         |
> | -------------- | ------------ | ------------------------------------------------------------ |
> | :one: 悬停动画 | 按钮旋转     | ![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-09/2026-10-09-11-04-50.gif) |
> | :two: 加载动画 | 无限循环旋转 | ![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-09/2026-10-09-11-10-16.gif) |
>
> * ③ 语法细节，如下所示：
>
> ```css
> /* 参数单位是 deg，正值是顺时针，负值是逆时针 */
> transform: rotate(360deg);
> ```
>
> ```css
> /* 设置旋转中心点（原点），属性值支持 left、top 等，也支持数字或百分比 */
> transform-origin: left top ;
> ```
>
> * ④ 注意事项：行内元素的布局特性（无法设置宽高、盒子模型限制、transform 基准异常）会破坏旋转效果的稳定性和准确性；所以，文字类要转换为行内块或块级元素，如：字体图标就需要进行转换。



* 示例：

::: code-group

```html [index.html] {21,30,36}
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    [class*='box'] {
      width: 200px;
      height: 200px;
      margin: 100px auto;
      background-color: pink;
      transition: all .5s;
    }

    .box1:hover {
      /* 正值表示顺时针旋转，旋转 60 度 */
      /* transform: rotate(60deg); */
      /* 正值表示顺时针旋转，旋转 180 度 */
      transform: rotate(180deg);
      /* 负值表示逆时针旋转，旋转 -60 度 */
      /* transform: rotate(-60deg); */
      /* 负值表示逆时针旋转，旋转 -180 度 */
      /* transform: rotate(-180deg); */
    }

    .box2 {
      /* 旋转起点 */
      transform-origin: left top;
      background-color: skyblue;
    }

    .box2:hover {
      /* 顺时针旋转 180deg */
      transform: rotate(180deg);
    }
  </style>
</head>

<body>

  <div class="box1"></div>
  <div class="box2"></div>

</body>

</html>
```

### 1.3.4 缩放

* 格式：

```css
transform: scale(1.5);
```

> [!NOTE]
>
> * ① 缩放（scale）用于调整元素尺寸，且 `不改变` 元素在文档流中的原始位置。
> * ② 应用场景，如下所示：
>
> | 应用场景       | 说明                                                         |
> | -------------- | ------------------------------------------------------------ |
> | :one: 悬停放大 | ![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-09/2026-10-09-11-40-23.gif) |
> | :two: 焦点突出 | ![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-09/2026-10-09-11-41-33.gif) |
>
> * ③ 语法细节，如下所示：
>
> ```css
> /* 
> 	单参数，同时作用于 x 轴和 y 轴。
> 	1.5 表示整体放大 2 倍 
> */
> transform: scale(1.5);
> ```
>
> ```css
> /* 	
> 	双参数，第一个控制 x 轴，第二个控制 y 轴，0.5
> 	1.5 表示 x 轴缩小 0.5，y 轴放大 1.5 倍 
> */
> transform: scale(0.5, 1.5);
> ```



* 示例：

::: code-group

```html [index.html] {19,28}
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    [class*='box'] {
      width: 200px;
      height: 200px;
      margin: 100px auto;
      background-color: pink;
      transition: all .5s;
    }

    .box1:hover {
      /* 整体放大到原来的 1.5倍 */
      transform: scale(1.5);
    }

    .box2 {
      background-color: skyblue;
    }

    .box2:hover {
      /* x 轴缩放 0.5 倍，y 轴放大 1.5 倍*/
      transform: scale(0.5, 1.5);
    }
  </style>
</head>

<body>

  <div class="box1"></div>
  <div class="box2"></div>

</body>

</html>
```

### 1.3.5 倾斜

* 格式：

```css
transform: skew(30deg,30deg);
```

> [!NOTE]
>
> * ① 倾斜（skew）用于对元素进行二维 `倾斜` 变换，通过沿着 x 轴或 y 轴扭曲元素的几何形状。
> * ② 应用场景，如下所示：
>
> | 应用场景         | 说明                                                         |
> | ---------------- | ------------------------------------------------------------ |
> | :one: 斜切导航栏 | ![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-09/2026-10-09-13-27-33.gif) |
> | :two: 动态表单   | ![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-09/2026-10-09-13-33-08.gif) |
>
> * ③ 语法细节，如下所示：
>
> ```css
> /* x 轴倾斜多少度，y 轴倾斜多少度 */
> transform: skew(30deg,30deg);
> /* x 轴倾斜多少度*/
> transform: skewX(30deg);
> /* y 轴倾斜多少度*/
> transform: skewY(30deg);
> ```
>
> ```css
> /* 设置倾斜中心点（原点），属性值支持 left、top 等，也支持数字或百分比 */
> transform-origin: left top ;
> ```



* 示例：

::: code-group

```html [index.html] {18,25}
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    .box {
      width: 200px;
      height: 55px;
      text-align: center;
      line-height: 55px;
      background-color: #000;
      margin: 100px auto;
      color: #fff;
      /* 倾斜 */
      transform: skewX(-16deg);
    }

    .box::after {
      content: '>';
      display: inline-block;
      padding-left: 10px;
      transform: skewX(16deg);
    }
  </style>
</head>

<body>

  <div class="box">查看所有英雄</div>

</body>

</html>
```

### 1.3.6 复合写法

* 格式：

```css
transform: A() B() C();
```

> [!NOTE]
>
> 核心原则：`从右到左` 的执行顺序，即：先执行 C() ，再执行 B() ，最后执行 A() 。



* 示例：

::: code-group

```html [index.html] {23}
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    .box {
      width: 700px;
      height: 100px;
      border: 1px solid red;
      margin: 100px auto;
    }

    .box img {
      width: 100px;
      transition: all 2s;
    }

    .box:hover img {
      /* 先旋转再平移 */
      transform: translateX(600px) rotate(360deg);
    }
  </style>
</head>

<body>

  <div class="box">
    <img src="./img/wj.webp" alt="">
  </div>

</body>

</html>
```

## 1.4 过渡

* 格式：

```css
/* 
	持续时间是必须的，其余可以省略，如果省略，过渡属性默认是 all
	all 0.3s linear 1s
*/
transition: 过渡属性 持续时间 速度曲线 延迟时间;
```

> [!NOTE]
>
> * ① `transition: all 1s linear 1s;` 表示所有属性添加过渡效果，过渡持续时间 1 秒，匀速，并且延迟 1 s 执行。
> * ② 速度曲线参数，如下所示：
>
> ::: details 点我查看 具体细节
>
> |          速度曲线参数          | 效果描述                                                     | 备注                                                         |
> | :----------------------------: | ------------------------------------------------------------ | ------------------------------------------------------------ |
> |             `ease`             | 默认值，慢速开始 → 加速 → 慢速结束，适合大多数自然过渡，如：按钮悬停。 | ![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-09/2026-10-09-14-41-15.png) |

> |           `ease-in`            | 慢速开始 → 逐渐加速，适合元素从静止启动，如：弹窗出现。      | ![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-09/2026-10-09-14-41-53.png) |

### 1.5.2 旋转

* 格式：

```css
transform: ratateX(45deg); /* 围绕 x 轴旋转 */
transform: ratateY(45deg); /* 围绕 y 轴旋转 */
transform: ratateZ(45deg); /* 围绕 z 轴旋转 */
```

> [!NOTE]
>
> * ① 旋转（rotate）是通过改变元素在 3D 空间中的 `角度` 实现视觉效果。
> * ② 参数单位是：deg（度），`正值` 是 `顺时针旋转`，`负值` 是  `逆时针旋转`。
> * ③ rotateZ() 和 二维中的 rotate() 效果一样。



* 示例：

::: code-group

```html [index.html] {37,42,47}
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    .box {
      display: flex;
      align-items: center;
      justify-content: space-evenly;
      gap: 10px;
      width: 80%;
      height: 320px;
      background-color: skyblue;
      margin: 100px auto;
    }

    .card {
      width: 150px;
      height: 150px;
      border: 1px solid red;
      background-color: #fff;
      transition: all 1s ease-in-out;

      img {
        object-fit: cover;
        object-position: center;
        width: 100%;
        height: 100%;
      }
    }

    .card:first-child:hover {
      /* 沿着 x 轴旋转 180 deg */
      transform: rotateX(180deg);
    }

    .card:nth-child(2):hover {
      /* 沿着 y 轴旋转 180 deg */
      transform: rotateY(180deg);
    }

    .card:last-child:hover {
      /* 沿着 z 轴旋转 180 deg */
      transform: rotateZ(180deg);
    }
  </style>
</head>

<body>

  <div class="box">
    <div class="card">
      <img src="./img/1.png" alt="">
    </div>
```

### 1.5.3 透视

#### 1.5.3.1 概述

* `透视` 指的是在 `平面上` 描述物体的空间关系的方法或技术，如下所示：

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-09/2026-10-09-15-38-29.png)

* 在 CSS 中，透视效果（Perspective）是用于 `模拟人眼` 观察 3D 空间时的 `近大远小` 的效果。

::: details 点我查看 具体细节

* ① 透视是通过 `视距` （眼睛到物体的距离）的大小来模拟 `近大远小` 的效果。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-09/2026-10-09-15-47-09.png)

* ② 视距越小，物体显得越大；而视距越大，物体显得越小。

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-09/2026-10-09-15-45-18.png)

```css
/* 设置视距 */
```

> [!NOTE]

> * ② 给父元素添加，里面的 `所有子元素` 都会添加透视效果（常用）。
> * ② 给子元素添加，`当前元素` 添加透视效果。
>
> ```css

# 第二章：动画（animation）

## 2.1 概述

* CSS3 的 `animation` 是一种通过定义` 关键帧` 和 `动画属性` 来实现元素 `动态` 效果的技术。

::: details 点我查看 具体细节

* ① 动画的优势，如下所示：

| 动画的优势       | 描述                                                         |
| ---------------- | ------------------------------------------------------------ |
| :one: 性能高效   | 通过浏览器原生支持，利用 GPU 加速渲染，避免频繁的 JavaScript 计算开销。 |
| :two: 代码简洁   | 解决了传统 CSS 过渡（transition）只能定义两帧状态的局限性，可以利用关键帧实现更复杂的动画。 |
| :three: 交互增强 | 支持和用户操作（悬停、点击）结合，提升网页的动态表现力和用户体验。 |

* ② 动画的应用，如下所示：

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-10/2026-10-10-10-18-53.gif)

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-10/2026-10-10-10-07-51.png)

## 2.2 名词解释 --- 关键帧

* `关键帧`（keyframe）是动画和视频制作中用于定义动作或状态变化的 `核心节点`，其决定了动画的起始、转折和结束状态，并且中间帧（插帧）通过算法自动生成，形成连贯的动画效果。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-10/2026-10-10-10-26-03.png)

## 2.3 语法

* 格式：

::: code-group

```css [css - 定义动画方式一]
/* ① 定义动画 */
@keyframe move { /* move 是动画名称 */
    0 { /* 关键帧 */ 
        transform: translateX(0); 
    }
    20% { /* 关键帧 */
        transform: translateX(50%);
    }
    /* 可以定义多个关键帧，如：30%、50%、80% 等 */
    100% { /* 关键帧 */
        transform: translateX(100px);
    }
}
```

```css [css - 定义动画方式二]
/* ① 定义动画：适用于只有 2 帧的情况，即：起始和结束。 */
@keyframe move { /* move 是动画名称 */
    from { /* 关键帧 */
        transform: translateX(0); 
    }
    to { /* 关键帧 */
        transform: translateX(100px);
    }
}
```

:::

```css
/* ② 使用动画 */
p {
    /* animation: 动画名称 动画时长 */
    animation: move 1s;
}
```

## 2.4 完整语法（animation）

* 格式：

```css
/*
  animation: 动画名称 动画时长 速度曲线 延迟时间 播放次数 播放方向 执行完毕状态;
*/
```

> [!NOTE]
>
> * ① `动画名称` 和 `动画时长` 必须写（要保证书写顺序），其余可以省略。
> * ② 播放次数，播放方向以及执行完毕状态，如下所示：
>
> | 其余属性             | 默认值 | 描述                                                         |
> | -------------------- | ------ | ------------------------------------------------------------ |
> | :one: 播放次数       | 1      | 播放次数，如需无限循环写 infinite 。                         |
> | :two: 播放方向       | normal | 播放方向，如：reverse（反向）或 alternate（交替）。          |
> | :three: 执行完毕状态 | none   | 动画结束后的状态，如：forwards 保留最后一帧，backwards 回到第一帧 |
>
> * ③ 单写属性，如下所示：
>
> |        动画子属性         | 默认值  | 说明                                                         |
> | :-----------------------: | :-----: | :----------------------------------------------------------- |
> | animation-timing-function |  ease   | **动画速度曲线**，支持 linear、cubic-bezier() 等             |
> |      animation-delay      |   0s    | **动画延迟时间**，可设为负值（跳过部分动画）                 |
> | animation-iteration-count |    1    | **播放次数**，若需无限循环需显式声明 infinite                |
> |    animation-direction    | normal  | **播放方向**，如：reverse（反向）、alternate（交替）         |
> |    animation-fill-mode    |  none   | **执行完毕状态**，动画结束后是否保留样式，如：forwards 保留最后一帧） |
> |   animation-play-state    | running | **暂停或者继续动画**，需单独设置 paused 暂停动画             |

# 第三章：动效案例（case）

## 3.1 卡片两面翻转

* 需求：利用 3D 旋转实现卡片两面翻转的效果。

::: details 点我查看 具体步骤

* ① 搭建 HTML 结构，分别创建卡片容器、翻转层、卡片正面以及卡片背面。

```html
<!-- 最外层容器，负责设置透视效果 -->
<div class="card">
    <!-- 翻转层，负责整体旋转 -->
    <div class="card-flipper">
        <!-- 卡片正面，初始朝向观察者 -->
        <div class="card-front">正面</div>
        <!-- 卡片背面，初始背向观察者 -->
        <div class="card-back">背面</div>
    </div>
</div>
```

* ② 设置卡片尺寸和透视效果：

```css
.card {
    /* 设置卡片的宽度 */
    width: 300px;
    /* 设置卡片的高度 */
    height: 200px;
    /* 设置透视，即：视距 */
    perspective: 1000px;
}
```

* ③ 设置翻转层：

```css
.card-flipper {
    /* 为正反两面的绝对定位提供参照。 */
    position: relative;
    width: 100%;
    height: 100%;
    /* 使正反两面保留在同一个 3D 空间中。 */
    transform-style: preserve-3d;
    /* 让翻转过程平滑过渡，持续 0.8 秒。 */
    transition: transform 0.8s;
}
```

* ④ 让正反两面重叠：

```css
.card-front,
.card-back {
    /* 使正反两面脱离普通文档流。 */
    position: absolute;
    top: 0;
    right: 0;
    bottom: 0;
    left: 0;
    /* 隐藏朝向远离观察者的那一面，避免镜像文字透出。 */
    backface-visibility: hidden;
}
```

* ⑤ 将卡片背面预先旋转 180 度：

```css
.card-back {
    /* 此时正面朝向观察者，而背面已经围绕 Y 轴旋转 180°，因此背面不可见。 */
    transform: rotateY(180deg);
}
```

* ⑥ 鼠标悬停时翻转卡片：

```css
.card:hover .card-flipper {
    /*
    	当鼠标进入 .card 时，整个 .card-flipper 围绕 Y 轴旋转 180°。
    	由于背面原本已经旋转 180°，此时整体再旋转 180°，最终背面朝向观察者，正面转到后方。
    */
    transform: rotateY(180deg);
}
```
