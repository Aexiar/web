# 第一章：CSS 布局

## 1.1 概述

* CSS 布局是网页设计的核心技术之一，用于控制元素在页面中的排列方式。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-02/2026-10-02-13-17-02.gif)

* CSS 布局有很多种，如下所示：

::: details 点我查看 具体细节

* ① CSS 布局，有很多种方式：正常流布局、浮动布局、定位布局、弹性布局、网格布局、多列布局以及响应式布局。
* ② 每种布局方式都有其自己的用途以及优缺点，根据实际情况，灵活选择。

| 布局方式             | 特点                                          |
| -------------------- | --------------------------------------------- |
| :one: 简单布局       | 优先使用 Flexbox（一维）或 Grid（二维）。       |
| :two: 复杂响应式布局 | 使用 Grid + 媒体查询。                        |
| :three: 文本内容分栏 | 多列布局 (column-count)。                      |
| :four: 兼容旧浏览器  | 浮动布局或 Flexbox 的降级方案。               |
| :five: 主流方案      | CSS Grid 逐渐成为主流，支持更复杂的布局场景。 |

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-02/2026-10-02-12-47-26.png)

## 1.2 正常流布局（普通文档流）

* `正常流布局` 是指不对页面进行任何布局控制时，浏览器默认的 HTML 布局方式，即：标准流。

> [!NOTE]
>
> * ① `正常流布局` 是 CSS 布局的基石，页面大的布局基本就是利用 `块级元素` 上下罗列而成。
> * ② 块级元素 VS 行内元素，如下所示：
>
> | 块级元素（block）              | 行内元素（inline）                         | 文档流方向                   |
> | ------------------------------ | ------------------------------------------ | ---------------------------- |
> | 独占一行，宽度默认撑满父容器。 | 水平方向依次排列，直到容器宽度不足则换行。 | 默认从上到下、从左到右排列。 |
> | 垂直方向排列，可以设置宽高。   | 宽度和高度由内容决定，无法直接设置。       | ^^                           |
> | 范例：div、p、h1 等元素。      | 范例：span、img、strong 等。               | ^^                           |
>
> * ③ 标准流中的所有元素都有一个 display 属性，用作元素的默认行为方式。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <div>我是div元素</div>
  <span>我是span元素</span>
  
</body>

</html>
```

## 1.3 模式转换

* 如果需要 `块级元素` 一行排列，或 `行内元素` 设置宽高，就可以利用 display 属性来进行转换。

| 属性值                 | 描述             | 是否独占一行 | 能够设置宽高 | 备注 |
| ---------------------- | ---------------- | ------------ | ------------ | ---- |
| display: block;        | 转换为块级元素   | ✅️            | ✅️            | 常用 |
| display: inline;       | 转换为行内元素   | ❌️            | ❌️            | 罕见 |
| display: inline-block; | 转换为行内块元素 | ❌️            | ✅️            | 较少 |

* `表单元素` 默认 `inline-block` ，其他元素想要转换可以使用 `display: inline-block;` 。

| 使用场景及其注意事项 | 描述                                                         |
| -------------------- | ------------------------------------------------------------ |
| :one: 使用场景       | 让块级盒子在一行显示。                                       |
| ^^                   | 让行内盒子可以设置宽度和高度。                               |
| :two: 注意事项       | 行内块元素中间会有空白缝隙，给父元素设置字体大小为 0 即可去掉；但是，子元素的字体大小还需要单独设置。 |
| ^^                   | 在实际开发中，如果对 `间距要求不高` 的情况下可以转换为行内块元素，以便同时具有行内元素和块级元素的特点。 |
| ^^                   | 如果要精细布局，需要使用 flex 布局或 grid 布局。             |



* 示例：模式转换（块级盒子在一行显示）

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    .container {
      /* 给父元素设置 font-size: 0 */
      font-size: 0;
    }

    [class*="box"] {
      /* 转换为行内块元素 */
      display: inline-block;
      /* 子元素字体大小需要单独设置 */
      font-size: 16px;
      width: 100px;
      height: 100px;
      background-color: pink;
      border: 1px solid red;
      text-align: center;
      line-height: 100px;
    }
  </style>
</head>

<body>

  <div class="container">
    <div class="box1">box1</div>
    <div class="box2">box2</div>
    <div class="box3">box3</div>
    <div class="box4">box4</div>
  </div>

</body>

</html>
```

# 第二章：浮动布局（过时）

## 2.1 概述

* `浮动`（float）最早是做 `文字环绕` 效果的，如下所示：

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-02/2026-10-02-15-09-18.gif)

## 2.2 浮动布局

* 格式：

```css
float: left | right | none;
```

> [!NOTE]
>
> * ① 属性值，如下所示：
>
> | 属性值 | 作用           | 范例          |
> | ------ | -------------- | ------------- |
> | left   | 向左浮动       | float: left;  |
> | right  | 向右浮动       | float: right; |
> | none   | 默认值，不浮动 | float: none;  |
>
> * ② `浮动` 可以让元素 `脱离文档流`，向左或向右浮动，直到碰到 `父容器边缘或其他浮动元素`。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <link rel="stylesheet" href="./css/index.css">
</head>

<body>

  <div class="box1"></div>
  <div class="box2"></div>
  <div class="box3"></div>

</body>

</html>
```

```css [index.css]
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

[class^="box"] {
  width: 100px;
  height: 100px;
  background-color: pink;
  text-align: center;
  line-height: 100px;
}

.box1 {
  float: left;
}

.box2 {
  float: left;
  background-color: lightgreen;
}

.box3 {
  float: left;
  background-color: lightcoral;
}
```

```md:img [cmd控制台]
![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-02/2026-10-02-15-26-34.gif)
```

## 2.3 浮动的弊端

* 浮动可以 `让元素脱离文档流` ，会影响周围元素的布局。

> [!NOTE]
>
> 脱离文档流：盒子 `上浮` 到标准流之上，浮动的盒子 `不占位置`。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-02/2026-10-02-15-45-23.gif)

* 浮动带来的影响，如下所示：

| 浮动的弊端                       | 描述                                                       |
| -------------------------------- | ---------------------------------------------------------- |
| 浮动带来的影响（父元素高度塌陷） | :one: 父盒子没有高度（很多情况下，不能给父盒子指定高度）。 |
| ^^                               | :two: 子元素浮动，会影响到其他的盒子布局。                 |

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-02/2026-10-02-15-54-00.gif)



* 示例：父元素高度塌陷

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <link rel="stylesheet" href="./css/index.css">
</head>

<body>

  <div class="container">
    <div class="box1">1</div>
    <div class="box2">2</div>
    <div class="box3">3</div>
    <div class="box4">4</div>
    <div class="box5">5</div>
  </div>
  <div class="footer">底部</div>

</body>

</html>
```

```css [index.css]
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

.container {
  width: 600px;
  background-color: skyblue;
  border: 1px solid #000;
}

[class^="box"] {
  /* 会导致父元素高度塌陷 */
  float: left;
  width: 100px;
  height: 100px;
  background-color: pink;
  text-align: center;
  line-height: 100px;
  border: 1px solid red;
}

.footer {
  width: 100%;
  height: 100px;
  background-color: orange;
  text-align: center;
  line-height: 100px;
}
```

```md:img [cmd控制台]
![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-02/2026-10-02-16-00-06.gif)
```

:::

## 2.4 解决方案

* 让浮动的元素尽量控制在父盒子之内，不要影响到其他盒子，即：清除浮动（闭合浮动）。

| 清除浮动的四种方式       | 描述                                                         |
| ------------------------ | ------------------------------------------------------------ |
| :one: 额外标签法         | 在浮动元素的最后面，新增一个块级标签，并添加 css 为 `clear: both;` 。 |
| :two: 单伪元素清除浮动   | 父元素添加伪元素，如：<pre>.clearfix::after {&#10;    content: "";&#10;    display: block;&#10;    clear: both;&#10;}</pre> |
| :three: 双伪元素清除浮动 | 父元素添加双伪元素，如：<pre>.clearfix::after,&#10;.clearfix::before {&#10;    content: "";&#10;    display: table;&#10;}&#10;&#10;.clearfix::after {&#10;    clear: both;&#10;}</pre> |
| :four: overflow 清除浮动 | 父元素添加 overflow，如：`overflow: hidden;` 。              |



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <link rel="stylesheet" href="./css/index.css">
</head>

<body>

  <div class="container clearfix">
    <div class="box1">1</div>
    <div class="box2">2</div>
    <div class="box3">3</div>
    <div class="box4">4</div>
    <div class="box5">5</div>
  </div>
  <div class="footer">底部</div>

</body>

</html>
```

```css [index.css]
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

/* 解决方案：清除浮动 */
.clearfix::after,
.clearfix::before {
  content: "";
  display: table;
}

.clearfix::after {
  clear: both;
}

.container {
  width: 600px;
  background-color: skyblue;
  border: 1px solid #000;
}

[class^="box"] {
  /* 会导致父元素高度塌陷 */
  float: left;
  width: 100px;
  height: 100px;
  background-color: pink;
  text-align: center;
  line-height: 100px;
  border: 1px solid red;
}

.footer {
  width: 100%;
  height: 100px;
  background-color: orange;
  text-align: center;
  line-height: 100px;
}
```

# 第三章：flex 布局

## 3.1 概述

* Flexbox 是 CSS 弹性盒子布局模块的缩写，可以快速实现元素的 `对齐`、`分布` 和 `空间分配` 。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-02/2026-10-02-16-37-18.png)

* 弹性盒子的核心，如下所示：

::: details 点我查看 具体细节

| 弹性盒子的核心             | 描述                                                      | 备注                                                         |
| -------------------------- | --------------------------------------------------------- | ------------------------------------------------------------ |
| :one: 父控子（亲父子）     | 父盒子 `控制` 子盒子如何排列布局                          | ![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-02/2026-10-02-19-54-49.png) |
| ^^                         | 父盒子称为容器（container），子盒子称为项目（item）       | ![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-02/2026-10-02-20-04-09.png) |
| :two: 主轴和交叉轴（侧轴） | 主轴默认水平方向，交叉轴默认垂直方向，可以更改            | ![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-02/2026-10-02-20-08-28.png) |
| ^^                         | 主轴决定了项目的主要排列方向（主轴 → 管排列）             | ![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-02/2026-10-02-20-27-08.png) |
| ^^                         | 交叉轴决定了项目在侧轴方向上的对齐方式（交叉轴 → 管对齐） | ![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-02/2026-10-02-20-36-45.png) |

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-02/2026-10-02-20-50-10.png)

## 3.2 容器（父盒子）属性 VS 项目（子盒子）属性

* 容器（父盒子）属性，如下所示：

| 属性            | 描述                                    | 范例                                         |
| --------------- | --------------------------------------- | -------------------------------------------- |
| display         | 设置元素为 flex 容器                    | .container  { display: flex; }               |
| flex-direction  | 修改主轴方向                            | .container { flext-direction: row; }         |
| ^^              | 项目排列方向                            | ^^                                           |
| flex-wrap       | 控制是否换行                            | .container { flext-wrap: wrap; }             |
| justify-content | 设置子盒子在主轴上的对齐方式            | .container { justify-content: center; }      |
| ^^              | 整体分布                                | ^^                                           |
| align-items     | 定义侧轴上的对齐方式                    | .container { align-items: center; }          |
| ^^              | 单行时整体对齐                          | ^^                                           |
| align-content   | 定义多行侧轴上的对齐方式                | .container { align-content: space-between; } |
| ^^              | 仅当 flext-wrap: wrap; 且内容换行时生效 | ^^                                           |

* 项目（子盒子）属性，如下所示：

| 属性        | 描述                                      | 范例                          |
| ----------- | ----------------------------------------- | ----------------------------- |
| order       | 定义项目的排列顺序                        | .item{ order: -1; }           |
| ^^          | 默认 0，数值越小越靠前                   | ^^                            |
| flex-grow   | 定义项目的放大比例                        | .item { flex-grow: 1; }       |
| ^^          | 默认 0，即：不放大                       | ^^                            |
| flex-shrink | 定义项目的缩小比例                        | .item { flex-shrink: 1; }     |
| ^^          | 默认 1，空间不足时等比缩小                | ^^                            |
| flex-basis  | 定义项目在主轴方向上的初始大小            | .item { flex-basis: 200px; }  |
| ^^          | 优先级高于 width 和 height                | ^^                            |
| flex        | flex-grow、flex-shrink、flex-basis 的缩写 | .item { flex: 1; }            |
| align-self  | 覆盖容器的 align-items                    | .item { align-self: center; } |
| ^^          | 单独定义某个项目的交叉轴对齐方式          | ^^                            |

## 3.3 容器（父盒子）属性

### 3.3.1 flex 容器

* 格式：

```css
.container  { 
    display: flex; 
}
```

> [!NOTE]
>
> * ① 容器（父盒子）设置 `display: flex;`，可以让子盒子按照 `主轴` 方式排列。
> * ② 特点，如下所示：
>   * 如果子元素 `有` 大小，则按照 `给定大小` 进行显示（最常用）。
>   * 如果子元素 `没有` 大小，则 `拉伸` 充满父容器（高度）。
>   * 如果子元素总宽度 `超过` 容器宽度，默认会 `压缩` 子元素。
> * ③ 在实际开发中，父容器设置 `display: flex;`，子元素设定大小。



* 示例：

::: code-group

```html [index.html] {17,26-27}
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    * {
      margin: 0;
      padding: 0;
      box-sizing: border-box;
    }

    .box {
      /* 开启弹性布局容器 */
      display: flex;
      width: 500px;
      height: 100px;
      border: 1px solid red;
    }


    .box .item {
      /* 如果子元素有大小，则按照给定大小来显示 */
      width: 100px;
      height: 100px;
      background-color: pink;
      border-radius: 10px;
      text-align: center;
      line-height: 100px;
    }
  </style>
</head>

<body>

  <div class="box">
    <div class="item">1</div>
    <div class="item">2</div>
    <div class="item">3</div>
    <div class="item">4</div>
  </div>

</body>

</html>
```


###  3.3.7 gap 间距

* 格式：

```css
.container {

    /* 让元素和元素之间保留间隙 */
```

>
> * ① gap 属性用于设置行和列的间隙，即：间距。
> * ② 语法解释，如下所示：
>
> | 语法            | 描述                                 |
> | --------------- | ------------------------------------ |
> | gap: 20px;      | 行和列之间保持 20 像素的间歇。       |
> | gap: 20px 30px; | 行间距是 20 像素，列间距是 30 像素。 |

## 3.4 项目（子盒子）属性

* 格式：

```css
.item {
    /* 数字表示剩余空间所占份数，是正整数。*/
    flex: 1;
}
```

> [!NOTE]
>
> * ① 子元素的属性用于控制自身的 `尺寸`、顺序或对齐方式。
> * ② `flex: 1;` 表示剩余空间占 1 份，并且可以伸缩盒子大小。
> * ③ `flex: 1;` 其实是缩写，如下所示：
>
> ::: details 点我查看 具体细节
>
> | 属性        | 描述                                      | 范例                          |
> | ----------- | ----------------------------------------- | ----------------------------- |
> | order       | 定义项目的排列顺序                        | .item{ order: -1; }           |
> | ^^          | 默认 0，数值越小越靠前                    | ^^                            |
> | flex-grow   | 定义项目的放大比例                        | .item { flex-grow: 1; }       |
> | ^^          | 默认 0，即：不放大                        | ^^                            |
> | flex-shrink | 定义项目的缩小比例                        | .item { flex-shrink: 1; }     |
> | ^^          | 默认 1，空间不足时等比缩小                | ^^                            |
> | flex-basis  | 定义项目在主轴方向上的初始大小            | .item { flex-basis: 200px; }  |
> | ^^          | 优先级高于 width 和 height                | ^^                            |
> | flex        | flex-grow、flex-shrink、flex-basis 的缩写 | .item { flex: 1; }            |
> | align-self  | 覆盖容器的 align-items                    | .item { align-self: center; } |
> | ^^          | 单独定义某个项目的交叉轴对齐方式          | ^^                            |
>
> :::



* 示例：

::: code-group

```html [index.html] {17,27}
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    * {
```
