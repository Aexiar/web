# 第一章：定位布局

## 1.1 概述

* `定位布局`（position）是控制元素在页面中位置的核心技术之一。

::: details 点我查看 具体细节

* ① 通过定位，可以实现元素脱离文档流、层叠、固定在 `特定位置` 的布局效果（定位和位置有关）。
* ② 应用场景，如下所示：

| 应用场景                                                   | 描述                                                         |
| ---------------------------------------------------------- | ------------------------------------------------------------ |
| :one: 固定导航栏：元素滚动时导航栏始终 `固定` 在视口顶部。 | ![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-08/2026-10-08-08-24-38.gif) |
| :two: 吸顶效果：元素在滚动到某个位置后固定。               | ![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-08/2026-10-08-08-29-14.gif) |
| :three: 弹出菜单或下拉框：鼠标悬停时显示浮动菜单。         | ![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-08/2026-10-08-08-30-16.gif) |
| :four: 悬浮效果：元素悬浮在其他元素上方。                  | ![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-08/2026-10-08-08-31-05.gif) |

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-08/2026-10-08-08-18-34.png)

* 根据定位使用场景的不同，可以将定位分为：`相对定位`、`绝对定位`、`固定定位` 和 `粘性定位`。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-08/2026-10-08-08-34-55.png)

## 1.2 相对定位

* 格式：

```css
position: relative;
```

::: details 点我查看 具体细节

* ① 相对定位是定位布局中常用的定位方式，其核心在于 `元素相对于自身正常位置` 进行偏移。
* ② 使用场景：相对定位通常和绝对定位搭配使用（`子绝父相`），主要是给绝对定位当 `爹` 的。
* ③ 相对定位的特点，如下所示：
  * 相对于自身 `原来位置` 移动距离。
  * `不脱离` 文档流，元素原位置依然被 `保留`，其他元素按照原布局排列。
  * 可以通过 `top`、`bottom`、`left` 和 `right` 等属性进行偏移。
  * 优先级：如果同时设置 top 和 bottom，仅 top 生效；同理，left 覆盖 right。

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-08/2026-10-08-09-12-02.png)



* 示例：

::: code-group

```html [index.html] {17,23-24}
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    [class*='box']{
      width: 200px;
      height: 200px;
      background-color: skyblue;
    }

    .box1 {
      /* 给元素添加相对定位 */
      position: relative;
      /* 
        相对于自身原来位置移动距离。
        可以通过 top、bottom、left、right 属性来设置元素的偏移量
        不脱离文档流，元素原位置依然被保留，其他元素按照原布局排列
      */
      top: 100px;
      left: 100px;
    }

    .box2 {
      background-color: pink;
    }

  </style>
</head>

<body>

  <div class="box1">1</div>
  <div class="box2">2</div>

</body>

</html>
```

## 1.3 绝对定位

* 格式：

```css
position: absolute;
```

::: details 点我查看 具体细节

* ① 绝对定位的核心是 `脱离文档流`，并且基于 `定位基准` 进行偏移。
* ② 使用场景，如下所示：

| 使用场景              | 描述                       |
| --------------------- | -------------------------- |
| :one: 弹出菜单/下拉框 | 鼠标悬停时，显示浮动菜单。 |
| :two: 悬浮效果        | 元素悬浮在其他元素上方。   |

* ③ 绝对定位的特点，如下所示：
  * 元素 `脱离文档流`，不占据空间，其他元素按照原布局排列。
  * 相对于最近的 `已定位的祖先元素`（position 非 static）移动位置。如果都没有定位则相对于 `视口` 来定位。
  * 可以通过 `top`、`bottom`、`left` 和 `right` 等属性进行偏移。
  * 优先级：如果同时设置 top 和 bottom，仅 top 生效；同理，left 覆盖 right。

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-08/2026-10-08-09-43-52.png)



* 示例：

::: code-group

```html [index.html] {11,29,36-37}
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    .father {
      /* 给盒子添加相对定位 */
      position: relative;
      width: 400px;
      height: 400px;
      background-color: pink;
      margin: 100px auto;
    }

    [class*='son'] {
      text-align: center;
      align-content: center;
      width: 120px;
      height: 120px;
      background-color: skyblue;
      border: 1px solid red;
    }

    .son1 {
      /* 给元素添加绝对定位 */
      position: absolute;
      /* 
        元素 `脱离文档流`，不占据空间，其他元素按照原布局排列。
        相对于最近的 `已定位的祖先元素`（position 非 static）移动位置。
        如果都没有定位则相对于 `视口` 来定位。
        可以通过 `top`、`bottom`、`left` 和 `right` 等属性进行偏移。
      */
      top: 100px;
      left: 100px;
    }

    .son2 {
      background-color: purple;
    }
  </style>
</head>

<body>

  <div class="father">
    <div class="son1">1</div>
    <div class="son2">2</div>
  </div>

</body>

</html>
```

## 1.4 固定定位

* 格式：

```css
position: fixed;
```

::: details 点我查看 具体细节

* ① 固定定位的核心是 `脱离文档流`，并且始终基于 `浏览器视口` 进行偏移。
* ② 使用场景，如下所示：

| 使用场景         | 描述                                           |
| ---------------- | ---------------------------------------------- |
| :one: 固定导航栏 | 页面滚动的时候，导航栏始终 `固定` 在视口顶部。 |
| :two: 页面广告   | 广告覆盖整个页面。                             |

* ③ 固定定位的特点，如下所示：
  * 元素 `脱离文档流`，不占据空间，其他元素按照原布局排列。
  * 始终相对于浏览器窗口（视口）定位，滚动页面时位置不变。
  * 可以通过 `top`、`bottom`、`left` 和 `right` 等属性进行偏移。
  * 优先级：如果同时设置 top 和 bottom，仅 top 生效；同理，left 覆盖 right。

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-08/2026-10-08-13-42-34.png)



* 示例：

::: code-group

```html [index.html] {14-16}
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    .box {
      /* 
        固定定位
        始终相对于视口定位，滚动页面时位置不变。
      */
      position: fixed;
      bottom: 30px;
      left: 50%;
      transform: translateX(-50%);

      width: 600px;
      height: 120px;
      background-color: rgba(0, 0, 0, .5);
      border-radius: 15px;
    }
  </style>
</head>

<body>
  <div class="box"></div>
</body>

</html>
```

## 1.5 粘性定位

* 格式：

```css
position: sticky;
```

::: details 点我查看 具体细节

* ① 粘性定位是一种混合定位模式，结合了相对定位和固定定位的特性。
* ② 使用场景，如下所示：

| 使用场景           | 描述                         |
| ------------------ | ---------------------------- |
| :one: 吸顶效果     | 元素在滚动到某个位置后固定。 |
| :two: 表格表头固定 | 长表格滚动时表头始终可见。   |

* ③ 粘性定位的特点，如下所示：
  * 元素在滚动到指定位置（top: 10px）前为相对定位，之后转为固定定位。
  * 父容器的 overflow 需要设置为 visible；否则，粘性定位将失效。
  * 可以通过 `top`、`bottom`、`left` 和 `right` 等属性进行偏移。
  * 必须指定 top、right、bottom 和 left 中的一个，方可使得粘性定位生效。

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-08/2026-10-08-13-53-34.png)



* 示例：

::: code-group

```html [index.html] {21,23}
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    ul,
    ol {
      list-style: none;
    }

    a {
      text-decoration: none;
      color: #000;
    }

    .nav {
      /* 开启粘性定位 */
      position: sticky;
      /* 元素在滚动到指定位置（top: 0）前为相对定位，之后转为固定定位。 */
      top: 0;
      display: flex;
      align-items: center;
      gap: 10px;
      height: 80px;
      width: 500px;
      margin: 100px auto;
      background-color: pink;
    }

    .nav .item {
      text-align: center;
      align-content: center;
      letter-spacing: 2px;
      width: 84px;
      height: 28px;
      background-color: #f6f7f8;
    }

    .nav .item a {
      display: block;
      width: 100%;
      height: 100%;
    }

    .main {
      height: 2000px;
      background-color: skyblue;
    }
  </style>
</head>

<body>

  <!-- 导航 -->
  <ul class="nav">
    <li class="item"><a href="#">番剧</a></li>
    <li class="item"><a href="#">国创</a></li>
    <li class="item"><a href="#">综艺</a></li>
    <li class="item"><a href="#">动画</a></li>
    <li class="item"><a href="#">鬼畜</a></li>
  </ul>

  <!-- 主体部分 -->
  <main class="main"></main>

</body>

</html>
```

## 1.6 层叠顺序 z-index

* 格式：

```css
z-index: 9999;
```

::: details 点我查看 具体细节

* ① z-index 属性用于控制元素在三维空间中的层叠顺序，即：z 轴方向。
* ② 当多个元素在同一个平面（同一行或列）重叠的时候，z-index 决对那个元素显示在最上层。
* ③ 使用场景：提高层次悬浮效果或实现图片层叠效果。

* ④ z-index 的特点，如下所示：
  * 用于设置层级，其值是整数（正数、负数或 0）或 auto。数值越大，层级越高。
  * 默认值是 auto（等同于未设置，后面出现的元素会覆盖前面出现的元素）。
  * 生效条件：仅对定位元素（relative、absolute、fixed 或 sticky）有效。

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-08/2026-10-08-14-46-54.png)



* 示例：

::: code-group

```html [index.html] {10,32}
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    .box img {
      position: absolute;
    }

    .box img:nth-child(1) {
      /* z-index: 4; */
      left: 30px;
      top: 30px;
    }

    .box img:nth-child(2) {
      /* z-index: 3; */
      left: 60px;
      top: 60px;
    }

    .box img:nth-child(3) {
      /* z-index: 2; */
      left: 90px;
      top: 90px;
    }

    .box img:nth-child(4) {
      z-index: 1;
      left: 120px;
      top: 120px;
    }
  </style>
</head>

<body>

  <div class="box">
    <img src="./img/tel1.png" alt="">
    <img src="./img/tel2.png" alt="">
    <img src="./img/tel3.png" alt="">
    <img src="./img/tel4.png" alt="">
  </div>
</body>

</html>
```

# 第二章：grid 布局

## 2.1 概述

* `网格布局` 是 `二维布局` 模型，允许开发者通过定义行或列来精确控制网页元素的位置和尺寸。

::: details 点我查看 具体细节

* 弹性布局 Flex VS 网络布局 Grid，如下所示：

| 布局类型       | 特点                                                         |
| -------------- | ------------------------------------------------------------ |
| :one: 弹性布局 | 一维布局，只能在单一方向（水平或垂直）上排列元素，适合线性排列的场景。 |
| :two: 网格布局 | 二维布局，可以同时控制行或列的排列，实现真正的二维布局。     |

* 如何选择？

| 布局模型                                                     | 应用场景       | 备注                                 |
| ------------------------------------------------------------ | -------------- | ------------------------------------ |
| :one: 弹性布局：适合快速实现一维布局、动态内容对齐。         | 单行布局       | 实际开发中，大部分情况下是两者混用。 |
| :two: 网格布局：适合构建复杂页面框架、提供更强大的二维控制能力。 | 多列或者响应式 | ^^                                   |

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-08/2026-10-08-15-54-12.png)

## 2.2 网格布局的基本概念

### 2.2.1 概述

* 网格布局的基本概念，包括：`容器`、`行`、`列`、`单元格` 以及 `项目` 。

::: details 点我查看 具体细节

* ① 网格布局是一种二维布局模型，能够同时处理行和列。理解网格布局的核心，在于清晰区分其基础构件及其层次关系。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-08/2026-10-08-16-23-43.jpg)

* ② 容器（Grid Container）：网格布局的 `顶层宿主环境` 。通过在 HTML 元素上设置 `display:grid` 或 `display: inline-grid` 声明。

| 作用 & 主要职责 | 描述                                                         |
| --------------- | ------------------------------------------------------------ |
| :one: 作用      | 定义网格格式化上下文（Grid Formatting Context），其内部的所有直接子元素都会自动成为网格项目。 |
| :two: 主要职责  | 定义整个网格的结构（有多少行、多少列、列宽、行高、间距等）。 |

* ② 行（Row）和列（Column）：网格布局中的 `维度轨道`（Grid Tracks），即：两条相邻网格线之间的空间。

| 行 & 列  | 描述                                                         |
| -------- | ------------------------------------------------------------ |
| :one: 行 | 网格中的水平轨道，从左到右延伸。在 CSS 中使用 `grid-template-rows` 进行定义。 |
| :two: 列 | 网格中的垂直轨道，从上到下延伸。在 CSS 中使用 `grid-template-columns` 进行定义。 |

* ③ 单元格（Grid Cell）：网格中的 `最小基本单元` 。

| 形式方式 & 特点 | 描述                                                         |
| --------------- | ------------------------------------------------------------ |
| :one: 形成方式  | 由一条水平网格线和一条垂直网格线交叉交叉围成的独立区域（类似于 Excel 表格中的单个单元格）。 |
| :two: 特点      | 1 行 × 1 列相交的物理空间。网格默认按顺序将项目放入每个单元格中。 |

* ④ 项目（Grid Item）：网格容器中的 `直接子元素`（Direct Children）。

| 特点 & 定位与跨越 | 描述                                                         |
| ----------------- | ------------------------------------------------------------ |
| :one: 特点        | 仅限 **第一层直接子元素**，孙子节点或更深层级的元素不会自动成为 Grid Item。 |
| :two: 定位与跨越  | 默认情况下，一个项目占用一个单元格；但通过 `grid-column` 或 `grid-row` 属性，一个项目可以跨越多个单元格，覆盖一片 **网格区域（Grid Area）**。 |

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-08/2026-10-08-16-19-47.png)

### 2.2.2 网格容器（Grid Container）

* 格式：

```css

```

::: details 点我查看 具体细节

* ① 容器（父盒子）设置 `display : grid;` （块级）或者 `display: inline-grid;` （行内）。
* ② 和弹性盒子不同的是，在定义网格后，网页并不会立即发生变化，因为 `display : grid;` 的声明只创建了一个只有一列的盒子。

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-08/2026-10-08-16-40-40.png)

### 2.2.3 网格轨道（Grid Tracks）

* 格式：

```css
/* 定义网格中的行，每行的高度是 100px */
grid-template-rows : 100px 100px 100px;
/* 定义网格中的列，每列的宽度是 200px */
grid-template-columns : 200px 200px 200px; 
```

::: details 点我查看 具体细节

* ① 网格轨道（Grid Tracks）决定了网格容器的基础布局，为子元素提供放置的位置。
* ② 有几个属性值就代表创建了几行或几列。

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-08/2026-10-08-16-53-17.png)



* 示例：

::: code-group

```html [index.html] {22,24,26}
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    * {
      margin: 0;
      padding: 0;
      box-sizing: border-box;
    }

    ul,
    ol {
      list-style: none;
    }

    .box {
      /* 开启网格布局 */
```

# 第三章：多列布局

## 3.1 概述

* `多列布局` 用于将元素的内容 `自动切割` 为指定数量的垂直列。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-08/2026-10-08-23-18-55.png)

## 3.2 语法

* 格式：

```css
/* 根据容器宽度和 column-count 值，自动分配宽度 */
column-count: 5 ;
/* 列之间的距离 */
column-gap: 20px；
/* 列之间的分割线样式（原色 宽度 样式） */
column-rule: 1px solid red;
```

> [!NOTE]
>
> * 【问】底部子元素被“切断” ，是因为 column-count 的本质是将内容按照垂直方向 `自动切割到多列`（类似报纸排版），内容会优先填满一列后再流入下一列。
> * 【答】给子元素添加 `break-inside: avoid-column;` ，即：强制元素不跨列分割。



* 示例：

::: code-group

```html [index.html] {17-19,29}
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>

  <style>
    * {
      margin: 0;
      padding: 0;
      box-sizing: border-box;
    }

    .box {
      column-count: 5;
      column-gap: 10px;
      column-rule: 1px solid red;
      max-width: 1200px;
      border: 1px solid red;
      margin: 100px auto;
    }

    .box .item {
      height: 150px;

    }
```

## 4.1 鼠标样式

* 格式：

```css
cursor: pointer;
```

> [!NOTE]
>
> * ① 在 CSS 中，cursor 属性用于控制 `鼠标指针` 在元素上的 `显示样式` ，通过改变光标形态可以向用户传递交互提示，从而提升界面交互体验。
> * ② cursor 属性值，如下所示：
>
> | 属性值      | 描述                                                         |
> | ----------- | ------------------------------------------------------------ |
> | default     | 默认箭头（通常是系统默认的箭头光标）。                       |
> | pointer     | 手型（指尖朝下的小手），常用于可点击元素，如：链接 `<a>`、按钮 `<button>`。 |
> | text        | `|` 型竖线（类似文本输入光标），用于可编辑文本区域，如：`<textarea>`、contenteditable 元素。 |
> | wait        | 等待（旋转圆圈或沙漏），表示操作进行中，如：加载、提交时。   |
> | help        | 帮助（带问号的箭头），提示用户需要帮助，如：提示信息区域。   |
> | not-allowed | 禁止（圆圈带斜线），表示操作不可用，如：禁用的按钮。         |
> | grab        | 抓取（手型带抓取动作），表示可拖动，如：可拖拽的元素。       |
> | grabbing    | 抓取中（手型收紧），表示正在拖动，配合 grab 使用。          |
> | zoom-in     | 放大（`+` 号），表示放大操作，如：图片预览时。                |
> | zoom-out    | 缩小（`-` 号），表示缩小操作，如：图片预览时。                |

## 4.2 CSS 书写顺序

* 属性顺序应遵循 `布局→盒模型→视觉→交互→其他` 的逻辑，核心目标是让代码更易读、易维护。



* 示例：

| 顺序              | 常见属性列表                                                 |
| ----------------- | ------------------------------------------------------------ |
| 布局相关          | `display`（显示类型）、`visibility`（可见性）、`position`（定位方式）、`top/right/bottom/left`（定位偏移）、`float`（浮动）、`clear`（清除浮动）、`overflow`（溢出处理）、`z-index`（层叠顺序）、`clip`（裁剪）。 |
| 盒模型            | `box-sizing`（盒模型计算方式）、`width/min-width/max-width`（宽度）、`height/min-height/max-height`（高度）、`margin`（外边距）、`padding`（内边距）、`border`（边框）、`outline`（轮廓，可选）。 |
| 视觉样式          | `color`（文本颜色）、`background`（背景，含 `background-color/background-image` 等）、`font`（字体综合）、`font-size`（字号）、`font-family`（字体系列）、`line-height`（行高）、`text-align`（文本对齐）、`text-indent`（首行缩进）、`letter-spacing`（字间距）、`white-space`（空白处理）。 |
| 交互与动画        | `cursor`（鼠标指针）、`opacity`（透明度）、`transition`（过渡）、`animation`（动画）、`transform`（变换，如旋转、缩放）。 |
| 其他（按需/低频） | `filter`（滤镜）、`clip-path`（裁剪路径）、`backdrop-filter`（背景滤镜）、`will-change`（优化提示）、`touch-action`（触摸行为）、`scroll-behavior`（滚动行为）。 |
