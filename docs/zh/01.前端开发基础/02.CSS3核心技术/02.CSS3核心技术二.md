# 第一章：盒子模型

## 1.1 概述

* 页面中所有元素都会被 `盒子` 包围，学会 `盒子模型` 是实现 `准确布局`、`处理元素排列` 的关键。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-09-30/2026-09-30-09-02-18.png)

* 当然，也可以使用 `浏览器插件` 来 `查看` 对应 `页面` 的 `每个小盒子`。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-09-30/2026-09-30-09-13-05.gif)

## 1.2 盒子的分类

* 在 CSS 中，我们通常会将盒子分为三类，如下所示：

::: details 点我查看 具体细节

* ① 盒子的分类，如下所示：

| 盒子的分类                         | 特点                                     | 范例                     |
| ---------------------------------- | ---------------------------------------- | ------------------------ |
| :one: 块级盒子（block）            | 盒子 `会` 都占一行。                       | div、p、h、ul、table 等 |
| ^^                                 | width 和 height 属性 `可以` 发挥作用。     | ^^                       |
| ^^                                 | 不设置宽度，默认是父元素宽度的 100% 。   | ^^                       |
| ^^                                 | 内边距、外边距和边框会撑大元素。         | ^^                       |
| :two: 行内盒子（inline）           | 盒子 `不会` 独占一行。                     | span、em、a、strong 等。 |
| ^^                                 | width 和 height 属性 `不会` 发挥作用。     | ^^                       |
| ^^                                 | `垂直方向` 的内边距和外边距不起效果。     | ^^                       |
| ^^                                 | `水平方向` 的内边距、外边距会有效果。     | ^^                       |
| :three: 行内块盒子（inline-block） | 盒子 `不会` 独占一行，可以和其他盒子同行。 | button、input、select 等 |
| ^^                                 | width 和 height 属性 `可以` 发挥作用。     | ^^                       |
| ^^                                 | 内边距、外边距和边框都可以正常设置。     | ^^                       |
| ^^                                 | 同时具有行内盒子和块级盒子的特点。       | ^^                       |

* ② 行内块盒子可以简单理解为：外面像行内盒子，可以同行；里面像块级盒子，可以设置宽高。
* ③ 在浏览器中，可以通过查看 display 样式来确定盒子的具体分类。

::: 

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-09-30/2026-09-30-09-36-32.png)

## 1.3 盒子模型的组成

### 1.3.1 概述

* CSS 的 `盒子模型` 整体上适用于 `块级盒子`，包含了 `内容`、`内边距` 、`外边距` 以及 `边框` 。

::: details 点我查看 具体细节

* 盒子模型，如下所示：

| 盒子模型             | 描述                                                   |
| -------------------- | ------------------------------------------------------ |
| :one: 内容 content   | 显示内容的区域，由内容或指定宽度或高度来决定内容大小。 |
| :two: 内边距 padding | 内容和边框之间的距离。                                 |
| :three: 边框 border  | 包裹内容和内边距。                                     |
| :four: 外边距 margin | 盒子和其他元素之间的距离。                             |

* 元素的实际占用尺寸 = 内容尺寸 + 内边距 + 边框。

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-09-30/2026-09-30-09-53-59.png)

### 1.3.2 边框（border）

* 格式：

```css
boder: border-width(宽度) border-style(样式) border-color(颜色);
```

> [!NOTE]
>
> * ① `边框属性` 用于设置盒子边框。
> * ② 边框的三个属性必须同时存在，并且没有先后顺序之分，中间使用 `空格` 隔开。
> * ③ 边框样式，如下所示：
>
> | 边框样式 | 描述     | 视觉效果         |
> | -------- | -------- | ---------------- |
> | dotted   | 点状边框 | 圆点组成的虚线   |
> | dashed   | 虚线边框 | 短横线组成的虚线 |
> | solid    | 实线边框 | 单一线条         |
>
> * ④ 应用场景：给盒子设置四个边框或单独设置边框（使用方位名词，如：border-top、border-bottom、border-left、border-right）。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <link rel="stylesheet" href="./style/index.css">
</head>

<body>
    
  <div class="box box1">我是box1盒子</div>
  <div class="box box2">我是box2盒子</div>
  <div class="box box3">我是box3盒子</div>
  <div class="box box4">我是box4盒子</div>
    
</body>

</html>
```

```css [index.css]
body {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

.box {
  width: 150px;
  height: 150px;
}

.box1 {
  border: 2px solid #b02179;
}

.box2 {
  border:2px dotted #b02179;
}

.box3 {
  border: 2px dashed #b02179;
}

.box4{
  border: 2px solid #d9e0ee;
  border-top: 3px solid orange;
}
```

### 1.3.3 内边距（padding）

* 格式：

```css
padding: 10px;
```

> [!NOTE]
>
> * ① `内边距` 是控制 `边框` 和 `内容区域` 之间距离的，主要是让盒子内容和边框保持一定距离，更加美观。
>
> ::: details 点我查看 具体细节
>
> | 使用场景                               | 描述                                                         |
> | -------------------------------------- | ------------------------------------------------------------ |
> | 让盒子内容和边框保持一定距离，更加美观 | ![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-01/2026-10-01-14-12-46.png) |
> | ^^                                     | ![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-01/2026-10-01-14-14-15.png) |
>
> :::
>
> * ② 内边距的多个值之间使用 `空格` 隔开，如下所示：
>
> | 边框样式                      | 描述                                         |
> | ----------------------------- | -------------------------------------------- |
> | padding: 10px;                | 上下左右 4 个内边距都是 10px                 |
> | padding: 10px 20px;           | 上下内边距是 10px，左右内边距是 20px         |
> | padding: 10px 20px 30px;      | 上是 10px，左右是 20px，下是 30px            |
> | padding：10px 20px 30px 40px | 上 10px，右 20px，下 30px，左 40px（顺时针） |
>
> * ③  应用场景：给盒子设置四个内边距或单独设置内边距（使用方位名词，如：padding-top、padding-bottom、padding-left、padding-right）。

```html [index.html]
  <div class="box box1">box1</div>
```

### 1.3.4 外边距（margin）

* 格式：

```css
margin: 10px;
```

> [!NOTE]
>
> * ① `外边距` 是是盒子周围一圈看不到的空间，主要是让盒子和盒子之间保持一定距离，更加美观。
>
> ::: details 点我查看 具体细节
>
> | 使用场景                               | 描述                                                         |
> | -------------------------------------- | ------------------------------------------------------------ |
> | ​让盒子和盒子之间保持一定距离，更加美观 | ![image-20261001143549089](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-01/2026-10-01-14-35-49.png) |
> | ^^                                     | ![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-01/2026-10-01-14-39-41.png) |
>
> :::
>
> * ② 外边距的多个值之间使用 `空格` 隔开，如下所示：
>
> | 边框样式                    | 描述                                         |
> | --------------------------- | -------------------------------------------- |
> | margin: 10px;               | 上下左右 4 个外边距都是 10px                 |
> | margin: 10px 20px;          | 上下外边距是 10px，左右外边距是 20px         |
> | margin: 10px 20px 30px;     | 上是 10px，左右是 20px，下是 30px            |
> | margin：10px 20px 30px 40px | 上 10px，右 20px，下 30px，左 40px（顺时针） |
>
> * ③  应用场景：给盒子设置四个外边距或单独设置外边距（使用方位名词，如：margin-top、margin-bottom、margin-left、margin-right）。
> * ④ 行内元素（内联元素）左右外边距生效；但是，上下外边距无效（设置宽度和高度无效）。

## 1.7 外边距折叠和塌陷

### 1.7.1 概述

* `普通文档流` 中的 `块级元素` 使用 margin 时，可能会出 `现外边距折叠（合并）` 或 `外边距塌陷`。

### 1.7.2 外边距合并

* 相邻兄弟盒子的外边距合并，如下所示：

::: details 点我查看 具体细节

* 形成的原因，如下所示：

| 折叠（合并）情况       | 原因                                                         |
| ---------------------- | ------------------------------------------------------------ |
| 邻兄弟盒子的外边距合并 | :one: 相邻兄弟的块级盒子。                                   |
| ^^                     | :two: 两个上下外边距将合并为一个外边距。其大小等于最大的单个外边距。 |

* 解决方案：不要给相邻兄弟盒子都使用外边距，只需要给其中一个盒子使用外边距。

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-01/2026-10-01-15-45-26.png)



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <link rel="stylesheet" href="./style/index.css">
</head>

<body>
    
  <div class="box1">box1</div>
  <div class="box2">box2</div>
    
</body>

</html>
```

```css [index.css]
[class^="box"] {
  width: 100px;
  height: 100px;
  background-color: pink;
  border: 1px solid #000;
}

.box1 {
  /* margin-bottom: 20px; */ 
}

.box2 {
  /* 解决方案：只给一个盒子使用外边距 */  
  margin-top: 50px;
  background-color: skyblue;
}
```

### 1.7.3 外边距塌陷

* 父子盒子的外边距塌陷，如下所示：

::: details 点我查看 具体细节

* 形成的原因，如下所示：

| 折叠（合并）情况     | 原因                                             |
| -------------------- | ------------------------------------------------ |
| 父子盒子的外边距塌陷 | :one: 嵌套关系 (父子）的区块元素。                |
| ^^                   | :two: 给子盒子设置上下外边距会让父盒子塌陷移动。 |

* 解决方案：
  * :one: 给父盒子添加 `上边框 border-top`（父盒子本身有边框，则不会出现问题）。
  * :two: 给父盒子添加 `上内边距 padding-top` 。
  * :three: 给父盒子添加 `overflow:hidden;` 属性。
  * :four: 给父盒子创建新的格式上下文，如：`display: flow-root/flex/grid` 。

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-01/2026-10-01-15-51-37.png)



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <link rel="stylesheet" href="./style/index.css">
</head>
```

## 1.8 尺寸计算

* CSS 盒子模型（默认），除了 width 和 height 会增加盒子大小，padding 和 border 一样可以：

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-01/2026-10-01-18-04-04.gif)

* 因为 box-sizing 是定义元素盒子模型的计算方式，即：控制元素的 width 和 height 是否包含 padding 和 border。

| 属性       | 值          | 说明                                                         |
| ---------- | ----------- | ------------------------------------------------------------ |
| box-sizing | content-box | 元素的 width 和 height 仅包含内容区域，不包含 padding 和 border。 |
| ^^         | ^^          | width = 内容的宽度（默认）。                                 |
| ^^         | border-box  | 元素的 width 和 height 包含内容、padding 和 border           |
| ^^         | ^^          | width = 内容的宽度 + border + padding（实际开发推荐）。      |

* 如果我们要实现指定固定 width 和 height 的盒子，之前我们需要计算，非常麻烦：

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-01/2026-10-01-18-15-12.gif)

* 在实际开发中，我们提倡使用 border-box，这样可以省略计算，非常方便：

## 1.9 背景

### 1.9.1 概述

* background 用于设置元素背景相关属性，包括：背景颜色、背景图片、背景位置等。

::: details 点我查看 具体细节

| background 相关属性   | 描述                 | 常用值                                                   |

| ---------------------- | ---------------------------------------------- |
| :one: 矢量缩放         | 无损放大缩小。                                 |
| :two: 样式灵活         | 通过 CSS 直接修改颜色、大小、阴影等属性。      |
| :three: 减少 HTTP 请求 | 一个字体文件可包含多个图标，比多张图片更高效。 |
| :four: 兼容性好        | 支持所有现代浏览器，甚至部分旧版浏览器。       |

## 1.2 如何使用？

* 字体图标要么由设计师提供，要么去字体库下载。

| 图标库                                             | 特点                                               |
| -------------------------------------------------- | -------------------------------------------------- |
| [Font Awesome](https://fontawesome.com/)           | 图标最全，支持免费版和 Pro 付费版。                |
| [Bootstrap Icons](https://icons.getbootstrap.com/) | Bootstrap 生态内图标，简单易用                     |
| [icomoon](https://icomoon.io/)                     | IcoMoon 最早推出了第一个自定义图标字体生成器       |
| [iconfont](https://www.iconfont.cn/)               | 阿里字体库，包含淘宝图标库和阿里妈妈图标库（免费） |

> [!NOTE]
>
> 使用步骤，如下所示：
>
> * ① 下载字体图标文件：去官网或者设计师准备字体图标文件， 保存到项目目录下。
> * ② 引入 html 文件：根据提供的压缩包，通过 link 标签的方式引入 CSS 文件。
> * ③ 使用字体图标：一般情况下，我们通过标签调用类名选择对应字体图标。根据实际需求，调整字体样式，如：颜色、大小、位置等。

# 第三章：精灵图

## 3.1 概述

* 精灵图是将多个小图标或图像合并到一张大图中，通过调整 background-position 属性来显示特定部分的图像技术。

> [!NOTE]
>
> * ① 精灵图解决的是“减少大量小图片 HTTP 请求”这个老问题。
> * ② 现在 HTTP/2、HTTP/3 多路复用，加上 SVG Sprite、SVG `<symbol>`、iconfont、Webpack/Vite 打包等方案，已经让传统 PNG Sprite 的优势小很多。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-02/2026-10-02-09-35-16.png)

## 3.2 如何使用？

* 步骤：

```txt
① 给盒子添加背景图片。
② 通过背景定位（background-position）移动位置对齐。
③ 需要注意网页坐标的不同。
```

> [!NOTE]
>
> * ① 实际开发中，从设计稿中复制即可。
> * ② 网页的坐标和数学中坐标的方向是不同的，如下所示：
>
> ::: details 点我查看 具体细节
>
> ![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-02/2026-10-02-09-39-57.jpeg)
>
> :::



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    .box {
      width: 27px;
      height: 26px;
      /* 精灵图的核心是作为背景 */

    }

    .box1 {
      background-position: 0 -169px;
    }

    .box2 {
      margin: 100px auto;
      background-position: -90px -170px;
    }
  </style>
</head>

  <div class="box box1"></div>
  <div class="box box2"></div>
```

## 4.2 多行文本显示省略号

* 单行文本溢出显示省略号：

```css
text-overflow: ellipsis; /* 文字溢出显示省略号 */
white-space: nowrap; /* 文字不换行 */
overflow: hidden; /* 元素溢出时隐藏 */
```

* 多行文本显示省略号：

```css
dispaly: -webkit-box; /* 旧版弹性盒子布局*/
-webkit-box-orient: vertical; /* 文本垂直排列*/
-webkit-line-clamp: 3; /* 限制显示行数*/
overflow: hidden; /* 隐藏溢出内容*/
text-overflow: ellipsis; /* 文本溢出显示省略号*/
```



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="zh-CN">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    .box {
      width: 200px;
      background-color: pink;
      /* 多行文本溢出显示省略号：盒子高度由行数自动撑开，无需写死固定高度 */
      /* 旧版弹性盒子布局 */
      display: -webkit-box;
      /* 文本垂直排列 */
      -webkit-box-orient: vertical;
      /* 限制显示行数（WebKit 前缀在前兼容旧浏览器，标准写法在后渐进增强） */
      -webkit-line-clamp: 2;

      /* 隐藏溢出内容 */
```
