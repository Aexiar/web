# 第一章：盒子模型

## 1.1 概述

* 页面中所有元素都会被 `盒子` 包围，学会 `盒子模型` 是实现 `准确布局`、`处理元素排列` 的关键。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-09-30/2026-09-30-09-02-18.png)

* 当然，也可以使用 `浏览器插件` 来 `查看` 对应 `页面` 的 `每个小盒子`。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-09-30/2026-09-30-09-13-05.gif)

## 1.2 盒子的分类

* 在 CSS 中，我们通常会将盒子分为三类，如下所示：

::: details 点我查看 具体细节

* ① 盒子的分类，如下所示：

| 盒子的分类                         | 特点                                     | 范例                     |
| ---------------------------------- | ---------------------------------------- | ------------------------ |
| :one: 块级盒子（block）            | 盒子 `会` 都占一行。                       | div、p、h、ul、table 等 |
| ^^                                 | width 和 height 属性 `可以` 发挥作用。     | ^^                       |
| ^^                                 | 不设置宽度，默认是父元素宽度的 100% 。   | ^^                       |
| ^^                                 | 内边距、外边距和边框会撑大元素。         | ^^                       |
| :two: 行内盒子（inline）           | 盒子 `不会` 独占一行。                     | span、em、a、strong 等。 |
| ^^                                 | width 和 height 属性 `不会` 发挥作用。     | ^^                       |
| ^^                                 | `垂直方向` 的内边距和外边距不起效果。     | ^^                       |
| ^^                                 | `水平方向` 的内边距、外边距会有效果。     | ^^                       |
| :three: 行内块盒子（inline-block） | 盒子 `不会` 独占一行，可以和其他盒子同行。 | button、input、select 等 |
| ^^                                 | width 和 height 属性 `可以` 发挥作用。     | ^^                       |
| ^^                                 | 内边距、外边距和边框都可以正常设置。     | ^^                       |
| ^^                                 | 同时具有行内盒子和块级盒子的特点。       | ^^                       |

* ② 行内块盒子可以简单理解为：外面像行内盒子，可以同行；里面像块级盒子，可以设置宽高。
* ③ 在浏览器中，可以通过查看 display 样式来确定盒子的具体分类。

::: 

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-09-30/2026-09-30-09-36-32.png)

## 1.3 盒子模型的组成

### 1.3.1 概述

* CSS 的 `盒子模型` 整体上适用于 `块级盒子`，包含了 `内容`、`内边距` 、`外边距` 以及 `边框` 。

::: details 点我查看 具体细节

* 盒子模型，如下所示：

| 盒子模型             | 描述                                                   |
| -------------------- | ------------------------------------------------------ |
| :one: 内容 content   | 显示内容的区域，由内容或指定宽度或高度来决定内容大小。 |
| :two: 内边距 padding | 内容和边框之间的距离。                                 |
| :three: 边框 border  | 包裹内容和内边距。                                     |
| :four: 外边距 margin | 盒子和其他元素之间的距离。                             |

* 元素的实际占用尺寸 = 内容尺寸 + 内边距 + 边框 。

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-09-30/2026-09-30-09-53-59.png)

### 1.3.2 边框（ border）

* 格式：

```css
boder: border-width(宽度) border-style(样式) border-color(颜色);
```

> [!NOTE]
>
> * ① 边框属性用于设置盒子边框。
> * ② 边框的三个属性必须同时存在，并且没有先后顺序之分，中间使用 `空格` 隔开。
> * ③ 边框样式，如下所示：
>
> | 边框样式 | 描述     | 视觉效果         |
> | -------- | -------- | ---------------- |
> | dotted   | 点状边框 | 圆点组成的虚线   |
> | dashed   | 虚线边框 | 短横线组成的虚线 |
> | solid    | 实线边框 | 单一线条         |
>
> * ④ 应用场景：给盒子设置四个边框或单独设置边框（使用方位名词，如：border-top、border-bottom、border-left、border-right ）。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <link rel="stylesheet" href="./style/index.css">
</head>

<body>
    
  <div class="box box1">我是box1盒子</div>
  <div class="box box2">我是box2盒子</div>
  <div class="box box3">我是box3盒子</div>
  <div class="box box4">我是box4盒子</div>
    
</body>

</html>
```

```css [index.css]
body {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

.box {
  width: 150px;
  height: 150px;
}

.box1 {
  border: 2px solid #b02179;
}

.box2 {
  border:2px dotted #b02179;
}

.box3 {
  border: 2px dashed #b02179;
}

.box4{
  border: 2px solid #d9e0ee;
  border-top: 3px solid orange;
}
```

## 1.4 圆角

* 格式：

```css
border-radius: 50px | 50% ;
```

> [!NOTE]
>
> * ① 可以通过 border-radius 设置元素的外边框为圆角，主要是因为圆角有时更好看。
> * ② 盒子或者图片都设置为圆形，如下所示：
>
> ::: details 点我查看 具体细节
>
> | 使用场景             | 描述                                                         |
> | -------------------- | ------------------------------------------------------------ |
> | :one: 盒子设置为圆角 | ![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-09-30/2026-09-30-11-59-31.png) |
> | :two: 图片设置为圆角 | ![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-09-30/2026-09-30-11-58-50.png) |
>
> :::
>
> * ③ 胶囊圆角和圆形的设置，如下所示：
>
> | 特殊场景        | 描述                               |
> | --------------- | ---------------------------------- |
> | :one:  胶囊圆角 | 长方形设置圆角为宽度或高度的一半。 |
> | :two: 圆形      | 正方形设置圆角为高度一半或者50%。  |
>
> * ④ 圆角的其他写法，如下所示：
>
> ::: details 点我查看 具体细节
>
> | 圆角写法                            | 作用                                    | 备注                                                         |
> | ----------------------------------- | --------------------------------------- | ------------------------------------------------------------ |
> | border-radius: 10px;                |                                         | border-radius: 左上角 右上角 右下角 左下角；<br>顺时针记忆 <br>中间空格隔开 <br>不需要圆角的设置为 0 即可 |
> | border-radius: 10px 20px;           | 左上、右下是10px，右上、左下 20px       | ^^                                                           |
> | border-radius ：10px 20px 30px;     | 左上是10px，右上 、左下是20px，右下30px | ^^                                                           |
> | border-radius： 10px 20px 30px 40px | 左上10px，右上20px，右下30px，左下40px  | ^^                                                           |
>
> :::
>
> * ⑤ 实际开发中，都是直接从设计稿中复制，无需记忆。



* 示例：

::: code-group

  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>

## 1.5 过渡

* 格式：

```css
/*
	过渡属性如果都要比那话，可以写 all 
    过渡时间的单位是 s ，如：0.2s 等。
*/
transition: 过渡属性 过渡时间;
```

> [!NOTE]
>
> * ① 过渡效果用在元素的属性值发生变化时，平滑地过渡，而不是瞬间切换。
> * ② 过渡的应用场景，如下所示：
>
> ::: details 点我查看 具体细节
>
> | 应用场景                       | 描述                                                         |
> | ------------------------------ | ------------------------------------------------------------ |
> | :one: 鼠标经过图片放大         | ![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-09-30/2026-09-30-12-15-15.gif) |
> | :two: 表单获取焦点，输入框变宽 | ![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-09-30/2026-09-30-12-19-24.gif) |
> 
> :::



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <link rel="stylesheet" href="./style/index.css">
</head>

<body>
    
	<div class="box"></div>
    
</body>

</html>
```

```css [index.css]
.box {
  width: 100px;
  height: 100px;
  background-color: pink;
  transition: all 0.3s;
}

.box:hover {
  width: 200px;
}
```
