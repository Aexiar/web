# 第一章：CSS3 基础知识

## 1.1 概述

* HTML 是结构，用于展现内容；而 CSS 是样式，用于设置网页的样式和布局。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-09-28/2026-09-28-17-08-39.png)

* CSS（Cascading Style Sheets，层叠样式表），是用来控制网页在浏览器中 `显示外观` 的语言。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-09-28/2026-09-28-17-05-38.png)

## 1.2 初识 CSS

* 格式：

```html
<style>
  /* 选择器 { } */
  p {
    /* CSS 属性 */
    color: red;
  }
</style>

<p>体验 CSS</p>
```

> [!NOTE]
>
> * ① 书写位置：在 title 标签的下方添加 style 标签，并在 style 标签中书写 css 代码。
> * ② css 的书写规则是：`选择器 {属性名: 值;}` 。



* 示例：

::: code-group

```html [index.html] {8-13}
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    div {
      color: red;
      font-size: 20px;
    }
  </style>
</head>

<body>
  <div>你好，CSS！！！</div>
</body>

</html>
```

## 1.3 CSS 的分类

### 1.3.1 概述

* 根据 CSS 书写位置的不同，可以将 CSS 分为三种，如下所示：

::: details 点我查看 具体细节

| CSS 分类（根据书写位置的不同） | 描述                                                         | 备注         |
| ------------------------------ | ------------------------------------------------------------ | ------------ |
| 内联样式表（行内样式表）       | 样式写到标签内部，可以控制当前标签的样式。                   | 特殊情况使用 |
| 内部样式表                     | 写到  `<style>` 标签中，脱离结构，可以控制当前页面的所有标签。 | 较为常用     |
| 外部样式表                     | 单独新建一个 css 文件，完全脱离结构，可以控制整个网站的所有标签。 | 最常用       |

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-09-28/2026-09-28-17-17-32.png)

# 第二章：CSS3 选择器

## 2.1 概述

* `CSS 选择器` 用于告诉浏览器：页面上哪些 HTML 元素需要应用接下来的样式规则。

::: details 点我查看 具体细节

* 语法：

```css
/* p 是选择器，用于选择页面中的所有 p 标签，即：选择标签 */
p {
    /* css 属性采取键值对的形式，属性名: 属性值; 即：修改样式 */
    color: red;
}
```

* CSS 选择器的作用，如下所示：

| CSS 选择器的作用       | 描述                                                         |
| ---------------------- | ------------------------------------------------------------ |
| :one: 精准定位元素     | 在复杂的 HTML 结构中，精准选中某个或某类需要修改样式的标签。 |
| :two: 样式与结构解耦   | 无需在 HTML 中直接写内联样式（`style="..."`），使网页结构（HTML）与样式外观（CSS）完全分离，便于维护。 |
| :three: 提升代码复用率 | 通过类选择器等方式，可以将同一套样式应用到多个页面元素上。   |
| :four: 动态交互表达    | 结合伪类选择器，可根据用户的操作状态（如鼠标悬停、获得焦点）或元素的结构状态自动改变样式。 |

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-09-28/2026-09-28-17-40-46.png)

## 2.2 CSS 选择器的完整分类

* 根据 W3C 规范以及日常开发，可以将 CSS 选择分为如下的六个大类：

::: details 点我查看 具体细节

| CSS 选择器的分类           | 描述                                                         |
| -------------------------- | ------------------------------------------------------------ |
| :one: 基础选择器           | 最基本、最常用的选择器类型。                                 |
| :two: 复合/分组选择器      | 将多个基础选择器组合在一起使用。                             |
| :three:关系选择器 / 组合器 | 根据元素在 DOM 树中的层级和相对位置进行选择。                |
| :four: 属性选择器          | 根据 HTML 元素的属性及其属性值来选择元素。                   |
| :five: 伪类选择器          | 以单冒号 `:` 开头，用于选择处于特定 **状态** 或 **结构位置** 的元素。 |
| :six: 伪元素选择器         | 以双冒号 `::` 开头，用于选择元素的 **特定部分** 或插入虚拟内容（非实际 DOM 节点）。 |

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-09-28/2026-09-28-17-59-31.png)

## 2.3 基础选择器（Basic Selectors）

### 2.3.1 概述

* 基础选择器是由单个选择器组成，如：元素选择器、类选择器、id 选择器、通配符选择器。

| 选择器类型               | 范例         | 说明                                | 备注   |
| ------------------------ | ------------ | ----------------------------------- | ------ |
| 元素选择器（标签选择器） | `p {}`       | 匹配指定的 HTML 标签。              |        |
| 类选择器                 | `.btn {}`    | 匹配拥有 `class="btn"` 的所有元素。 | 最常用 |
| ID 选择器                | `#header {}` | 匹配 `id="header"` 的唯一元素。     |        |
| 通配选择器               | `* {}`       | 匹配页面上的所有 HTML 元素。        |        |

### 2.3.2 元素选择器（标签选择器、类型选择器）

* 格式：

```css
p {
    ...
}
```

> [!NOTE]
>
> * ① 标签选择器使用 `标签名` 作为选择器，选中 `同名标签` 设置 `相同的样式`。
> * ② 因为 HTML 中的标签也称为元素，所以标签选择器也被称为元素选择器或类型选择器（选中的是一类标签）。
> * ③ 标签选择器 `无法差异化` 同名标签的显示效果。





* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <link rel="stylesheet" href="./style/index.css">
</head>

<body>
    
  <div>我是第1个div标签</div>
  <div>我是第2个div标签</div>
  <div>我是第3个div标签</div>

  <p>我是第1个标签</p>
  <p>我是第2个标签</p>
  <p>我是第3个标签</p>
  <p>我是第4个标签</p>
  <p>我是第5个标签</p>
    
</body>

</html>
```

```css [index.css]
div {
  color: red;
}

p {
  color: skyblue;
}
```

### 2.3.3 类选择器

* 格式：

```html
<style>
  /* 
    ① 定义类选择器的语法是：
    .类名 { ... }
  */  
  .red {
    color: red;
  }

</style>

<!-- ② 使用类选择器 class="类名1 类名2" -->
<div class="red">这是 div 标签</div>
```

> [!NOTE]
>
> * ① 类选择器，在查找标签的时候，可以 `差异化` 设置标签的显示效果，即：可以查找一个或多个标签。
> * ② 注意事项，如下所示：
>   * 类名自定义，`不要用纯数字或中文`，尽量用英文命名。
>   * 一个类选择器可以供 `多个标签` 使用。
>   * 一个标签可以使用 `多个` 类名，类名之间使用 `空格` 隔开。
>   * 类名尽量见名知意，多个单词可以使用 `-` 连接，如：`news-bd` 。



* 示例：

::: code-group

```html [index.html] {14,17,19}
<!DOCTYPE html>

<head>
  <meta charset="UTF-8">

</head>

<body>
    
  <div>我是第1个div标签</div>
  <div class="red">我是第2个div标签</div>
  <div>我是第3个div标签</div>

  <p class="red">我是第1个标签</p>
  <p>我是第2个标签</p>
  <p class="red">我是第3个标签</p>
  <p>我是第4个标签</p>
  <p>我是第5个标签</p>
    
</body>

</html>
```

```css [index.css]
.red {
  color: red;
}
```

## 2.4 复合选择器（Grouping Selectors）

### 2.4.1 概述

* 将多个基础选择器组合在一起使用。

| 选择器类型      | 范例                | 说明                                                         | 备注   |
| --------------- | ------------------- | ------------------------------------------------------------ | ------ |
| 并集/分组选择器 | `h1, h2, .title {}` | 用逗号隔开，为多个不同的选择器同时应用同一套样式。           | 最常用 |
| 交集选择器      | `p.active {}`       | 必须同时满足多个条件（既是 `<p>` 标签，又带有 `active` 类）。 |        |

### 2.4.2 并集选择器

* 格式：

```css
选择器1,选择器2, ... {
    ...
}
```

> [!NOTE]
>
> * ① 使用 `,` 号隔开，多个不同的选择器同时应用同一套样式。
> * ② 并集选择器，也称为分组选择器，因为选中多组标签设置相同样式。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <link rel="stylesheet" href="./style/index.css">
</head>

<body>
    
  <div>我是第1个div标签</div>
  <div class="box1">我是第2个div标签</div>
  <div>我是第3个div标签</div>

  <p>我是第1个标签</p>
  <p>我是第2个标签</p>
  <p class="box2">我是第3个标签</p>
  <p>我是第4个标签</p>
  <p>我是第5个标签</p>
    
</body>

</html>
```

```css [index.css]
.box1,
.box2 {
  color: red;
}
```

## 2.5 关系选择器（Combinators）

### 2.5.1 概述

* 根据元素在 DOM 树中的层次和相对位置进行选择。

| 选择器类型     | 范例         | 说明                                              | 备注   |
| -------------- | ------------ | ------------------------------------------------- | ------ |
| 后代选择器     | `div p {}`   | 匹配 `<div>` 内部 **任意层级** 的 `<p>` 元素。    | 最常用 |
| 子代选择器     | `ul > li {}` | 仅匹配 `<ul>` 的 **第一层直接子元素** `<li>`。    |        |
| 相邻兄弟选择器 | `h1 + p {}`  | 紧接在 `<h1>` **后面同层级的第一个** `<p>` 元素。 |        |
| 通用兄弟选择器 | `h1 ~ p {}`  | 位于 `<h1>` **后面同层级的所有** `<p>` 元素。     |        |

### 2.5.2 后代选择器

* 格式：

```css
选择器1 选择器2 {
    ...
}
```

> [!NOTE]
>
> * ① 选择某个元素的后代元素，不限层次，包括子元素、孙元素等。
> * ② 选择器之间使用 `空格` 隔开。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <link rel="stylesheet" href="./style/index.css">
</head>

<body>
    
  <div class="box">
    <span>我是儿子</span>
    <span>我是儿子</span>
    <p>
      <span>我是孙子</span>
    </p>
  </div>
    
</body>

</html>
```

```css [index.css]
.box span {
  background-color: pink;
}
```

### 2.5.3 子代选择器

* 格式：

```css
选择器1 > 选择器2 {
    ...
}
```

> [!NOTE]
>
> * ① 选择某个元素的直接子元素（仅限一层）。
> * ② 选择器之间使用 `>` 隔开。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">
```

## 2.6 属性选择器（Attribute Selectors）

### 2.6.1 概述

* 根据 HTML 元素的属性及其属性值来选择元素。

| 选择器类型      | 说明                                                         |
| --------------- | ------------------------------------------------------------ |
| `[attr]`        | 含有 `attr` 属性的元素，如：`[disabled]` 。                  |
| `[attr="val"]`  | `属性值` 等于 `val`，如： `type="text"`。                    |
| `[attr~="val"]` | 属性值包含用空格分隔的词列表；其中，包含 `val`。             |
| `[attr^="val"]` | 属性值以 `val` 开头。                                        |
| `[attr$="val"]` | 属性值以 `val` 结尾，如： `a[href$=".pdf"]` 匹配 PDF 链接。  |
| `[attr*="val"]` | 属性值中包含 `val` 子字符串。                                |
| `[attr|="val"]` | 属性值为 `val` 或以 `val-` 开头，常用语语言匹配，如： `lang|="en"`。 |

### 2.6.2 包含属性

## 2.7 伪类选择器（Pseudo-classes）

### 2.7.1 概述

* 以单冒号 `:` 开头，用于选择处于 `特定状态` 、 `结构位置` 或 `满足特定条件` 的元素。

::: details 点我查看 具体细节

| 伪类选择器           | 说明                                                         | 范例                                               |
| -------------------- | ------------------------------------------------------------ | -------------------------------------------------- |
| :one: 状态伪类       | 根据 **用户交互或元素当前状态** 进行选择。                   | 鼠标悬停、链接被访问、元素获得焦点等。             |
| :two: 结构伪类       | 根据元素在 **父元素中的结构位置或顺序** 进行选择。           | 选择第 5 个元素、前 3 个元素、奇数元素等。         |
| :three: 表单状态伪类 | 根据 **表单控件当前所处的状态** 进行选择。                   | 表单禁用、启用、复选框选中、输入内容是否合法等。   |
| :four: 逻辑伪类      | 根据一个或多个选择条件进行 **匹配、排除或组合判断**，用于简化复杂选择器，即：逻辑伪类 = 对其他选择器进行“组合、排除、条件判断”。 | 排除符合条件的元素、匹配多个选择器中的任意一个等。 |

### 2.7.3 结构伪类

* 格式：

```css
/* 一组兄弟元素中获取第一个元素 */

    ....
}

li:last-child {
    ....
}

/* 一组兄弟元素中获取第 n 个元素 */
li:nth-child(m) {
    ....
}
```

> [!NOTE]
>
> * ① 根据元素的位置选择目标元素。
> * ② 对于 `li:nth-child(n) {}` 中的 n 取值，如下所示：
>
> | n 的取值     | 描述                                                         |
> | ------------ | ------------------------------------------------------------ |
> | :one: 数字   | 从 1 开始。                                                  |
> | :two: 关键字 | odd 奇数；even 偶数                                          |
> | :three: 公式 | `:nth-child(3n)`  表示 3 的倍数，n 从 0 开始计算。           |
> | ^^           | `:nth-child(n+2)` 表示第 2 个以及以后的元素，n 从 0 开始计算。 |
> | ^^           | `:nth-child(-n+3)` 表示前 3 个元素，n 从 0 开始计算。        |

## 4.4 优先级

### 4.4.1 概述

* 浏览器通过优先级来判断哪些属性值和一个元素最为相关。

| 选择器类型           | 范例                             | 权重         | 优先级说明                   |
| -------------------- | -------------------------------- | ------------ | ---------------------------- |
| `!important`         | `color:red !important;`          | 无限大       | 强制覆盖所有规则（慎用）     |
| 内联样式             | `<div style="color:red;"></div>` | (1 ,0 ,0, 0) | 行内样式权重最高 1,0,0,0     |
| ID 选择器            | `#id`                            | (0 ,1 ,0, 0) | 每个 ID 增加 0,1,0,0          |
| 类、伪类             | `.class`、`[type="text"]`        | (0 ,0 ,1, 0) | 每个类或伪类增加 0,0,1,0     |
| 元素（标签）、伪元素 | `div`、`::after`                 | (0 ,0 ,0, 1) | 每个元素或伪元素增加 0,0,0,1 |
| 通配符、继承         | `*`、继承的样式                  | (0 ,0 ,0, 0) | 通配符和继承的样式最低       |

> [!NOTE]
>
> * ① 优先级相等的时候，CSS 中最后的那个声明的样式将会被应用到元素上。（层叠遵循就近原则）
> * ② 其余判断那个选择器权重高，优先执行那个样式。
> * ③  权重是 4 位一组，是分开的层级，不能进位。

### 4.4.2 权重的叠加

* 权重是可以累加的，每个选择器的层次权重相加。

::: details 点我查看 具体细节

浏览器的调试工具或 vscode 等集成了 CSS 选择器权重计算的功能，如下所示：

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-09-29/2026-09-29-21-01-15.png)

:::



* 示例：

```txt
#nav .item a 的权重是 ？

   0 1 0 0 --> id
   0 0 1 0 --> 类
+  0 0 0 1 --> 元素
-------------------
```
