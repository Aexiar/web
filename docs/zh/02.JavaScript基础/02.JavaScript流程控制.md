# 第一章：类型转换

## 1.1 概述

* 类型转换是指在运行过程中动或手动进行类型转换，以便在不同类型之间进行运行或处理。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-17/2026-10-17-19-30-14.png)

## 1.2 类型转换的分类

* JavaScript 中的类型转换，可以分为如下两类：

| 类型转换                       | 描述                                                  |
| ------------------------------ | ----------------------------------------------------- |
| :one: 自动类型转换（隐式转换） | 在特定场景下，JavaScript 会自动将值转换为合适的类型。 |
| :two: 手动类型转换（显示转换） | 通过内置方法主动进行类型转换。                        |

## 1.3 手动类型转换

### 1.3.1 概述

* 通过内置方法，主动将值转换为指定的类型。

### 1.3.2 转换为数字

#### 1.3.2.1 Number()

* 格式：

```js
Number(value?: any): number
```

> [!NOTE]
>
> * ① 如果转换成功，则返回一个数字类型。
> * ② 如果转换失败，则返回 NaN，如：数据里面包含非数字。
> * ③ 如果转换布尔类型，则 true 为 1 ，false 为 0 （不常用）。
> * ④ 如果转换 null ，则返回 0 ；如果转换 undefined ，则返回 NaN （不常用）。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <script>
    /* Number(): (value?: any) => number */
    console.log(Number(10)) // 10
    console.log(Number('12px')) // NaN
    console.log(Number(true)) // 1
    console.log(Number(false)) // 0
    console.log(Number(null)) // 0
    console.log(Number(undefined)) // NaN
  </script>


</body>

</html>
```

#### 1.3.2.2 parseInt()

* 格式：

```js
parseInt(string: string, radix?: number): number
```

> [!NOTE]
>
> * ① 如果转换成功，只保留 `整数` 。
> * ② 如果是 `数字开头` 的字符串，只保留 `整数` 数字，如：`12px` --> `12` 。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <script>
    /*  
      parseInt(string: string, radix?: number): number
    */
    console.log(parseInt('12')) // 12
    console.log(parseInt('12px')) // 12
    console.log(parseInt('12.34px')) // 12
    console.log(parseInt('12.34')) // 12
  </script>

</body>

</html>
```

#### 1.3.2.3 paseFloat()

* 格式：

```js
parseFloat(string: string): number
```

> [!NOTE]
>
> * ① 如果转换成功，只保留 `小数` 。
> * ② 如果是 `数字开头` 的字符串，只保留 `小数` 数字，如：`12.3px` --> `12.3` 。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <script>
    /* parseFloat(string: string): number */
    console.log(parseFloat('12')) // 12
    console.log(parseFloat('12px')) // 12
    console.log(parseFloat('12.34px')) // 12.34
    console.log(parseFloat('12.34')) // 12.34
  </script>

</body>

</html>
```
