* 流程控制，主要分为 `顺序结构`、`分支结构` 以及 `循环结构`，如下所示：

| 流程控制         | 描述                                                         |
| ---------------- | ------------------------------------------------------------ |
| :one: 顺序结构   | 程序从上到下逐行执行，中间没有任何判断和跳转。               |
| :two: 分支结构   | 根据条件，有选择的执行某段代码，如：if...else，switch...case。 |
| :three: 循环结构 | 根据循环条件，重复性的执行某段代码，如：while、do...while，for。 |

## 4.2 if 单分支

### 4.2.1 语法

* 格式：

```js
if(条件表达式) {
    // 语句块
}
```

> [!NOTE]
>
> * ① 小括号内的 `条件表达式` 的结果是 `布尔值` ，如下所示：
>   * 如果是 true，则进入大括号内执行 `语句块` 中的代码。
>   * 如果是 false，则不进入大括号内执行 `语句块` 中的代码。
> * ② 其执行流程图，如下所示：
>
> ```mermaid
> flowchart TD
>     A([开始]) --> B{if 条件是否成立？}
>     B -->|true| C[执行 if 语句块]
>     B -->|false| D[继续执行后面的代码]
>     C --> D
>     D --> E([结束])
> 
>     style A fill:#bbf7d0,stroke:#16a34a
>     style B fill:#fecaca,stroke:#dc2626
>     style C fill:#ddd6fe,stroke:#7c3aed
>     style D fill:#bfdbfe,stroke:#2563eb
>     style E fill:#bbf7d0,stroke:#16a34a
> ```
>
> * ③ 小括号内的 `条件表达式` 的结果不是 `布尔值` ，会进行类型转换，类似于 Boolean（不建议） 。
> * ④ 如果大括号中只有一个语句；那么，大括号可以省略（不建议）。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <script>
    if (1 == 1) {
      console.log('true')
    }
  </script>

</body>

</html>
```

### 4.2.2 综合练习

* 需求：完成心率检查的逻辑判断。

> [!NOTE]
>
> * ① 成年人心率的正常范围是每分钟 60~100 次。
> * ② 体检时，如果心率不在此范围内，则提示需要做进一步的检查。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <input type="text" placeholder="请输入您的心率">

  <script>
    /* 获取 input 元素 */
    const input = document.querySelector('input')
    /* 按回车键也算输入完成 */
    input.addEventListener('keydown', function (e) {
      if (e.key === 'Enter') {
        /* 获取输入框的值 */
        const value = e.target.value
        /* 去掉首尾空格后判断是否为空 */
        if (value.trim() === '') return
        /* 获取输入框的值并转为数字 */
        const heartBeats = Number(value)
        /* 判断心率是否在正常范围内 */
        if (heartBeats < 60 || heartBeats > 100) {
          console.warn('您的心率不在正常范围内，请做进一步的检查。')
        }
        /* 清空输入 */
        e.target.value = ''
      }
    })
  </script>

</body>

</html>
```

## 4.3 if 双分支

### 4.3.1 语法

* 格式：

```js
if(条件表达式) {
  // 语句块1;
}else {
  // 语句块2;
}
```

> [!NOTE]
>
> * ① 小括号内的 `条件表达式` 的结果是 `布尔值` ，如下所示：
>   * 如果是 true，则进入大括号内执行 `语句块1` 中的语句
>   * 如果是 false，则进入大括号内执行 `语句块2` 中的代码。
> * ② 其执行流程图，如下所示：
>
> ```mermaid
> flowchart TD
>     A([开始]) --> B{if 条件是否成立？}
>     B -->|true| C[执行 if 语句块]
>     B -->|false| D[执行 else 语句块]
>     C --> E[继续执行后面的代码]
>     D --> E
>     E --> F([结束])
> 
>     style A fill:#bbf7d0,stroke:#16a34a
>     style B fill:#fecaca,stroke:#dc2626
>     style C fill:#ddd6fe,stroke:#7c3aed
>     style D fill:#fef3c7,stroke:#d97706
>     style E fill:#bfdbfe,stroke:#2563eb
>     style F fill:#bbf7d0,stroke:#16a34a
> ```
>
> * ③ 小括号内的 `条件表达式` 的结果不是 `布尔值` ，会进行类型转换，类似于 Boolean（不建议） 。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <script>
    let num1 = 3
    let num2 = 100
    if (num1 >= num2) {
      console.log(`${num1} > ${num2}`)
    } else {

    }
  </script>

</html>
```

### 4.3.2 综合练习

* 需求：输入一个整数，要求判断其是奇数还是偶数。

> [!NOTE]
>
> * ① 获取用户输入的整数，并将其赋值给变量 num。
> * ② 如果 `num%2 == 0` ，则表示 num 是偶数；否则，num 是奇数。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <input type="text" placeholder="请输入整数">

  <script>
    /* 获取 input 元素 */
    const input = document.querySelector('input')
    /* 按回车键也算输入完成 */
    input.addEventListener('keydown', function (e) {
      if (e.key === 'Enter') {
        /* 获取输入框的值 */
        const value = e.target.value
        /* 去掉首尾空格后判断是否为空 */
        if (value.trim() === '') return
        /* 获取输入框的值并转为数字 */
        const num = Number(value)
        /* 判断是否为偶数 */
        if (num % 2 === 0) {
          console.log(`${num} 是偶数`)
        } else {
          console.log(`${num} 是奇数`)
        }
        /* 清空输入 */
        e.target.value = ''
      }
    })
  </script>

</body>

</html>
```

* 需求：判断某个年份是否为闰年？

> [!NOTE]
>
> * ① ① 获取用户输入的整数，并将其赋值给变量 num。
> * ② 如果 year 是 400 的整倍数，即：`year%400==0` ；或者，year 能被 4 整除，但不能被 100 整除，即：`year % 4 == 0 && year % 100 != 0` 。

```html [index.html]
    const input = document.querySelector('input')

      if (e.key === 'Enter') {
        /* 获取输入框的值 */
        const value = e.target.value
```

## 4.4 if 多重分支

### 4.4.1 语法

* 格式：

```js
if(条件表达式1) {
  // 语句块1;
}else if(条件表达式2) {
  // 语句块2;
} 
...
} else if (条件表达式n) {
 	// 语句块n;
} else {
  	// 语句块n+1;
}
```

> [!NOTE]
>
> * ① 首先判断 `条件表达式1` 的结果是 `真`（true）还是 `假`（false）：
>   - 如果为真，就执行 `语句块1`，然后结束当前多分支。
>   - 如果是假，就继续判断 `条件表达式2`，看其结果是真还是假。
>   - 如果是真，就执行 `语句块2`，然后结束当前多分支。
>   - 如果是假，就继续判断 `条件表达式…`，看其结果是真还是假。
>   - ...
>   - 如果没有任何关系表达式为 `真`，就执行 `语句块 n+1`，然后结束当前多分支。
> * ② 其执行流程图，如下所示：
>
> ```mermaid
> flowchart TD
>     A([开始]) --> B{条件1 是否成立?}
>     B -->|true| C[执行 if 语句块]
>     B -->|false| D{条件2 是否成立?}
> 
>     D -->|true| E[执行 else if 语句块]
>     D -->|false| F[执行 else 语句块]
> 
>     C --> G[继续执行后面的代码]
>     E --> G
>     F --> G
> 
>     G --> H([结束])
> 
>     style A fill:#bbf7d0,stroke:#16a34a
>     style B fill:#fecaca,stroke:#dc2626
>     style D fill:#fecaca,stroke:#dc2626
>     style C fill:#ddd6fe,stroke:#7c3aed
>     style E fill:#fde68a,stroke:#d97706
>     style F fill:#bfdbfe,stroke:#2563eb
>     style G fill:#c7d2fe,stroke:#4f46e5
>     style H fill:#bbf7d0,stroke:#16a34a
> ```
>
> * ③ 当 `条件表达式` 之间是 `互斥`（彼此之间没有交集）关系时，条件判断语句及执行语句间顺序无所谓。
> * ④ 当 `条件表达式`  之间是 `包含` 关系时，必须 `小上大下 / 子上父下`，否则范围小的条件表达式将不可能被执行。
> * ⑤ 当 if-else 结构是多选一的时候，最后的 else 是可选的，可以根据需要省略。
> * ⑥ 如果语句块中只有一条执行语句的时候，`{}` 是可以省略的；但是，强烈建议保留！！！



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <input type="text" placeholder="请输入您的分数">

  <script>

    /* 获取 input 元素 */
    const input = document.querySelector('input')
    /* 按回车键也算输入完成 */
    input.addEventListener('keyup', function (e) {
      if (e.key === 'Enter') {
        /* 获取输入框的值 */
        const value = e.target.value
        /* 去掉首尾空格后判断是否为空 */
        if (value.trim() === '') return
        /* 获取输入框的值并转为数字 */
        const score = Number(value)
        /* 判断分数 */
        if (score >= 90) {
          console.log('优秀')
        } else if (score >= 80) {
          console.log('良好')
        } else if (score >= 60) {
          console.log('及格')
        } else {
          console.log('不及格')
        }
        /* 清空输入 */
        e.target.value = ''
      }
    })

  </script>

</body>

</html>
```
