## 4.2 if 语句

### 4.2.1 if 单分支

#### 4.2.1.1 语法

* 格式：

```js
if(条件表达式) {
    // 语句块
}
```

> [!NOTE]
>
> * ① 小括号内的 `条件表达式` 的结果是 `布尔值` ，如下所示：
>   * 如果是 true，则进入大括号内执行 `语句块` 中的代码。
>   * 如果是 false，则不进入大括号内执行 `语句块` 中的代码。
> * ② 其执行流程图，如下所示：
>
> ```mermaid
> flowchart TD
>     A([开始]) --> B{if 条件是否成立？}
>     B -->|true| C[执行 if 语句块]
>     B -->|false| D[继续执行后面的代码]
>     C --> D
>     D --> E([结束])
> 
>     style A fill:#bbf7d0,stroke:#16a34a
>     style B fill:#fecaca,stroke:#dc2626
>     style C fill:#ddd6fe,stroke:#7c3aed
>     style D fill:#bfdbfe,stroke:#2563eb
>     style E fill:#bbf7d0,stroke:#16a34a
> ```
>
> * ③ 小括号内的 `条件表达式` 的结果不是 `布尔值` ，会进行类型转换，类似于 Boolean（不建议） 。
> * ④ 如果大括号中只有一个语句；那么，大括号可以省略（不建议）。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <script>
    if (1 == 1) {
      console.log('true')
    }
  </script>

</body>

</html>
```

* 需求：完成心率检查的逻辑判断。

> [!NOTE]
>
> * ① 成年人心率的正常范围是每分钟 60~100 次。
> * ② 体检时，如果心率不在此范围内，则提示需要做进一步的检查。

::: code-group

```html [index.html]

  <meta charset="UTF-8">

</html>
```

>     C --> E[继续执行后面的代码]
>     D --> E
>     E --> F([结束])
> 
>     style A fill:#bbf7d0,stroke:#16a34a

>     style C fill:#ddd6fe,stroke:#7c3aed
>     style D fill:#fef3c7,stroke:#d97706
>     style E fill:#bfdbfe,stroke:#2563eb
>     style F fill:#bbf7d0,stroke:#16a34a
> ```
>
> * ③ 小括号内的 `条件表达式` 的结果不是 `布尔值` ，会进行类型转换，类似于 Boolean（不建议） 。

### 4.2.3 if 多重分支

#### 4.2.3.1 语法

* 格式：

```js
if(条件表达式1) {
  // 语句块1;
}else if(条件表达式2) {
  // 语句块2;
} 
...
} else if (条件表达式n) {
 	// 语句块n;
} else {
  	// 语句块n+1;
}
```

> [!NOTE]
>
> * ① 首先判断 `条件表达式1` 的结果是 `真`（true）还是 `假`（false）：
>   - 如果为真，就执行 `语句块1`，然后结束当前多分支。
>   - 如果是假，就继续判断 `条件表达式2`，看其结果是真还是假。
>   - 如果是真，就执行 `语句块2`，然后结束当前多分支。
>   - 如果是假，就继续判断 `条件表达式…`，看其结果是真还是假。
>   - ...
>   - 如果没有任何关系表达式为 `真`，就执行 `语句块 n+1`，然后结束当前多分支。
> * ② 其执行流程图，如下所示：
>
> ```mermaid
> flowchart TD
>     A([开始]) --> B{条件 1 是否成立？}
>     B -->|true| C[执行 if 语句块]
>     B -->|false| D{条件 2 是否成立？}
> 
>     D -->|true| E[执行 else if 语句块]
>     D -->|false| F[执行 else 语句块]
> 
>     C --> G[继续执行后面的代码]
>     E --> G
>     F --> G
> 
>     G --> H([结束])
> 
>     style A fill:#bbf7d0,stroke:#16a34a
>     style B fill:#fecaca,stroke:#dc2626
>     style D fill:#fecaca,stroke:#dc2626
>     style C fill:#ddd6fe,stroke:#7c3aed
>     style E fill:#fde68a,stroke:#d97706
>     style F fill:#bfdbfe,stroke:#2563eb
>     style G fill:#c7d2fe,stroke:#4f46e5
>     style H fill:#bbf7d0,stroke:#16a34a
> ```
>
> * ③ 当 `条件表达式` 之间是 `互斥`（彼此之间没有交集）关系时，条件判断语句及执行语句间顺序无所谓。
> * ④ 当 `条件表达式`  之间是 `包含` 关系时，必须 `小上大下 / 子上父下`，否则范围小的条件表达式将不可能被执行。
> * ⑤ 当 if-else 结构是多选一的时候，最后的 else 是可选的，可以根据需要省略。
> * ⑥ 如果语句块中只有一条执行语句的时候，`{}` 是可以省略的；但是，强烈建议保留！！！



* 示例：

::: code-group

```html [index.html]

  <meta name="viewport" content="width=device-width, initial-scale=1.0">
```

## 4.3 switch 语句

### 4.3.1 语法

* 格式：

```js
switch(表达式){
	case 常量值1: 
        语句块1;
        //break;
	case 常量值2: 
        语句块2;
        //break;
	...
     
	case 常量值n: 
        语句块n; 
        //break;
	[default: 
        语句块n+1;
        //break;
    ]
}
```

> [!NOTE]
>
> - ① switch 后面表达式的值必须是一个`数值类型（数字类型）`。
> - ② case 后面的值必须是常量，不能是变量。

### 4.3.3 if 语句 vs switch 语句

#### 4.3.3.1 概述

* `if` 和 `switch` 都属于条件分支结构，用于根据不同条件决定执行哪一段代码。

> [!NOTE]
>
> 核心区别，如下所示：
>
> * ① `if`：适合判断条件是否成立，支持复杂的逻辑表达式。
> * ② `switch`：适合将同一个表达式的值与多个候选值进行匹配。

#### 4.3.3.2 if 和 switch 的区别

* if 语句和 switch 语句的区别，如下所示：

| 对比项           | if 语句                          | switch 语句                                  |
| ---------------- | -------------------------------- | -------------------------------------------- |
| 核心作用         | 根据条件是否成立执行分支         | 根据表达式的值匹配分支                       |
| 判断方式         | 判断表达式的真假                 | 使用严格相等规则 `===` 匹配 `case`           |
| 判断条件         | 可以使用比较、逻辑运算等复杂条件 | 通常匹配固定的值，也支持表达式               |
| 判断对象         | 每个分支可以判断不同变量         | 所有 `case` 与同一个 `switch` 表达式进行比较 |
| 数据类型         | 条件表达式可以产生任意类型的值   | 匹配时不进行隐式类型转换                     |
| 判断顺序         | 从上到下依次判断，满足后停止判断 | 从上到下查找首个匹配的 `case`                |
| 默认分支         | `else`                           | `default`                                    |
| 是否需要 `break` | 不需要                           | 通常需要，防止穿透                           |
| 穿透现象         | 不存在                           | 存在，未遇到 `break` 可能继续执行后续分支    |
| 适用场景         | 范围判断、复杂条件、多变量判断   | 枚举值、菜单选项、状态码匹配                 |

#### 4.3.3.3 总结

* `if` 更灵活，可以判断范围、复杂表达式以及多个变量；`switch` 更适合针对同一个表达式进行多个固定值匹配。
* 不存在必须使用 `switch` 或 `if` 的硬性要求。应该根据条件特点、代码可读性和后续维护成本选择。

```html [index.html]
      }

      // 更新循环变量

    }
```

* 格式：


## 5.5 循环嵌套（嵌套循环）

### 5.5.1 概述

* 所谓的循环嵌套（嵌套循环），是指一个循环结构 A 的循环体是另一个循环结构 B ，如下所示：

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-21/2026-10-21-16-25-36.png)

### 5.5.2 语法

* 格式：

```js
for(初始化语句①; 循环条件语句②; 迭代语句⑦) {
    for(初始化语句③; 循环条件语句④; 迭代语句⑥) {
      	循环体语句⑤;
    }
}
```

> [!NOTE]
>
> - ① 实际上，嵌套循环就是将内层循环当成外层循环的循环体。当只有内层循环的循环条件为 false ，才会完全跳出内层循环，才可结束外层的当次循环，开始下一次循环。
> - ② 假设外层循环次数为 m 次，内层循环次数为 n 次，则内层循环体实际上需要执行 m × n 次。
> - ③ 从二维图形的角度看，外层循环控制`行数`，内层循环控制`列数`。
> - ④ 实际开发中，我们最多见到的嵌套循环是两层，一般不会出现超过三层的嵌套循环。如果将要出现，一定要停下来重新梳理业务逻辑，重新思考算法的实现，控制在三层以内；否则，可读性会很差。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <script>
    for (let i = 1; i <= 5; ++i) {
      let line = ''
      for (let j = 1; j <= i; ++j) {
        line += '⭐'
      }
      console.log(line)
    }
  </script>

</body>

</html>
```
