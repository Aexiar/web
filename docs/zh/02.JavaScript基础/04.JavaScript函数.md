# 第二章：函数的基本使用

## 2.1 函数的基本组成

* 格式：

```js
function green(name){
    console.log(`你好，${name}！`)
}

greet("小明")
```

> [!NOTE]
>
> 函数的基本组成，如下所示：
>
> | 函数的组成部分 | 范例            | 描述                     |
> | -------------- | --------------- | ------------------------ |
> | function       | `function`      | 声明函数的关键字         |
> | 函数名         | `green`         | 用于识别和调用函数       |
> | 形参           | `name`          | 函数定义时声明的接收位置 |
> | 函数体         | `{...}`         | 调用后执行的代码         |
> | 实参           | `"小明"`        | 调用时提供的实际数据     |
> | 调用表达式     | `greet("小明")` | 执行函数                 |



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <script>
    /* 
      声明函数
      function 是声明函数的关键字
      add 是函数的名称
      (num1, num2) 是函数的参数列表

      { 是函数体
        return num1 + num2
      } 
    */
    function add(num1, num2) {
      return num1 + num2
    }

    /* 
      调用函数
      函数名加括号调用，括号内传入参数
    */
    console.log(add(10, 20))
    console.log(add(30, 40))
    console.log(add(40, 50))
  </script>

</body>

</html>
```

## 2.2 函数的使用步骤

* 函数的使用步骤，即：`声明函数` 和 `调用函数`，如下所示：

::: details 点我查看 具体细节

* ① `声明函数` VS `调用函数`，如下所示：

| 区别                       | 描述                                                         | 备注                                                         |
| -------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| :one: 声明函数（定义函数） | 封装 `独立` 的功能，即：`声明函数` 的过程是 `对某些功能的封装过程`。 | 在之后的开发中，我们会根据自己的需求定义很多自己的函数       |
| :two: 调用函数（函数调用） | 享受 `封装` 的结果，即：`调用函数` 是让已经存在的函数为我们所用。 | 这些函数可以是 `我们已经封装好` 的某个功能函数，也可以使用 `默认提供` 或 `第三方库提供` 的某个功能函数。 |

* ② 我们可以利用函数提高编写代码的效率以及代码的复用。

## 2.3 函数的声明

* 格式：

```js
function 函数名(形参1,形参2,...){
    // 函数体
}
```

> [!NOTE]
>
> * ① `函数名` 的 `命名规则` 和 `变量名` 的 `命名规则` 一致。
> * ② 函数名 `命名` 的时候尽量做到 `见名知意`，通常使用动词或动词短语描述操作，如： `get`、`check`、`calculate` 等。
> * ③ `函数定义` 之后里面的代码 `不会` 立即执行，函数必须 `调用` 才会执行。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <script>

    /* 声明函数 */
    function add(num1, num2) {
      return num1 + num2
    }

    /* 声明函数 */
    function printMessage() {
      console.log("欢迎学习 JavaScript！");
    }

    /* 声明函数 */
    function calculateArea(width, height) {
      return width * height;
    }

  </script>

</body>

</html>
```

## 2.4 函数的调用

* 格式：

```js
函数名(实参1,实参2,...)
```

> [!NOTE]
>
> * ① 声明（定义）的函数必须调用才会真正被执行！
> * ② 函数一次声明可以被多次调用，每一次函数调用，其函数体内的代码都会被重新执行一次。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <script>

    /* 声明函数 */
    function printMessage() {
      console.log("欢迎学习 JavaScript！");
    }
    
    /* 调用函数 */
    printMessage()
    printMessage()
    printMessage()
    printMessage()

  </script>

</body>

</html>
```

## 2.5 综合练习

### 2.5.1 综合练习一

* 需求：封装一个函数，打印两个数的和。

> [!NOTE]
>
> 🤔：这些函数只能进行打印，却不能对函数的返回值进行任何处理，不够方便！



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>
<body>
  
  <script>

    /* 声明函数：用于计算两个数的和 */
    function printAdd(num1, num2) {
      console.log(`${num1} + ${num2} = ${num1 + num2}`)
    }

    /* 调用函数 */
    printAdd(10, 20)
    printAdd(30, 40)
    printAdd(40, 50)

  </script>

</body>
</html>
```

### 2.5.2 综合练习二

* 需求：封装一个函数，打印 1-100 之间所有数的和。

> [!NOTE]
>
> 🤔：这些函数只能进行打印，却不能对函数的返回值进行任何处理，不够方便！



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <script>

    /* 声明函数：用于计算 1 - 100 之间的和 */
    function printSum(num) {
      let sum = 0;
      for (let i = 1; i <= num; i++) {
        sum += i;
      }
      console.log(`1 - ${num} 之间的和为：${sum}`);
    }

    /* 调用函数 */
    printSum(50)
    printSum(100)
  </script>

</body>

</html>
```
