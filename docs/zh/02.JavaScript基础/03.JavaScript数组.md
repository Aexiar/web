# 第一章：数组的相关概念

## 1.1 为什么需要数组？

* 数组（Array）是一种可以按顺序存储多个数据的集合，能够用一个变量管理一组数据，方便处理、遍历和操作。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-21/2026-10-21-17-46-02.png)

## 1.2 什么是数组？

### 1.2.1 数组的概念

* 数组（Array）是一组 `有序的数据集合` ，每个位置可以存放一个元素，如下所示：

```js
const ages = [18, 20, 19];
const names = ['小明', '小红', '小华'];
const mixed = [18, '小明', true, null];
```

* JavaScript 中的数组能够保存数字、字符串、布尔值等不同类型的值，并且长度可以变化。

> [!NOTE]
>
> 通常建议数组中 `元素` 是 `同种类型`，以方便统一管理和操作。

### 1.2.2 数组的基本组成

* `数组` 由 `数组名`、`下标`（索引）、`长度` 以及 `元素` 组成，如下所示：

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-22/2026-10-22-15-38-45.png)

* 假设数组是 `const scores = [78, 85, 92, 66, 89];` 这样定义的；那么，其组成如下所示：

| 名称   | 描述                        | 范例          |
| ------ | --------------------------- | ------------- |
| 数组名 | 保存数组值的变量的名称      | `scores`      |
| 元素   | 数组中保存的具体数据        | `92`          |
| 索引   | 元素所在的位置，从 `0` 开始 | `scores[2]`   |
| 长度   | 数组的 `length` 属性        | scores.length |

### 1.2.3 数组的特点

* ① 有序：数组中的元素按照索引有序排列。
* ② 索引从 0 开始：数组中的第一个元素的下标是 `0` 。
* ③ 允许重复：数组中可以出现多个相同的值。
* ④ 类型灵活：可以混合保存不同类型的值（可以，但不建议）。
* ⑤ 长度可变：添加或删除元素后长度可能变化。

### 1.2.4 数组的分类

* 按照 `嵌套层次` 可以这么理解数组，如下所示：

| 数组分类 | 范例                       | 描述                       | 备注                                                         |
| -------- | -------------------------- | -------------------------- | ------------------------------------------------------------ |
| 一维数组 | `[10, 20, 30]`             | 一排元素                   | JavaScript 没有单独的“二维数组”专用语法，通常通过 `数组嵌套数组` 来表示。<br>这里的“一维、二维、多维”是便于学习的结构称呼。 |
| 二维数组 | `[[1, 2], [3, 4]]`         | 数组里面还有数组，类似表格 | ^^                                                           |
| 三维数组 | `[[[1], [2]], [[3], [4]]]` | 多层数组嵌套               | ^^                                                           |





# 第二章：数组的操作

## 2.1 数组的创建

* 格式：

```js

```

> [!NOTE]
>
> * ① 数组是按照顺序保存每个元素的，每个元素都有其自己的编号。

## 2.3 综合练习

### 2.3.1 综合练习一

* 需求：计算数组中所有元素的和以及平均数。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <script>
    // 定义数组
    const arr = [12, 2, 31, 24, 15, 36, 67, 108, 29, 51]
    /* 定义求和变量 */
    let sum = 0;
    /* 遍历数组元素，并进行求和 */
    for (let i = 0; i < arr.length; i++) {
      sum += arr[i]
    }
    /* 获取平均数 */
    let avg = sum / arr.length
    /* 打印结果 */
    console.log(`数组中元素的和是：${sum}`)
    console.log(`数组中元素的平均数是：${avg}`)

  </script>

</body>

</html>
```

### 2.3.2 综合练习二

* 需求：计算数组的最值，即：最大值和最小值。

> [!NOTE]
>
> - ① 假设数组中的第 0 个元素是最大值或最小值，并使用变量 max 或 min 保存。
> - ② 遍历数组中的每个元素：
>   - 如果有元素比最大值还要大，就让变量 max 保存最大值。
>   - 如果有元素比最小值还要小，就让变量 min 保存最小值。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <script>
    // 定义数组
    const arr = [12, 2, 31, 24, 15, 36, 67, 108, 29, 51]
    // 定义最大值
    let max = arr[0]
    // 定义最小值
    let min = arr[0]
    // 遍历数组，以便找到最大值和最小值
    for (let i = 1; i < arr.length; i++) {
      if (arr[i] > max) {
        max = arr[i]
      }
      if (arr[i] < min) {
        min = arr[i]
      }
    }
    /* 打印结果 */
    console.log(`数组中的最大值是：${max}`)
    console.log(`数组中的最小值是：${min}`)
  </script>

</body>

</html>
```

### 3.2.4 查询

* 格式：

```js
arr[index] 
```

```js
arr.at(index)
```

> [!NOTE]
>
> * ① `arr[index] ` 语句可以获取指定索引处的元素；但是，如果该索引处没有元素，则返回 undefined。
> * ② `arr.at(index)` 语句可以获取指定索引处的元素；并且，at() 方法可以接受正数和负数；如果是负数，则从数组中的最后一个元素开始倒数。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <script>
    // 定义数组
    const arr = [12, 2, 31, 24, 15, 36, 67, 108, 29, 51]
    /* 
      数组[索引]：通过索引访问数组元素，索引从0开始；
      如果索引超出数组范围，则返回 undefined
    */
    console.log(`数组中的第一元素：${arr[0]}`)
    console.log(`数组中的最后一个元素：${arr[arr.length - 1]}`)
    console.log(`数组中的的元素：${arr[-1]}`)
    console.log(`数组中的的元素：${arr[100]}`)

    console.log('----------------')

    /* 
      数组.at(索引)
      索引支持正数、0、负数；如果索引是负数，则从数组中的最后一个元素开始倒数
    */

    console.log(`数组中的第一元素：${arr.at(0)}`)
    console.log(`数组中的最后一个元素：${arr.at(arr.length-1)}`)
    console.log(`数组中的的元素：${arr.at(-1)}`)
    console.log(`数组中的的元素：${arr.at(100)}`)

  </script>

</body>

</html>
```

### 3.2.5 组合方法

* 格式：

```js
splice(start, deleteCount, item1, item2, /* …, */ itemN)
```

> [!NOTE]
>
> * ① splice 的意思是 `剪接` 以及 `拼接` ，即：在原数组中删除、插入或替换元素，直接改变原数组（直接编辑原照片，剪掉一部分内容，或者在其中插入新内容，`原照片发生改变`）。
> * ② slice 的意思是 `切片` 或 `切下一部分` ，即：从原数组中提取并复制指定范围的元素，生成新数组，不改变原数组（从一张照片中选取某个区域，`复制出一张新图片`，原照片保持不变）。
> * ③ splice 的参数，如下所示：
>
> | spliace 参数                 | 描述                                                        |
> | ---------------------------- | ----------------------------------------------------------- |
> | start                        | 从 0 开始计算的索引，表示要开始改变数组的位置。             |
> | deleteCount                  | 一个整数，表示数组中要从 `start` 开始删除的元素数量。       |
> | ^^                           | 如果 `deleteCount` 是 `0` 或者 `负数`，则不会移除任何元素。 |
> | item1, item2, /* …, */ itemN | 从 `start` 开始要加入到数组中的元素。                       |
> | ^^                           | 如果不指定任何元素，`splice()` 将只从数组中删除元素。       |



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <script>
    // 定义数组
    const arr = ['苹果', '香蕉', '橙子', '橘子']
    /* 打印数组中的元素 */
    console.log(arr)

    console.log('----------------------')

    /* splice 可以对数组进行增删改 */

    /* 在索引为 1 的地方增加元素，后面的元素依次向后移动 */
    // arr.splice(1, 0, '葡萄')

    /* 删除索引为 1 处的元素 */
    // arr.splice(1, 1)

    /* 修改索引为 1 处的元素 */
    arr.splice(1, 1, '葡萄')

    console.log(arr)
  </script>

</body>

</html>
```

### 3.4.3 排序

* 格式：

```js
arr.sort(compareFn(a, b) )
```

> [!NOTE]
>
> * ① `arr.sort(compareFn(a, b) )` 默认排序是将元素转换为字符串，然后按照它们的 UTF-16 码元值升序排序。并且，会修改原数组
> * ② `arr.sort(compareFn(a, b) )` 可以传入排序规则进行自定义排序。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <script>
    // 定义数组
    const arr = [15, -5, 3, 0, 5, 9, 8]
    /* 打印数组中的元素 */
    console.log("arr", arr)

    console.log('----------------------')

    /* 默认是升序 */
    const newArr = arr.sort()
    console.log("arr", arr)
    console.log("newArr", newArr)

    console.log('----------------------')

    /* 也可以自定义排序规则 */
    const sortArr = arr.sort((a, b) => b - a)
    console.log("arr", arr)
    console.log("sortArr", sortArr)
  </script>

</body>

</html>
```
