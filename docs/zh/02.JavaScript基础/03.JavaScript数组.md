# 第一章：数组的相关概念

## 1.1 为什么需要数组？

* 数组（Array）是一种可以按顺序存储多个数据的集合，能够用一个变量管理一组数据，方便处理、遍历和操作。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-21/2026-10-21-17-46-02.png)

## 1.2 什么是数组？

### 1.2.1 数组的概念

* 数组（Array）是一组 `有序的数据集合` ，每个位置可以存放一个元素，如下所示：

```js
const ages = [18, 20, 19];
const names = ['小明', '小红', '小华'];
const mixed = [18, '小明', true, null];
```

* JavaScript 中的数组能够保存数字、字符串、布尔值等不同类型的值，并且长度可以变化。

> [!NOTE]
>
> 通常建议数组中 `元素` 是 `同种类型`，以方便统一管理和操作。

### 1.2.2 数组的基本组成

* `数组` 由 `数组名`、`下标`（索引）、`长度` 以及 `元素` 组成，如下所示：

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-22/2026-10-22-15-38-45.png)

* 假设数组是 `const scores = [78, 85, 92, 66, 89];` 这样定义的 ；那么，其组成如下所示：

| 名称   | 描述                        | 范例          |
| ------ | --------------------------- | ------------- |
| 数组名 | 保存数组值的变量的名称      | `scores`      |
| 元素   | 数组中保存的具体数据        | `92`          |
| 索引   | 元素所在的位置，从 `0` 开始 | `scores[2]`   |
| 长度   | 数组的 `length` 属性        | scores.length |

### 1.2.3 数组的特点

* ① 有序：数组中的元素按照索引有序排列。
* ② 索引从 0 开始：数组中的第一个元素的下标是 `0` 。
* ③ 允许重复：数组中可以出现多个相同的值。
* ④ 类型灵活：可以混合保存不同类型的值（可以，但不建议）。
* ⑤ 长度可变：添加或删除元素后长度可能变化。

### 1.2.4 数组的分类

* 按照 `嵌套层次` 可以这么理解数组，如下所示：

| 数组分类 | 范例                       | 描述                       | 备注                                                         |
| -------- | -------------------------- | -------------------------- | ------------------------------------------------------------ |
| 一维数组 | `[10, 20, 30]`             | 一排元素                   | JavaScript 没有单独的“二维数组”专用语法，通常通过`数组嵌套数组`来表示。<br>这里的“一维、二维、多维”是便于学习的结构称呼。 |
| 二维数组 | `[[1, 2], [3, 4]]`         | 数组里面还有数组，类似表格 | ^^                                                           |
| 三维数组 | `[[[1], [2]], [[3], [4]]]` | 多层数组嵌套               | ^^                                                           |





# 第二章：数组的操作

## 2.1 数组的创建

* 格式：

```js
const 数组名 = [元素1,元素2,元素3,...]
```

> [!NOTE]
>
> * ① 数组是按照顺序保存每个元素的，每个元素都有其自己的编号。
> * ② 数组中的下标（索引，编号）是从 0 开始的。
> * ③ 数组中可以存储任意类型的数据；通常建议，数组的元素的类型保存一致。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>


  <script>
    /* 创建包含数字的数组 */
    const numArr = [1, 2, 3, 4, 5]
    /* 打印数组 */
    console.log(numArr)

    /* 创建包含字符串的数组 */
    const fruitArr = ["苹果🍎", "香蕉🍌", "橘子🍊"]
    /* 打印数组 */
    console.log(fruitArr)
  </script>

</body>

</html>
```

## 2.2 数组的基本使用

### 2.2.1 访问数组元素

* 语法：

```js
数组名[索引]
```

> [!NOTE]
>
> * ① 索引通常是 `0 ~ arr.length - 1` 。
> * ② 访问不存在的索引，结果是 undefined ；不像 Java、C# 等强类型语言直接抛出索引越界异常。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>


  <script>
    /* 创建包含字符串的数组 */
    const fruitArr = ["苹果🍎", "香蕉🍌", "橘子🍊"]
    /* 访问数组元素 */
    console.log(fruitArr[0]) // 苹果🍎
    console.log(fruitArr[1]) // 香蕉🍌
    console.log(fruitArr[2]) // 橘子🍊
    console.log(fruitArr[3]) // undefined
  </script>

</body>

</html>
```

### 2.2.2 修改数组元素

* 格式：

```js
数组名[索引] = 值
```

> [!NOTE]
>
> 如果使用超过当前最后一个索引的位置，会让数组长度变大，并可能留下空槽（不建议）。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <script>
    /* 创建包含字符串的数组 */
    const fruitArr = ["苹果🍎", "香蕉🍌", "橘子🍊"]
    /* 打印数组元素 */
    console.log(fruitArr)
    /* 修改数组元素 */
    fruitArr[0] = '西瓜🍉'
    fruitArr[1] = '桃子🍑'
    fruitArr[2] = '葡萄🍇'
    /* 打印数组元素 */
    console.log(fruitArr)
  </script>

</body>

</html>
```

### 2.2.3 length 属性

* 格式：

```js
arr.length
```

> [!NOTE]
>
> * ① length 表示数组的长度，即：最大数组索引 + 1 。
> * ② 可以通过 length 属性来向数组中添加元素或遍历元素。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>


  <script>
    /* 创建包含字符串的数组 */
    const fruitArr = ["苹果🍎", "香蕉🍌", "橘子🍊"]
    /* 打印数组的长度 */
    console.log(fruitArr.length) // 3
    /* 遍历数组元素 */
    for (let i = 0; i < fruitArr.length; i++) {
      console.log(fruitArr[i])
    }
  </script>
</body>

</html>
```

## 2.3 综合练习

### 2.3.1 综合练习一

* 需求：计算数组中所有元素的和以及平均数。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <script>
    // 定义数组
    const arr = [12, 2, 31, 24, 15, 36, 67, 108, 29, 51]
    /* 定义求和变量 */
    let sum = 0;
    /* 遍历数组元素，并进行求和 */
    for (let i = 0; i < arr.length; i++) {
      sum += arr[i]
    }
    /* 获取平均数 */
    let avg = sum / arr.length
    /* 打印结果 */
    console.log(`数组中元素的和是：${sum}`)
    console.log(`数组中元素的平均数是：${avg}`)

  </script>

</body>

</html>
```
