# 第一章：为什么需要面向对象？

## 1.1 传统写法（面向过程）的问题

* 传统 `面向过程` 的写法，易造成代码分散等问题；而 `面向对象`，就是为解决这些问题而生。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-11-08/2026-11-08-20-40-30.png)

## 1.2 面向对象解决了什么问题？

* `面向对象` 让 `代码` 从 `“零散、重复、混乱”` 变得 `“高内聚、可复用、易维护、可扩展”`。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-11-08/2026-11-08-20-47-30.png)



# 第二章：引用数据类型（对象类型）

## 2.1 概述

* 之前，在学习数据类型时，我们知道 JS 中的数据类型有：`基本数据类型` 和 `引用数据类型`。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-11-08/2026-11-08-21-13-45.png)

* 在数据类型中，存在着一种特殊的数据类型，即：引用数据类型（对象数据类型）。

::: details 点我查看 具体细节

* ① 引用数据类型（对象类型）涉及到 JavaScript 的各个方面，所以掌握对象类型非常重要。
* ② 对象类型是一种存储 `键值对`（key-value）的更复杂的数据类型。

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-11-08/2026-11-08-21-16-24.png)

* 基本数据类型虽可以存储一些简单的值；然而，现实世界中的事物抽象成程序，会比较复杂。

::: details 点我查看 具体细节

* ① 一个人，有自己的 `属性`（特性），如：姓名、年龄、身高等；也有自己的一些 `行为`（动作），如：跑步、学习、工作。
* ② 一辆车，有自己的 `属性`（特性），如：颜色、重量、速度等；也有自己的一些 `行为`（动作），如：行驶等。

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-11-08/2026-11-08-21-26-18.png)

* 为了解决上述问题，我们使用一种新的数据类型来将属性和方法组织到一起，即：对象类型。

::: details 点我查看 具体细节

* ① 对象类型使用 `{...}` 来表示，里面包含的都是 `key-value` ，即：键值对。
* ② `key-value（键值对）` 对应的就是 `属性和方法`，在对象中 `函数` 被称为 `方法`。
* ③ 其中，`key` 是 `字符串`，ES6 之后可以是 Symbol 类型。
* ④ 其中，`value` 可以是 `任意类型`，如：基本数据类型和引用数据类型（函数类型、对象类型、数组类型等。）

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-11-08/2026-11-08-21-40-22.png)

## 2.2 对象的使用

### 2.2.1 概述

* `对象的使用`，无非就是 `对象的创建`、`访问对象的属性和方法`。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-11-09/2026-11-09-07-32-02.png)

### 2.2.2 创建对象

* 格式：

```js
const obj = {} // 对象字面量
```

```js
new Object() + 动态添加属性和方法 
```

```js
new 构造函数(name,age,...)| 类名(name,age,...)
```

> [!NOTE]
>
> * ① 在实际开发中，我们经常使用 `对象字面量` 的方式来创建对象；但是，其他方式后期也会使用到。
> * ② 在 `对象字面量` 的方式中，`属性` 和 `属性` 之间使用 `,` 隔开。
> * ③ 事物的 `描述信息` 称为 `属性`，如：姓名、身高、年龄、性别等，一般是 `名词`。
> * ④ 事物的 `行为` 称为 `方法`，如：跑步、唱歌等，一般是 `动词` 。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <script>
    /* 创建对象 */
    const obj = {
      name: "张三", // 属性
      age: 18, // 属性
      sing: function () { // 方法
        console.log(this.name + "在唱歌")
      }
    }
    /* 访问对象属性 */
    console.log(obj.name) // 输出: 张三
    console.log(obj.age)  // 输出: 18
    /* 调用对象方法 */
    obj.sing()           // 输出: 张三在唱歌
  </script>

</body>

</html>
```

## 2.3 操作对象

### 2.3.1 概述

* `操作对象`，无非就是对 `对象属性` 或 `对象方法 ` 的 `增删改查`。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-11-09/2026-11-09-07-30-35.png)

### 2.3.2 语法

* 格式：

```js
对象.属性 // 【查】查询对象的属性或方法
对象.属性 = xxx // 【改】 修改对象的属性或方法
对象.新属性 = xxx // 【增】 给对象增加新的属性或方法
delete 对象.属性 // 【删】删除对象的属性或方法
```

> [!NOTE]
>
> * ① 对象本质上是无序的数据集合，`操作对象` 无法就是对 `属性` 或 `方法` 的 `增删改查`。
> * ② 通常而言，`不建议在代码中删除对象的属性和方法`；并且，在 JavaScript 中的 `严格模式` 下也是禁止的。
> * ③ `修改对象` 和 `新增对象` 的语法一样，判断标准就是对象是否有该属性或方法，没有就是新增，有就是修改。
> * ④ 如果 `对象` 的 `属性名` 或 `方法名` 中包含 `-` 等特殊字符，需要使用 `""` 来包裹，并且访问需要使用 `[]` ，如：`obj['my firstName']` 。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <script>
    /* 定义对象 */  
    const obj = {
      name: "张三",
      age: 18,
      sing: function () {
        console.log(this.name + "在唱歌")
      }
    }
    /* 【查】访问对象属性 */
    let name = obj.name
    let age = obj.age
    console.log(name, age)

    console.log('----------------')

    /* 【改】修改对象属性 */
    obj.name = "李四"
    obj.age = 20
    console.log(obj.name, obj.age)

    console.log('----------------')

    /* 【增】增加对象属性 */
    obj.sex = '男'
    obj.address = '杭州'
    console.log(obj.sex, obj.address)

    console.log('----------------')

    /* 【删】删除对象属性 */
    delete obj.sex
    delete obj.address
    console.log(obj.sex, obj.address)
  </script>
</body>

</html>
```

## 2.4 遍历对象

### 2.4.1 概述

* 所谓的遍历对象，就是将 `对象` 中的 `属性名` 和 `属性值` 依次取出来。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-11-09/2026-11-09-07-28-25.png)

### 2.4.2 获取所有属性名

* 格式：

```js
Object.keys(obj:{}): string[]
```

> [!NOTE]
>
> * ① 返回一个给定对象的自身可枚举的 key 组成的数组。
> * ② 可以使用 `普通 for 循环` + `obj[key]` 来遍历对象。
> * ③ 可以使用 for...in 来简化  `普通 for 循环` + `obj[key]` 来遍历对象。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>


  <script>
    /* 
      创建一个对象
    */
    let obj = { name: '张三', age: 10, gender: '男' }
    /* 
      获取所有 key 的数组
    */
    const keyArr = Object.keys(obj)
    /* 
      使用普通 for 循环 + obj[key] 获取 key 和 value 
    */
    for (let i = 0; i < keyArr.length; i++) {
      const key = keyArr[i]
      console.log(key, obj[key])
    }
  </script>

</body>

</html>
```

# 第三章：内存分配

## 3.2 值类型

* `基本数据类型` 的 `变量` 保存的是 `值`（数据本身），且变量之间赋值时，复制的也是 `值`。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-11-09/2026-11-09-01-02-04.png)



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>
<body>
  
  <script>
    /* 
      值类型在栈中分配空间，变量中保存的是值本身。
      值类型在赋值时，会创建一个新的值，并把这个值赋给变量。
      值类型，如：number、string、boolean、null、undefined、symbol。
      一个变量的变化，通常不会影响到另一个变量。
     */

    let a = 10
    let b = a
    console.log(`a = ${a}`) // a = 10
    console.log(`b = ${b}`) // b = 10

    console.log('----------------')

    a = 20
    console.log(`a = ${a}`) // a = 20
    console.log(`b = ${b}`) // b = 10
  </script>

</body>
</html>
```

## 3.3 引用类型

* `引用数据类型` 的 `变量` 保存的是 `引用`（对象地址），且变量之间赋值时，复制的也是 `引用`。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-11-09/2026-11-09-01-05-44.png)



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <script>

    /* 
      变量类型在堆中分配空间，变量中保存的是堆中对象的引用（地址）。
      变量类型在赋值的时候，会直接把堆中对象的引用（地址）赋给变量。
      变量类型，如：object、function、array、date、regexp。
      一个变量的变化，会影响到另一个变量。 
    */

    let obj = { name: '张三', age: 10 }
    let obj2 = obj

    console.log(`obj.name = ${obj.name}`, `obj.age = ${obj.age}`)
    console.log(`obj2.name = ${obj2.name}`, `obj2.age = ${obj2.age}`)


    console.log('----------------')

    obj2.name = '李四'
    obj2.age = 20

    console.log(`obj.name = ${obj.name}`, `obj.age = ${obj.age}`)
    console.log(`obj2.name = ${obj2.name}`, `obj2.age = ${obj2.age}`)


  </script>
</body>

</html>
```

## 4.2 推演类和对象

* 在 JavaScript 中，如果我们需要创建一系列相似的对象，难道使用 `字面量` 的方式来创建？

::: details 点我查看 具体细节

* ① 游戏中创建一系列的英雄，即：英雄具备的特性是相似的，如：名字、技能、价格等；但是，具体的值又不相同。
* ② 学生系统中创建一系列的学生，即：学生都有学号、姓名、年龄等；但是，具体的值又不相同。

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-11-09/2026-11-09-11-25-16.png)

* ① 如果一个普通的函数可以被 new 操作符调用；那么，这个函数就可以称为构造函数。
* ② 构造函数被 new 操作符调用，会执行如下的步骤：
  * 在内存中创建一个新的对象，即：空对象，如：`{}`  。
  * 这个对象内部的 `[[prototype]]` 属性会被赋值为该构造函数的 prototype 属性。
  * 构造函数内部的 this，会指向创建出来的新对象。
  * 执行构造函数内部的代码，即：函数体代码。
  * 如果构造函数没有返回非空对象，则返回创建出来的新对象。

## 4.3 构造函数和类

### 4.3.1 概述

* `构造函函数` 也称为 `构造器`（constructor），通常是我们在创建对象的时候会调用的函数。
* 在其它面向对象的编程语言中，如：Java 等，构造函数是存在于类中的一个方法，和类名相同，没有返回值，并且支持参数的重载。
* 在 ES5 版本之前，`构造函数` 扮演了其它 `面向对象编程语言` 中 `类` 的角色。
* 在 ES5 版本之后，可以通过 `class` 关键字来声明一个 `类` 。

### 4.3.2 ES5 之前的版本

## 5.2 包装类型

### 5.2.1 概述

* JavaScript 是一种拥有原型类型（Primitive Types，基本数据类型）和对象类型（Objects Types，引用数据类型）的编程语言。
* 虽然原始类型，如：字符串、数字、布尔值等，本身并不是 `对象` ，也没有 `属性` 和 `方法`；但是，在日常开发中却可以调用它们的方法，如：'hello'.length，这背后的机制就是 `自动装箱`（boxing），而与其对应的逆向过程则是 `自动拆箱`（unboxing）。

### 5.2.2 自动装箱（boxing）

* 当对一个 `原始类型` 的调用属性或方法时，JavaScript 引用会在后台 `隐式的` 将这个原始值包装成对应的 `临时对象`（Wrapper Object），从而可以使得我们调用该对象的属性和方法。一旦调用完成后，这个 `临时对象` 就会被销毁。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>


  <script>
    /* 
      自动装箱：
        在某些情况下，JavaScript 会自动将值转换为对象。
        这种转换被称为装箱（boxing）。
        装箱是 JavaScript 类型系统的一部分，它允许我们使用属性和方法调用值，而无需显式转换。
    */
    const str = "hello"
    /*
      背后的远离：
       ① 引擎发现 str 是个原始字符串，却调用了 .length 
       ② 隐式创建临时包装对象：const tempObj = new String("hello")
       ③ 访问该临时对象的 length 属性
       ④ 销毁 tempObj，返回结果 5
    */
    console.log(str.length)
  </script>

</body>

</html>
```

### 5.2.3 自动拆箱（unboxing）

* 自动拆箱指的是将一个 `包装对象`，如：new String("xxx") 等，转换为其对应的 `原始类型值` 的过程。

> [!NOTE]
>
> 当 JavaScript 引擎需要将一个对象用于数学运算、字符串拼接或逻辑判断等原始环境时，它会通过内部的 `ToPrimitive` 抽象操作来完成拆箱：
>
> * ① **优先调用 `valueOf()`**：如果该方法返回原始类型，则直接使用。
> * ② **其次调用 `toString()`**：如果 `valueOf()` 返回的不是原始类型，则尝试调用 `toString()`。
> * ③ **抛出错误**：如果两者都无法返回原始类型，则抛出 `TypeError`。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <script>
    // 显式创建一个 Number 包装对象
    const numObj = new Number(10);

    // 参与加法运算时，触发自动拆箱
    console.log(numObj + 5); // 输出: 15
    // 底层过程：numObj.valueOf() 返回原始数值 10，然后进行 10 + 5
  </script>

</body>

</html>
```

### 5.4.5 综合练习

* 需求：猜数字游戏。

> [!NOTE]
>
> * ① 程序生成 [1,10] 之间的随机整数，用户输入一个数字，判断猜的是否准备。
> * ② 如果输入数字 > 随机数字，就提示：'数字猜大了，继续猜' 。
> * ③ 如果输入数字 < 随机数字，就提示：'数字小了，继续猜' 。
> * ④ 如果输入数字 > 随机数字，就提示：'猜对了，退出游戏' 。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <h2>猜数字游戏</h2>
  <p>
    程序生成的随机数是：
    <span class="tip"></span>
  </p>
  <div>
    规则：
    <ul>
      <li>1. 猜的数字必须是 1-10 之间的数字</li>
      <li>2. 每猜一次，程序会提示数字是大了还是小了</li>
      <li>3. 直到猜对为止</li>
    </ul>
  </div>
  <input type="text" placeholder="请输入猜的数字（1-10）">


  <script>
    /* 获取随机数 */
    let random = Math.floor(Math.random() * 10 + 1)
    /* 获取元素 */
    const input = document.querySelector('input')
    const tip = document.querySelector('.tip')
    /* 设置程序猜的数字到页面 */
    tip.textContent = random
    /* 添加事件监听 */
    input.addEventListener('input', function (event) {
      // 获取输入的值
      const value = event.target.value
      /* 如果输入的值为空，则不做任何处理 */
      if (value.trim() === '') {
        return
      }
      /* 猜数字逻辑 */
      while (true) {
        // 获取猜的数字
        const guess = Number(value)
        // 判断
        if (guess == random) {
          alert(`${guess} 猜对了，退出游戏`)
          break
        } else if (guess > random) {
          alert(`${guess} 猜大了，请继续`)
          break
        } else if (guess < random) {
          alert(`${guess} 猜小了，请继续`)
          break
        }
      }
      /* 清空输入框 */
      event.target.value = ''
    })
```

## 5.5 字符串类型 String

### 5.5.1 概述

* 在开发中，我们经常需要对字符串进行各种各样的操作，String 类为我们提供改了对应的 `属性` 和 `方法`。

> [!NOTE]
>
> * ① 在实际开发中，一般都是后端将数据处理好，然后前端将数据渲染到页面上；所以，对于 String 类来说，了解即可。
> * ② String 是一个类（构造函数），所以我们需要使用对象调用对应的`属性`和`方法`。

### 5.5.2 常见属性

* 格式：

```js
str.length: number // 获取字符串的长度
```



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>
<body>
  
  <script>
    /* 获取字符串的长度 */
    console.log("".length) // 0
    console.log(" ".length) // 1
    console.log("Hello World".length) // 11
  </script>

</body>
</html>
```

### 5.5.6 查找子串

* 格式：

```js
// 查找字符串中子串的位置，从 0 开始，如果没有找到返回 -1

```

```js
// 判断字符串中子串是否存在

```

```js

str.startsWith(searchString: string, position?: number): boolean
```


```html [index.html]
</head>

<body>

  <script>
    let str = "hello world"

    console.log(str.indexOf("H")) // -1

    /* 判断字符串是否以xxx结尾 */
    console.log(str.endsWith("d")) // true
    console.log(str.endsWith("D")) // false
  </script>
  
</body>

</html>
```
