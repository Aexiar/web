# 第一章：初识 JavaScript

## 1.1 概述

* JavaScript 是一种运行在 `浏览器` 中的编程语言，用于为网页添加 `交互效果` 。

::: details 点我查看 具体细节

* ① 对于客户端（浏览器）来说，JavaScript 通常被实现为一门解释语言，但如今它已经可以被 `即时编译`（JIT）。
* ② 随着 `HTML5` 和 `CSS3` 语言标准的推行，它还可以用于游戏、桌面和移动应用程序的开发，以及在服务器端网络环境运行，如：Node.js 等。

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-15/2026-10-15-19-50-24.png)

## 1.2 JavaScript 组成

* JavaScript 由 `ECMA` 和 `WEB API` （DOM + BOM）组成，如下所示：

::: details 点我查看 具体细节

* ① ECMA 规定了 JavaScript 的基础语法，如：变量、分支语句、循环语句以及对象等等。
* ② WEB API 包含了 DOM 和 BOM：
  * DOM：用来管网页内容，即：操作文档，如：对页面元素进行移动、添加删除等。
  * BOM：用来管浏览器窗口，即：操作浏览器，如：页面弹窗、检测窗口宽度等。

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-19/2026-10-19-07-31-54.png)

## 1.3 JavaScript 书写位置

### 1.3.1 概述

* 根据 JavaScript 书写位置的不同，可以将 JavaScript 分为三种，如下所示：

::: details 点我查看 具体细节

* JavaScript 的分类，如下所示：

|          JavaScript 分类          |                             描述                             |         备注         |
| :-------------------------------: | :----------------------------------------------------------: | :------------------: |
| 内联 JavaScript（行内 JavaScript） | 写在 HTML 标签的事件属性中。<br>简单直接，但不利于代码维护。 |  简单演示、临时测试  |
|          内嵌 JavaScript          | 写在 HTML 文件的 `<script>` 标签中。<br/>HTML 和 JS 位于同一个文件中 |  学习练习、小型页面  |
|          外部 JavaScript          | 写在独立的 `.js` 文件中，通过 `<script src="">` 引入。<br>结构清晰、便于复用和维护 | 实际项目开发（推荐） |

:::

### 1.3.2 行内 JavaScript

* 格式：


>

> import { ref } from 'vue'
> 
> const counter = ref(0)
> </script>
> ```

### 1.3.3 内部 JavaScript

* 格式：

```html
<script>

    console.log('你好，世界');
	
</script>
```

> [!NOTE]
>
> * ① 直接写在 HTML 文件中，使用  `<script>`  标签进行包裹。
> * ② 尽量写到 HTML 文件底部，因为浏览器会按照代码在文件中的顺序加载 HTML，除非 `<script>` 添加 `defer` 属性。
> * ③ 如果先加载的 JavaScript 期望修改其下方的 HTML，那么它可能由于 HTML 尚未被加载而失效。



* 示例：

::: code-group

```html [index.html] {29-35}
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    .btn {
      width: 250px;
      height: 50px;
      border-radius: 25px;
      border: none;
      /* 去掉边框 */
      outline: none;
      background-color: skyblue;
      /* 去掉点击时的虚线/光晕 */
      outline: none;
      cursor: pointer;
      box-shadow: 0 0 10px rgba(0, 0, 0, 0.2);
    }
  </style>
</head>

<body>

  <button class="btn">点击我</button>

  <script>
    /* 内部 JavaScript */
    const btn = document.querySelector('.btn')
    btn.addEventListener('click', () => {
      alert('按钮被点击了！')
    })
  </script>

</body>

</html>
```

## 1.4 注释 & 结束符

### 1.4.1 注释

* 格式：

```js
// 单行注释
```

```js
/* 多行注释 */
```

> [!NOTE]
>
> - ① 注释是对一段代码的解释和说明。注释是给开发者看的，浏览器并不会将注释显示给用户。
> - ② 注释的意义：
>   - 帮助我们自己理清代码的思路，方便以后进行查阅。
>   - 与别人合作开发时，添加注释，可以减少沟通成本。
>   - 开发自己的框架时，加入适当的注释，方便别人使用和学习。
>   - 可以临时注释掉一段代码，方便调试。
> - ③ 单行注释的快捷键：`Ctrl + /` ，多行注释的快捷键是： `Ctrl + Shift + /`。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>
<body>
  
  <div class="box"></div>

  <script>
    // 单行注释
    console.log('单行注释');
    /* 多行注释 */
    console.log('多行注释');
  </script>

</body>
</html>
```

```md:img [cmd 控制台]
![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-19/2026-10-19-09-21-38.png)
```

```html [index.html]
    /* 对象字面量 */
    console.log({ name: 'John', age: 30 }) // {name: 'John', age: 30} 是对象字面量

  </script>
```

# 第二章：变量 & 常量

## 2.1 变量

### 2.1.1 概述

* `变量` 是程序中用于 `存储数据` 和 `管理数据` 的 `容器`，如下所示：

::: details 点我查看 具体细节

开发者可以通过变量保存数字、字符串、布尔值等数据，并在程序运行过程中读取或修改这些数据。

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-16/2026-10-16-08-07-40.png)

### 2.1.2 基本使用

* 格式：

```js
/* 定义变量（声明之后，再赋值） */
let 变量名; // 声明变量
变量名 = 值; // 给变量赋值

/* 定义变量（声明并赋值） */
let 变量名 = 值; 
```

```js
/* 使用变量 */
console.log(变量名);
```

> [!NOTE]
>
> * ① 变量需要遵循先定义后使用的原则。
> * ③ 变量的命名规则，如下所示：
>   * 可以包含字母、数字、下划线 `_` 和美元符号 `$`；并且，不能以数字开头。
>   * 区分大小写，如： `age` 和 `Age` 是不同变量。
>   * 不能使用 `let`、`const` 等保留关键字作为变量名。
>   * 推荐使用小驼峰命名法，如： `userName`、`totalPrice`。
> * ③ let 关键字具有块级作用域，适用于需要修改的变量。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>
<body>
  
  <script>
    // 变量的定义
    let name = '张三';

    // 变量的修改
    name = '李四';

    // 变量的使用
    console.log(name);
  </script>

</body>
</html>
```

## 2.2 常量

### 2.2.1 概述

* `常量` 是程序中 `不能重新赋值` 的 `数据容器` （仅针对基本数据类型），如下所示：

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-16/2026-10-16-09-11-07.png)

### 2.2.2 基本使用

* 格式：

```js
/* 定义常量 */
const 常量名 = 值;
```

```js
/* 使用常量 */
console.log(常量名);
```

> [!NOTE]
>
> * ① 对于值是 `基本数据类型` 的常量而言，一旦赋值，不可以再次重新赋予新的值。
> * ② 对于值是 `数组或对象类型` 的常量而言，虽然不可以重新赋予新的数据或对象（引用地址不可变）；但是，对象或数组的内部内容依然可以修改。
> * ③ `常量名` 建议 `大写`，如果由多个字母组成，建议使用 `_` 隔开，如：`MAX_VALUE` 。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <script>

    // 定义基本数据类型的常量
    const PI = 3.14

    // 不可以给基本数据类型的常量再次赋值
    // PI = 3.1415926 

    // 输出常量
    console.log('PI', PI)

  </script>

</body>

</html>
```

# 第三章：数据类型

## 3.2 数值类型（数字类型）

* 格式：

```js
let num = 10
```

## 5.4 自动类型转换

### 5.4.1 概述

* 在特定的运算或比较场景中，JavaScript 会自动进行类型转换。

> [!CAUTION]
>
> 自动类型转换的规则比较复杂，在生产环境中尽量使用显示转换，以避免 `隐式转换` 带来的意外结果。

### 5.4.2 转换为数字类型

* 算术运算符，如：`-`、`*`、`/`、`%`  等，可以将 `字符串` 隐式转换为 `数字` 类型。
* 比较运算符，如：`>`、`==` 等，可以将 `字符串` 隐式转换为 `数字` 类型。
* `+` 作为 `正号` 可以将 `字符串` 隐式转换为 `数字` 类型。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <script>
    // 1. 隐式转换为数字型的运算符
    // 1.1 算术运算符 - *  /   比较运算符  >   ==
    console.log(8 - '3') // 5
    console.log('1999' * '2') //  3998
    console.log(3 > '1')   // true
    console.log(3 == '3')  // true

    // 1.2 + 正号使用的时候，也会把字符串转换为 数字型
    console.log('123')  // '123'
    console.log(+'123')  // 123
    console.log(typeof +'123')  // number
  </script>

</body>

</html>
```

### 5.4.3 转换为字符串

* 当 `+` 运算符的一侧是字符串时，通常会触发字符串拼接，并将另一侧的值转换为字符串。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <script>
    /* 
      隐式转换为字符串型的运算符：
        + 拼接字符串 两侧只要有一个是字符串，结果就是字符串 
    */
    console.log('呵呵' + 18) // '呵呵 18'
    console.log('' + 18)  // '18'
  </script>

</body>

</html>
```
