# 第一章：初识 JavaScript

## 1.1 概述

* JavaScript 是一种运行在 `浏览器` 中的编程语言，用于为网页添加 `交互效果` 。

::: details 点我查看 具体细节

* ① 对于客户端（浏览器）来说，JavaScript 通常被实现为一门解释语言，但如今它已经可以被 `即时编译`（JIT）。
* ② 随着 `HTML5` 和 `CSS3` 语言标准的推行，它还可以用于游戏、桌面和移动应用程序的开发，以及在服务器端网络环境运行，如：Node.js 等。

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-15/2026-10-15-19-50-24.png)

## 1.2 JavaScript 的分类

### 1.2.1 概述

* 根据 JavaScript 书写位置的不同，可以将 JavaScript 分为三种，如下所示：

::: details 点我查看 具体细节

* JavaScript 的分类，如下所示：

|          JavaScript 分类          |                             描述                             |         备注         |
| :-------------------------------: | :----------------------------------------------------------: | :------------------: |
| 内联 JavaScript（行内 JavaScript） | 写在 HTML 标签的事件属性中。<br>简单直接，但不利于代码维护。 |  简单演示、临时测试  |
|          内嵌 JavaScript          | 写在 HTML 文件的 `<script>` 标签中。<br/>HTML 和 JS 位于同一个文件中 |  学习练习、小型页面  |
|          外部 JavaScript          | 写在独立的 `.js` 文件中，通过 `<script src="">` 引入。<br>结构清晰、便于复用和维护 | 实际项目开发（推荐） |

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-15/2026-10-15-19-59-29.png)

### 1.2.2 行内 JavaScript

* 格式：

```html
<button onclick="alert('如果你敢碰我，就嫁给你');">点我一下</button>
```

> [!NOTE]
>
> * ① 直接写到标签的属性中，如：onclick。
> * ② 此处仅作为了解；但是，后面的 Vue 框架会使用这种方式。



* 示例：

::: code-group

```html [index.html] {28}
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    .btn {
      width: 250px;
      height: 50px;
      border-radius: 25px;
      border: none;
      /* 去掉边框 */
      outline: none;
      background-color: skyblue;
      /* 去掉点击时的虚线/光晕 */
      outline: none;
      cursor: pointer;
      box-shadow: 0 0 10px rgba(0, 0, 0, 0.2);
    }
  </style>
</head>

<body>
    
  <!-- 行内JavaScript -->
  <button onclick="alert('按钮被点击了！')" class="btn">点击我</button>

</body>

</html>
```

### 1.2.3 内部 JavaScript

* 格式：

```html
<script>

    console.log('你好，世界');
	
</script>
```

> [!NOTE]
>
> * ① 直接写在 HTML 文件中，使用  `<script>`  标签进行包裹。
> * ② 尽量写到 HTML 文件底部，因为浏览器会按照代码在文件中的顺序加载 HTML，除非 `<script>` 添加 `defer` 属性。
> * ③ 如果先加载的 JavaScript 期望修改其下方的 HTML，那么它可能由于 HTML 尚未被加载而失效。



* 示例：

::: code-group

```html [index.html] {29-35}
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    .btn {
      width: 250px;
      height: 50px;
      border-radius: 25px;
      border: none;
      /* 去掉边框 */
      outline: none;
      background-color: skyblue;
      /* 去掉点击时的虚线/光晕 */
      outline: none;
      cursor: pointer;
      box-shadow: 0 0 10px rgba(0, 0, 0, 0.2);
    }
  </style>
</head>

<body>

  <button class="btn">点击我</button>

  <script>
    /* 内部JavaScript */
    const btn = document.querySelector('.btn')
    btn.addEventListener('click', () => {
      alert('按钮被点击了！')
    })
  </script>

</body>

</html>
```

### 1.2.4 外部 JavaScript

* 格式：

::: code-group

```html

```

```js
console.log('你好，世界');
```

:::

>
> * ① 单独建立一个以 .js 结尾的文件，里面存放所有的 JavaScript 代码。
> * ②  `<script src="./xxx.js"></script>` 标签中间无需写代码；否则，将会被忽略！ 



* 示例：

::: code-group

```html [index.html] {31}
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    .btn {
      width: 250px;
      height: 50px;
      border-radius: 25px;
      border: none;

      outline: none;

      outline: none;
      cursor: pointer;
      box-shadow: 0 0 10px rgba(0, 0, 0, 0.2);
    }
  </style>

</head>

<body>

  <button class="btn">点击我</button>
    
  <!-- 外部JavaScript -->
  <script src="./js/index.js"></script>

</body>

</html>
```

## 1.3 注释 & 结束符

### 1.3.1 注释

* 格式：

```js
// 单行注释
```

```js
/* 多行注释 */
```

> [!NOTE]
>
> - ① 注释是对一段代码的解释和说明。注释是给开发者看的，浏览器并不会将注释显示给用户。
> - ② 注释的意义：
>   - 帮助我们自己理清代码的思路，方便以后进行查阅。
>   - 与别人合作开发时，添加注释，可以减少沟通成本。
>   - 开发自己的框架时，加入适当的注释，方便别人使用和学习。
>   - 可以临时注释掉一段代码，方便调试。
> - ③ 单行注释的快捷键：`Ctrl + /`  。
> - ④ 多行注释的快捷键是： `Ctrl + Shift + /` 。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>
<body>
  
  <div class="box"></div>

  <script>
    // 单行注释
    console.log('单行注释');
    /* 多行注释 */
    console.log('多行注释');
  </script>

</body>
</html>
```

### 1.3.2 结束符

* 格式：

```js
console.log('你好，世界')
console.log('你好，世界');
```

> [!NOTE]
>
> * ① 在 JavaScript 中，可以使用 `;` 作为语句的结束符。
> * ② 在实际开发中，对于 JavaScript 中的结束符 `;` 可写可不写，因为 JavaScript 引擎可以自动推断语句的结束位置。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>
<body>
  
  <script>
    /* 有结束符 */
    console.log('Hello World!');
    /* 没有结束符 */
    console.log('Hello World!')
  </script>

</body>
</html>
```

## 1.4 输入 & 输出（了解）

### 1.4.1 概述

* JavaScript 能接收用户输入的数据，对其进行计算、判断、转换等处理，并将结果输出给用户。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-16/2026-10-16-07-21-51.png)

### 1.4.2 输出语句

* 格式：

```js
/* 不常用 */
alert('页面弹出警告框');
```

```js
/* 不常用：在 body 标签内输出内容，如果输出的内容是 HTML 元素，也会被解析 */
document.write('向页面文档输出内容');
```

```js
/* 最常用，控制台输出，供程序员进行调试 */
console.log('控制台输出内容');
```



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <script>

    /* 输出语句, 输出到控制台 */
    console.log('Hello World!');

  </script>

</body>

</html>
```

### 1.4.3 输入语句

* 格式：

```js
prompt('请输入 xxx ');
```

> [!NOTE]
>
> * ① prompt() 用来显示一个对话框，对话框中包含文字信息，用来提示用户输入信息。
> * ② 在实际开发中，并不会使用 prompt() ，因为其不太方便 CSS 对其进行定制或美化。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>


  <script>
    /* 提醒用户输入姓名和年龄 */

    /* 在 IDE 内置浏览器或部分沙盒化容器中，底层没有实现 prompt() 接口 */
    const name = prompt('请输入你的名字:');
    const age = prompt('请输入你的年龄:');

    // 将用户输入的信息输出到控制台
    console.log(name);
    console.log(age);

  </script>

</body>

</html>
```

# 第二章：变量 & 常量

## 2.1 变量

### 2.1.1 概述

* `变量` 是程序中用于 `存储数据` 和 `管理数据` 的 `容器`，如下所示：

::: details 点我查看 具体细节

开发者可以通过变量保存数字、字符串、布尔值等数据，并在程序运行过程中读取或修改这些数据。

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-16/2026-10-16-08-07-40.png)

### 2.1.2 变量的基本使用

* 格式：

```js
/* 定义变量（声明之后，再赋值） */
let 变量名; // 声明变量
变量名 = 值; // 给变量赋值

/* 定义变量（声明并赋值） */
let 变量名 = 值; 
```

```js
/* 使用变量 */
console.log(变量名);
```

> [!NOTE]
>
> * ① 变量需要遵循先定义后使用的原则。
> * ③ 变量的命名规则，如下所示：
>   * 可以包含字母、数字、下划线 `_` 和美元符号 `$`。
>   * 不能以数字开头。
>   * 区分大小写，如： `age` 和 `Age` 是不同变量。
>   * 不能使用 `let`、`const` 等保留关键字作为变量名。
>   * 推荐使用小驼峰命名法，如： `userName`、`totalPrice`。
>
> * ③ let 关键字具有块级作用域，适用于需要修改的变量。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>
<body>
  
  <script>
    // 变量的定义
    let name = '张三';

    // 变量的修改
    name = '李四';

    // 变量的使用
    console.log(name);
  </script>

</body>
</html>
```

### 2.1.3 综合练习

* 需求：交换两个变量的值。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-16/2026-10-16-08-25-02.gif)



* 示例：

::: code-group

```html [index.html] {69-71}
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    body {
      display: grid;
      height: 80vh;
      grid-template-columns: 1fr 1fr;
      justify-items: center;
      align-items: center;
    }

    .box {
      width: 200px;
      height: 200px;
      background-color: pink;
      text-align: center;
      line-height: 200px;
      font-size: 30px;
      transition: all 0.5s;
    }

    .box2 {
      background-color: aqua;
    }

    .btn {
      grid-column: 1 / 3;
      width: 250px;
      height: 50px;
      border-radius: 25px;
      border: none;
      /* 去掉边框 */
      outline: none;
      background-color: skyblue;
      /* 去掉点击时的虚线/光晕 */
      outline: none;
      cursor: pointer;
      box-shadow: 0 0 10px rgba(0, 0, 0, 0.2);
      text-align: center;
      line-height: 50px;
      color: white;
    }
  </style>
</head>

<body>

  <div class="box box1">5</div>
  <div class="box box2">10</div>


  <button class="btn">点我进行交换</button>


  <script>
    let box1 = document.querySelector('.box1');
    let box2 = document.querySelector('.box2');
    let btn = document.querySelector('.btn');

    btn.addEventListener('click', function () {
      let num1 = box1.innerHTML;
      let num2 = box2.innerHTML;

      let temp = num1;
      num1 = num2;
      num2 = temp;
      
      box1.innerHTML = num1;
      box2.innerHTML = num2;

    })
  </script>

</body>

</html>
```
