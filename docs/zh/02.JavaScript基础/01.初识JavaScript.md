# 第一章：初识 JavaScript

## 1.1 概述

* JavaScript 是一种运行在 `浏览器` 中的编程语言，用于为网页添加 `交互效果` 。

::: details 点我查看 具体细节

* ① 对于客户端（浏览器）来说，JavaScript 通常被实现为一门解释语言，但如今它已经可以被 `即时编译`（JIT）。
* ② 随着 `HTML5` 和 `CSS3` 语言标准的推行，它还可以用于游戏、桌面和移动应用程序的开发，以及在服务器端网络环境运行，如：Node.js 等。

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-15/2026-10-15-19-50-24.png)

## 1.2 JavaScript 组成

* JavaScript 由 `ECMA` 和 `WEB API` （DOM + BOM）组成，如下所示：

::: details 点我查看 具体细节

* ① ECMA 规定了 JavaScript 的基础语法，如：变量、分支语句、循环语句以及对象等等。
* ② WEB API 包含了 DOM 和 BOM：
  * DOM：用来管网页内容，即：操作文档，如：对页面元素进行移动、添加删除等。
  * BOM：用来管浏览器窗口，即：操作浏览器，如：页面弹窗、检测窗口宽度等。

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-19/2026-10-19-07-31-54.png)

## 1.3 JavaScript 书写位置

### 1.3.1 概述

* 根据 JavaScript 书写位置的不同，可以将 JavaScript 分为三种，如下所示：

::: details 点我查看 具体细节

* JavaScript 的分类，如下所示：

|          JavaScript 分类          |                             描述                             |         备注         |
| :-------------------------------: | :----------------------------------------------------------: | :------------------: |
| 内联 JavaScript（行内 JavaScript） | 写在 HTML 标签的事件属性中。<br>简单直接，但不利于代码维护。 |  简单演示、临时测试  |
|          内嵌 JavaScript          | 写在 HTML 文件的 `<script>` 标签中。<br/>HTML 和 JS 位于同一个文件中 |  学习练习、小型页面  |
|          外部 JavaScript          | 写在独立的 `.js` 文件中，通过 `<script src="">` 引入。<br>结构清晰、便于复用和维护 | 实际项目开发（推荐） |

:::

### 1.3.2 行内 JavaScript

* 格式：

```html

```

>
> * ① 直接写到标签的属性中，如：onclick。
> * ② 此处仅作为了解；但是，后面的 Vue 框架会使用这种方式。

### 1.3.3 内部 JavaScript

* 格式：

```html
<script>

    console.log('你好，世界');
	
</script>
```

> [!NOTE]
>
> * ① 直接写在 HTML 文件中，使用  `<script>`  标签进行包裹。
> * ② 尽量写到 HTML 文件底部，因为浏览器会按照代码在文件中的顺序加载 HTML，除非 `<script>` 添加 `defer` 属性。
> * ③ 如果先加载的 JavaScript 期望修改其下方的 HTML，那么它可能由于 HTML 尚未被加载而失效。



* 示例：

::: code-group

```html [index.html] {29-35}
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    .btn {
      width: 250px;
      height: 50px;
      border-radius: 25px;
      border: none;
      /* 去掉边框 */
      outline: none;
      background-color: skyblue;
      /* 去掉点击时的虚线/光晕 */
      outline: none;
      cursor: pointer;
      box-shadow: 0 0 10px rgba(0, 0, 0, 0.2);
    }
  </style>
</head>

<body>

  <button class="btn">点击我</button>

  <script>
    /* 内部JavaScript */
    const btn = document.querySelector('.btn')
    btn.addEventListener('click', () => {
      alert('按钮被点击了！')
    })
  </script>

</body>

</html>
```

## 1.4 注释 & 结束符

### 1.4.1 注释

* 格式：

```js
// 单行注释
```

```js
/* 多行注释 */
```

> [!NOTE]
>
> - ① 注释是对一段代码的解释和说明。注释是给开发者看的，浏览器并不会将注释显示给用户。
> - ② 注释的意义：
>   - 帮助我们自己理清代码的思路，方便以后进行查阅。
>   - 与别人合作开发时，添加注释，可以减少沟通成本。
>   - 开发自己的框架时，加入适当的注释，方便别人使用和学习。
>   - 可以临时注释掉一段代码，方便调试。
> - ③ 单行注释的快捷键：`Ctrl + /`  。
> - ④ 多行注释的快捷键是： `Ctrl + Shift + /` 。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>
<body>
  
  <div class="box"></div>

  <script>
    // 单行注释
    console.log('单行注释');
    /* 多行注释 */
    console.log('多行注释');
  </script>

</body>
</html>
```

# 第二章：变量 & 常量

## 2.1 变量

### 2.1.1 概述

* `变量` 是程序中用于 `存储数据` 和 `管理数据` 的 `容器`，如下所示：

::: details 点我查看 具体细节

开发者可以通过变量保存数字、字符串、布尔值等数据，并在程序运行过程中读取或修改这些数据。

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-16/2026-10-16-08-07-40.png)

### 2.1.2 基本使用

* 格式：

```js
/* 定义变量（声明之后，再赋值） */
let 变量名; // 声明变量
变量名 = 值; // 给变量赋值

/* 定义变量（声明并赋值） */
let 变量名 = 值; 
```

```js
/* 使用变量 */
console.log(变量名);
```

> [!NOTE]
>
> * ① 变量需要遵循先定义后使用的原则。
> * ③ 变量的命名规则，如下所示：
>   * 可以包含字母、数字、下划线 `_` 和美元符号 `$`；并且，不能以数字开头。
>   * 区分大小写，如： `age` 和 `Age` 是不同变量。
>   * 不能使用 `let`、`const` 等保留关键字作为变量名。
>   * 推荐使用小驼峰命名法，如： `userName`、`totalPrice`。
> * ③ let 关键字具有块级作用域，适用于需要修改的变量。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>
<body>
  
  <script>
    // 变量的定义
    let name = '张三';

    // 变量的修改
    name = '李四';

    // 变量的使用
    console.log(name);
  </script>

</body>
</html>
```

## 2.2 常量

### 2.2.1 概述

* `常量` 是程序中 `不能重新赋值` 的 `数据容器` （仅针对基本数据类型），如下所示：

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-16/2026-10-16-09-11-07.png)

### 2.2.2 基本使用

* 格式：

```js
/* 定义常量 */
const 常量名 = 值;
```

```js
/* 使用常量 */
console.log(常量名);
```

> [!NOTE]
>
> * ① 对于值是 `基本数据类型` 的常量而言，一旦赋值，不可以再次重新赋予新的值。
> * ② 对于值是 `数组或对象类型` 的常量而言，虽然不可以重新赋予新的数据或对象（引用地址不可变）；但是，对象或数组的内部内容依然可以修改。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <script>

    // 定义基本数据类型的常量
    const PI = 3.14

    // 不可以给基本数据类型的常量再次赋值
    // PI = 3.1415926 

    // 输出常量
    console.log('PI', PI)

  </script>

</body>

</html>
```

# 第三章：数据类型

## 3.1 概述

* `数据类型` 决定 `变量` 中 `保存的值是什么样子`，如下所示：

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-16/2026-10-16-09-25-53.png)

## 3.2 数值类型（数字类型）

* 格式：

```js
let num = 10
```

> [!NOTE]
>
> * ① 数值类型可以用于运算等操作，如：对数字的 `+`、`-`、`×` 、`÷` 等。
> * ② JavaScript 是动态语言，并没有像 Java 一样将 `数值` 严格区分 `整数类型` 或 `浮点数类型`。
> * ③ 在 JavaScript 中，`浮点数` 或 `整数` 统一被称为 `数值类型`（数字类型）。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <script>
    let num = 10
    console.log('num = ', num) // num =  10
    console.log('typeof num = ', typeof num) // typeof num = number

    let num2 = 3.14
    console.log('num2 = ', num2) // num2 =  3.14
    console.log('typeof num2 = ', typeof num2) // typeof num2 =  number
  </script>

</body>

</html>
```

## 3.3 字符串类型

* 格式：

```js
let str = 'xxx' | "xxx" | `abc${变量}bcd`
```

> [!NOTE]
>
> * ① `字符串` 就是被 `引号`（`单引号`、`双引号` 或 `反引号`）包裹的一段文字信息。
> * ② `单引号` 和 `双引号` 没有本质上的区别，推荐使用 `单引号` 。
> * ③ `单引号` 和 `双引号` 可以互相嵌套；但是，不可以自己嵌套自己，即：`外双内单` 或 `外单内双` 。
> * ④ 使用 `反引号` 和 `模板字符串` 可以解决 `字符串拼接` 问题。



* 示例：

::: code-group

```html [index.html]

  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <script>
    // 字符串类型，单引号、双引号或反引号都可以
    let str = '你好啊'
    console.log('str', str)
    console.log('typeof str', typeof str)

    let str2 = "你好啊"
    console.log('str2', str2)
    console.log('typeof str2', typeof str2)

    let str3 = `你好啊`
    console.log('str3', str3)
    console.log('typeof str3', typeof str3)

    // 反引号 + 模板字符串，可以解决字符串拼接的问题
    let name = 'zs'
    let age = 18
    let msg = `${name}今年${age}岁了`
    console.log('msg', msg)
    console.log('typeof msg', typeof msg)
  </script>

</body>

</html>
```

## 4.4 比较运算符

* 格式：

```js

```

> [!NOTE]
>
> * ① `比较运算符`（关系运算符）用于比较两个值的 `大小` 或 `相等`，其结果是 `true` 或 `false` 。
> * ② 如果需要比较 `相等` 或 `不相等`，推荐使用 `===` 或 `-==`，因为会同时比较值和类型，更加严格！

```html [index.html]
    /* 比较运算符 */
    let num1 = 10
    let num2 = 20
    console.log('num1 > num2 = ', num1 > num2) // false
    console.log('num1 < num2 = ', num1 < num2)  // true
    console.log('num1 >= num2 = ', num1 >= num2) // false
    console.log('num1 <= num2 = ', num1 <= num2) // true

    console.log('num1 != num2 = ', num1 != num2)  // true

    console.log('num === str = ', num === str) // false

  </script>

</html>
```

## 4.5 逻辑运算符

* 格式：


> [!NOTE]
>
> * ① `逻辑运算符`用于进行 `逻辑判断`，通常用于条件判断，让程序做出不同的选择。
> * ② 逻辑运算符的特点，如下所示：
>
> | 逻辑运算符  | 特点                                           | 描述     |
> | ----------- | ---------------------------------------------- | -------- |
> | :one: `&&`  | 两边为 true ，结果才是 true（一假则假）        | 与运算符 |
> | :two: `||`  | 一边为 true，结果就是 true（一真则真）         | 或运算符 |

```html [index.html]
</head>
<body>
  
  <script>
    /* 逻辑运算符 */
    let a = true;
    let b = false;
    
    console.log(a && b); // 逻辑与
    console.log(a || b); // 逻辑或
    console.log(!a);     // 逻辑非
  </script>
```

## 4.6 运算符优先级

* 运算符的优先级，如下所示：

| 优先级 | 顺序                      |
| :----- | :------------------------ |
| 1      | `()`                      |
| 2      | `++` `--` `!`             |
| 3      | 先 `*` `/` `%` 后 `+` `-` |
| 4      | `>` `>=` `<` `<=`         |
| 5      | `==` `!=` `===` `!==`     |
| 6      | 先 `&&` 后 `||`           |
| 7      | `=`                       |

> [!NOTE]
>
> 实际开发中，如果不确定优先级，请添加 `()` ！



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <script>
    /* 
      一个年份如果是闰年，必须满足以下两个条件之一:
      1. 年份能被4整除但不能被100整除，如：2024、2028
      2. 年份能被400整除，如：2000（1900、2100 不是闰年）
    */
    let year = 2024
    // let year = 2028
    // let year = 2000
    // let year = 1900
    // let year = 2100
    if ((year % 4 == 0 && year % 100 != 0)
      || (year % 400 == 0)) {
      console.log(`${year}是闰年`)
    }
    else {
      console.log(`${year}不是闰年`)
    }


  </script>
</body>

</html>
```
