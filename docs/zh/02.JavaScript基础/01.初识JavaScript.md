# 第一章：初识 JavaScript

## 1.1 概述

* JavaScript 是一种运行在 `浏览器` 中的编程语言，用于为网页添加 `交互效果` 。

::: details 点我查看 具体细节

* ① 对于客户端（浏览器）来说，JavaScript 通常被实现为一门解释语言，但如今它已经可以被 `即时编译`（JIT）。
* ② 随着 `HTML5` 和 `CSS3` 语言标准的推行，它还可以用于游戏、桌面和移动应用程序的开发，以及在服务器端网络环境运行，如：Node.js 等。

:::

## 1.2 JavaScript 的分类

### 1.2.1 概述

* 根据 JavaScript 书写位置的不同，可以将 JavaScript 分为三种，如下所示：

::: details 点我查看 具体细节

* JavaScript 的分类，如下所示：

|          JavaScript 分类          |                             描述                             |         备注         |
| :-------------------------------: | :----------------------------------------------------------: | :------------------: |
| 内联 JavaScript（行内 JavaScript） | 写在 HTML 标签的事件属性中。<br>简单直接，但不利于代码维护。 |  简单演示、临时测试  |
|          内嵌 JavaScript          | 写在 HTML 文件的 `<script>` 标签中。<br/>HTML 和 JS 位于同一个文件中 |  学习练习、小型页面  |
|          外部 JavaScript          | 写在独立的 `.js` 文件中，通过 `<script src="">` 引入。<br>结构清晰、便于复用和维护 | 实际项目开发（推荐） |

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-10-15/2026-10-15-19-59-29.png)

### 1.2.2 行内 JavaScript

* 格式：

```html
<button onclick="alert('如果你敢碰我，就嫁给你');">点我一下</button>
```

> [!NOTE]
>
> * ① 直接写到标签的属性中，如：onclick。
> * ② 此处仅作为了解；但是，后面的 Vue 框架会使用这种方式。



* 示例：

::: code-group

```html [index.html] {28}
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    .btn {
      width: 250px;
      height: 50px;
      border-radius: 25px;
      border: none;
      /* 去掉边框 */
      outline: none;
      background-color: skyblue;
      /* 去掉点击时的虚线/光晕 */
      outline: none;
      cursor: pointer;
      box-shadow: 0 0 10px rgba(0, 0, 0, 0.2);
    }
  </style>
</head>

<body>
    
  <!-- 行内JavaScript -->
  <button onclick="alert('按钮被点击了！')" class="btn">点击我</button>

</body>

</html>
```

### 1.2.3 内部 JavaScript

* 格式：

```html
<script>

    console.log('你好，世界');
	
</script>
```

> [!NOTE]
>
> * ① 直接写在 HTML 文件中，使用  `<script>`  标签进行包裹。
> * ② 尽量写到 HTML 文件底部，因为浏览器会按照代码在文件中的顺序加载 HTML，除非 `<script>` 添加 `defer` 属性。
> * ③ 如果先加载的 JavaScript 期望修改其下方的 HTML，那么它可能由于 HTML 尚未被加载而失效。



* 示例：

::: code-group

```html [index.html] {29-35}
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    .btn {
      width: 250px;
      height: 50px;
      border-radius: 25px;
      border: none;
      /* 去掉边框 */
      outline: none;
      background-color: skyblue;
      /* 去掉点击时的虚线/光晕 */
      outline: none;
      cursor: pointer;
      box-shadow: 0 0 10px rgba(0, 0, 0, 0.2);
    }
  </style>
</head>

<body>

  <button class="btn">点击我</button>

  <script>
    /* 内部JavaScript */
    const btn = document.querySelector('.btn')
    btn.addEventListener('click', () => {
      alert('按钮被点击了！')
    })
  </script>

</body>

</html>
```

### 1.2.4 外部 JavaScript

* 格式：

::: code-group

```html 
<script src="./js/index.js"></script>
```

```js
console.log('你好，世界');
```

:::

> [!NOTE]
>
> * ① 单独建立一个以 .js 结尾的文件，里面存放所有的 JavaScript 代码。
> * ② 在 HTML 文件中，通过 `<script src="./xxx.js" />` 文件引入。



* 示例：

::: code-group

```html [index.html] {31}
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    .btn {
      width: 250px;
      height: 50px;
      border-radius: 25px;
      border: none;
      /* 去掉边框 */
      outline: none;
      background-color: skyblue;
      /* 去掉点击时的虚线/光晕 */
      outline: none;
      cursor: pointer;
      box-shadow: 0 0 10px rgba(0, 0, 0, 0.2);
    }
  </style>

</head>

<body>

  <button class="btn">点击我</button>
    
  <!-- 外部JavaScript -->
  <script src="./js/index.js"></script>

</body>

</html>
```

```js [index.js]
const btn = document.querySelector('.btn')
btn.addEventListener('click', () => {
  alert('按钮被点击了！')
})
```
