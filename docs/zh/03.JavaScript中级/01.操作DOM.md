# 第三章：获取 DOM 对象

## 3.1 概述

## 3.2 根据 CSS 选择器来获取 DOM 元素

* 格式：

```js
document.querySelector(css选择器): HTMLElement | null

document.querySelectorAl(css选择器):  NodeListOf<HTMLElement>
```

> [!NOTE]
>
> * ① querySelector() 会返回 CSS 选择器匹配到的第一个元素（HTMLElement 对象），如果没有匹配到，则返回 null。
> * ② querySelectorAll() 会返回 CSS 选择器匹配到的 NodeList 对象集合（其是一个伪数组，即：只能遍历，才能获取其中的每个元素对象）。
> * ③ 哪怕只有一个元素，querySelectorAll()  返回的还是一个伪数组，里面只有一个元素而已。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <div id="box">123</div>
  <p id="nav">导航栏</p>
  <div class="box2">456</div>
  <ul>
    <li>1</li>
    <li>2</li>
    <li>3</li>
  </ul>

  <script>
    /* 1. 获取匹配到的第一个元素 */
    const div = document.querySelector('div')
    console.log(div)

    /* 2. 获取匹配到的所有元素 */
    const divList = document.querySelectorAll('div')
    console.log(divList)
  </script>

</body>

</html>
```

## 3.3 其他获取 DOM 元素方法（了解）

* 格式：

```js
// 根据 id 属性值获取元素
document.getElementById(elementId: string): HTMLElement | null

// 根据 class 属性值获取伪元素数组
document.getElementsByClassName(classNames: string): HTMLCollectionOf<Element>

// 根据标签名获取伪元素数组
document.getElementsByTagName(qualifiedName: string): HTMLCollectionOf<Element>

// 根据 name 属性值获取伪元素数组    
document.getElementsByName(qualifiedName: string): HTMLCollectionOf<Element>   
```



* 示例：

::: code-group

```html [index.html]

  <div class="box2">456</div>

    <li>2</li>
    <li>3</li>
  </ul>

    // 根据 id 获取元素

    // 根据 class 获取元素

    // 根据标签名获取元素
```

# 第四章：操作元素内容

## 4.1 概述

* 可以通过 `对象.innerText` 属性或 `对象.innerHTML` 属性来操作元素内容，即：读或写。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-11-02/2026-11-02-18-14-31.png)

## 4.2 对象的 innerText 属性

* 格式：

```js
// 获取标签内部的内容
对象.innerText
// 修改标签内部的内容
对象.innerText = 'xxx'
```

> [!NOTE]
>
> * ① 可以通过 `对象.innerText` 对标签内的内容进行读或写。
> * ② `对象.innerText` 只会显示纯文本；但是，并不会解析标签。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <div id="box">我是文字内容</div>
  <p id="nav">导航栏</p>
  <div class="box2">456</div>
  <ul>
    <li>1</li>
    <li>2</li>
    <li>3</li>
  </ul>

  <button class="btn">点我修改内容</button>

  <script>
    /* 获取匹配到的所有元素 */
    const div = document.querySelector('#box')
    const btn = document.querySelector('.btn')
    /* 获取元素内容 */
    console.log(div.innerText)
    /* 设置元素内容 */
    btn.addEventListener('click',function(){
      div.innerText = '我是新的文字内容'
    })
  </script>
</body>

</html>
```

## 4.4 综合案例

* 需求：从数组随机抽取一等奖、二等奖和三等奖，显示到对应的标签里面。

> [!NOTE]
>
> * ① 声明数组：const arr = ['张三','李四',...] 。
> * ② 随机生成一个数组索引（0 - 数组长度），并获取对应位置的数组元素。
> * ③ 每次随机生成之后，将其从数组中删除，并继续进行随机获取。
> * ④ 通过 innerText 或 innerHTML 将数组元素设置到对应的位置。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8" />
  <meta http-equiv="X-UA-Compatible" content="IE=edge" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>年会抽奖</title>
  <style>
    .wrapper {
      width: 700px;
      height: 420px;
      background: url(./images/bg01.jpg) no-repeat center / cover;
      padding: 100px 250px;
      box-sizing: border-box;
      margin: 100px auto;
    }
  </style>
</head>

<body>

  <div class="wrapper">
    <strong>某公司年会抽奖</strong>
    <h1>一等奖：<span id="one">???</span></h1>
    <h3>二等奖：<span id="two">???</span></h3>
    <h5>三等奖：<span id="three">???</span></h5>
  </div>

  <script>
    /* ① 声明数组 */
    const arr = ['张三', '李四', '王五', '赵六', '田七']
    /* ② 随机抽取一个元素，并要求每次抽取的不一样 */
    function getElement(arr) {
      let randomIndex = Math.floor(Math.random() * arr.length)
      let ele = arr[randomIndex]
      arr.splice(randomIndex, 1)
      return ele
    }
    let one = getElement(arr)
    let two = getElement(arr)
    let three = getElement(arr)
    // 设置获奖人姓名
    document.querySelector('#one').innerHTML = one
    document.querySelector('#two').innerHTML = two
    document.querySelector('#three').innerHTML = three
  </script>

 </body> 

</html>
```

# 第五章：操作元素属性

## 5.2 操作元素的常用属性

* 格式：

```js
对象.属性 = xxx
```

> [!NOTE]
>
> * ① 可以通过 js 修改标签的属性值，如：通过修改 src 更换图片等。
> * ② 最常见的属性有 href、title、src 等。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    body {
      display: flex;
      justify-content: center;
      align-items: center;
      gap: 50px;
      flex-direction: column;
    }
  </style>
</head>

<body>

  <img src="./images/1.webp" alt="">

  <button>点我修改图片</button>

  <script>
    /* 获取元素 */
    const imgEl = document.querySelector('img')
    const btnEl = document.querySelector('button')
    /* 添加事件 */
    btnEl.addEventListener('click', function () {
      // 修改 src 属性
      imgEl.src = './images/2.webp'
      // 修改 title 属性
      imgEl.title = '刘德华'
    })

  </script>
</body>

</html>
```

## 5.3 操作元素的样式属性

### 5.3.1 概述

* 可以通过  js  修改标签的样式属性，如：width、background、translate 等。

### 5.3.2 通过 style 属性修改 css

* 格式：

```js
对象.style.样式属性 = xxx
```

> [!NOTE]
>
> * ① 修改样式是通过 style 属性引出的，即：`<h1 style='color: red'>标签</h1>` 。
> * ② 如果样式属性有 `-` 连接符，需要转换为 `小驼峰` 命名法。
> * ③ 赋值的时候，不要忘记添加 css 单位，如：`px` 、`%`、`rem` 、`vw` 等。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    .box {
      width: 200px;
      height: 200px;
      background-color: pink;
    }
  </style>
</head>

<body>

  <div class="box"></div>

  <script>
    /* 获取 box 元素 */
    const boxEl = document.querySelector('.box')
    /* 
      通过 style 属性修改样式

      对象.style.样式属性 = '值'
    */
    boxEl.style.width = '300px'
    boxEl.style.height = '300px'
    /* 多组单词可以采用小驼峰 */
    boxEl.style.backgroundColor = 'red'
    boxEl.style['background-color'] = 'skyblue'
    boxEl.style.border = '2px solid red'
  </script>

</body>

</html>
```

### 5.3.3 通过 className 修改 css

* 格式：

```js
对象.className = '类名'
```

> [!NOTE]
>
> * ① 如果修改的样式比较多，直接通过修改 style 属性比较繁琐，我们可以借助于修改 class 类名的方式，即：将多个样式放到 css 的类中，然后将这个类添加到元素上面。
> * ② 由于 class 是 JavaScript 的关键字，所以使用 className 代替。
> * ③ className 是用新值 `替换（覆盖）` 旧值，即：如果需要添加一个类，就需要保留之前的类名。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    .box {
      width: 200px;
      height: 200px;
      background-color: pink;
      color: #fff;
      text-align: center;
      align-content: center;
      font-size: 20px;
    }

    .active {
      width: 300px;
      height: 300px;
      background-color: red;
      margin: 100px auto;
      border: 1px solid #000;
      box-shadow: 0 10px 10px rgba(0, 0, 0, .3);
    }
  </style>
</head>

<body>

  <div class="box">123</div>

  <script>
    /* 获取元素 */
    const boxEl = document.querySelector('.box')
    /* 
      通过 className 覆盖样式
      如果要添加一个类，需要保留之前的类名
    */
    boxEl.className = 'box active'
  </script>

</body>

</html>
```

### 5.3.4 通过 classList 修改 css

* 格式：

```js
// 追加一个类
对象.classList.add('类名')
// 删除一个类
对象.classList.remove('类名')
// 切换一个类（之前有，则删除；之前没有，则添加）
对象.classList.toggle('类名')
```

> [!NOTE]
>
> 为了解决 className 容易覆盖以前的类名，我们可以通过 classList 的方式来追加、删除或切换类名。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    .box {
      width: 200px;
      height: 200px;
      background-color: saddlebrown;
      color: #fff;
      text-align: center;
      align-content: center;
      font-size: 20px;
    }

    .active {
      background-color: red;
      border: 1px solid #000;
      box-shadow: 0 10px 10px rgba(0, 0, 0, .3);
    }
  </style>
</head>

<body>

  <div class="box">123</div>

  <button class="btn-add">增加</button>
  <button class="btn-remove">删</button>
  <button class="btn-toggle">切换</button>

  <script>
    /* 获取元素 */
    const boxEl = document.querySelector('.box')
    /* 通过 classList 修改样式，可以增、删、切换 */
    /* 点击按钮，添加 active 类*/
    const btnAdd = document.querySelector('.btn-add')
    btnAdd.addEventListener('click', function (e) {
      boxEl.classList.add('active')
    })
    /* 点击按钮，删除 active 类*/
    const btnRemove = document.querySelector('.btn-remove')
    btnRemove.addEventListener('click', function (e) {
      boxEl.classList.remove('active')
    })
    /* 点击按钮，切换 active 类*/
    const btnToggle = document.querySelector('.btn-toggle')
    btnToggle.addEventListener('click', function (e) {
      boxEl.classList.toggle('active')
    })
  </script>

</body>

</html>
```

## 5.4 操作表单元素属性

* 格式：

```js
/* 对于文本框或密码框 */
表单对象.type = xxx
表单对象.value = xxx
/* 对于单选、多选、下拉框以及按钮 */
表单对象.checked = true | false
```

## 6.1 概述

## 6.2 间隔函数

* 格式：

```js
// 开启定时器（每隔一段时间调用该函数），间隔时间的单位是毫秒
let timerId = setInterval(函数名或匿名函数, 间隔时间)

// 关闭定时器（满足一定条件，停止定时器）
clearInterval(timerId)
```



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">

      margin-bottom: 20px;
    }
  </style>

  <div class="box"></div>

  <button class="start">开启定时器</button>
  <button class="end">关闭定时器</button>

  <script>
    const startBtn = document.querySelector('.start')
    const endBtn = document.querySelector('.end')
    const box = document.querySelector('.box')

    function fn() {
      let counter = 0;

      return function () {
        box.innerHTML = `1秒执行1次，第${++counter}次`
      }
    }

    let timerId = null

    startBtn.addEventListener('click', () => {
      if (timerId !== null) return
      timerId = setInterval(fn(), 1000)
    })

    endBtn.addEventListener('click', () => {
      clearInterval(timerId)
      timerId = null
    })
  </script>
```
