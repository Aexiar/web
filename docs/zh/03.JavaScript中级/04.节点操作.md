# 第一章：日期时间类型 Date

## 1.1 概述

* `时间标准的发展历史` 是人类为了统一和精确衡量时间而进行的持续努力，如下所示：

:::: details 点我查看 具体细节

::: timeline 天文观测和日晷

* 古代人们最早通过观测 `天体运动` 来判断时间。
* 日晷是一种利用太阳的影子来测量时间的简单仪器，被广泛使用于古代文明。

:::

::: timeline 机械钟的出现

* 中世纪，机械钟的发明使得人们可以更准确地测量时间。
* 钟表使用摆锤的摆动或者齿轮的旋转等机械运动来计时，提供了更精确的时间参考。

:::

::: timeline 格林尼治标准时间（`GMT`）

* 随着铁路的发展，全球需要有统一的时间标准。
* 1884 年，在英国伦敦的格林尼治皇家天文台的格林尼治时间被确定为世界的参考时间，称为格林尼治标准时间（GMT）。

:::

::: timeline 标准时间区

* 由于地球的广度，各个地区的太阳时间会有差异。
* 为解决这个问题，国际经度会议于 1884 年确定了 `24` 个时区，每个时区跨 15 度经度，各自有自己的标准时间，如：`中国` 就是 `东八区`。

:::

::: timeline 原子钟和国际原子时（TAI）

* 20 世纪中叶，原子钟的发明使得时间测量更加精确。
* 1955 年，国际原子时（TAI）作为全球的时间标准被引入，它是通过多个原子钟的平均值来测量时间。

:::

::: timeline 协调世界时（`UTC`）

* 尽管原子钟提供了高精度的时间测量，地球自转的速度会因为多种因素而产生微小变化。
* 1972 年，为了解决这个问题，引入了协调世界时（UTC）。
* UTC 通过在国际原子时（TAI）上增加或减少闰秒来与地球自转保持同步。

:::

::: timeline GPS 时间

* 球定位系统（GPS）采用原子钟来提供位置和时间信息。
* GPS 时间是基于原子钟计时的，与协调世界时（UTC）之间有微小的差异，因为 GPS 系统中不使用闰秒。

:::

## 1.2 创建 Date 对象

* 格式：

```js
const date = new Date() // 表示实例化当前时刻的日期和时间
const date = new Date(value) // value 表示 Unix 时间戳
const date = new Date(dateString) // 日期的字符串值，能被 Date.parse() 所识别
const date = new Date(year, month, ... ) // 提供日期与时间的每一个成员
```

> [!NOTE]
>
> Date 对象是带时区的本地时间，不是 UTC 时间。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <script>
    /* 获取当前时间*/
    const date = new Date() // 当前时间
    console.log('date', date)

    /* 获取指定的时间 */
    const date2 = new Date('2026-06-01 08:00:00') // 按UTC解析，仅日期的ISO格式
    console.log('date2', date2)

    /* 获取指定的时间 */
    const date3 = new Date(1780272000000) // 传入 Unix 时间戳
    console.log('date3', date3)

    /* 获取指定的时间 */
    const date4 = new Date(2026, 11, 11, 11, 11, 11) // 年,月,日,时,分,秒,毫秒
    console.log('date4', date4)
  </script>

</body>

</html>
```

## 1.4 取值方法

* 格式：

```js
date.getFullYear() // 获取年
date.getMonth() // 获取月
date.getDate() // 获取日（1–31）
date.getDay() // 获取周几，0 表示周日
date.getHours() // 获取时
date.getMinutes() // 获取分
date.getSeconds() // 获取秒
date.getMilliseconds() // 获取毫秒
```

> [!NOTE]
>
> * ① date.getFullYear() 等方法获取的是本地时间；而 date.getUTCFullYear() 获取的是 UTC 时间。
> * ② date.getMonth() 获取的月份是从 0 开始的，实际使用需要 +1 。

## 1.7 综合案例

### 1.7.1 显示当前日期时间

* 需求：将当前日期时间显示到页面中，如：2099年11月11日 08:08:56 。

> [!NOTE]
>
> * ① 封装一个函数 getDateTime() ，返回 `2099年11月11日 08:08:56`  格式的字符串。
> * ② 对于 `时间` 的数字可能需要前面 `补 0` ，如：`8` --> `08` 。
> * ③ 通过 innerText 给指定的标签将日期时间显示到页面中，并添加定时器效果。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>
<body>
  
  <!DOCTYPE html>
  <html lang="en">
  
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <style>
      .box {
        width: 500px;
        height: 200px;
        background-color: rgb(175, 95, 95);
        color: #fff;
        text-align: center;
        align-content: center;
        margin: 100px auto;
        border-radius: 10px;
        box-shadow: 0 0 10px rgba(0, 0, 0, .5);
      }
    </style>
  </head>
  
  <body>
  
    <div class="box">
      <h2>当前日期时间</h2>
      <p class="date-time">2025年12月12日 12:12:12</p>
    </div>
  
    <script>
      // 获取元素
      const dateTime = document.querySelector('.date-time')

      // 获取当前时间
      function getDateTime() {
        const date = new Date()
        const year = date.getFullYear()
        const month = date.getMonth() + 1
        const day = date.getDate()
        const hour = String(date.getHours()).padStart(2, '0')
        const minute = String(date.getMinutes()).padStart(2, '0')
        const second = String(date.getSeconds()).padStart(2, '0')
        return `${year}年${month}月${day}日 ${hour}:${minute}:${second}`
      }

      // 设置时间
      function setCurrentDateTime() {
        dateTime.innerText = getDateTime()
      }

      // 先调用函数
      setCurrentDateTime()

      // 开启定时器
      let timerId = null
      timerId = setInterval(() => {
        setCurrentDateTime()
      }, 1000)

      // 页面离开事件
      window.addEventListener('beforeunload', () => {
        if (timerId !== null) {
          clearInterval(timerId)
        }
      })

    </script>
  </body>
  
  </html>
</body>
</html>
```

### 1.7.2 下班倒计时

* 需求：计算到下班还有多少时间（18:30:30） 。

> [!NOTE]
>
> * ① 核心思路：使用 `将来的时间戳 - 当前的时间戳`，其结果是两段时间的时间差（毫秒）。
> * ② 得到的时间戳的差是 `毫秒值`，需要转换为 `秒`（毫秒/1000） ，再进行计算时分秒。
> * ③ 如果 `当前日期时间` 已经超过了 `目标日期时间`（下班时间），则顺延一天。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="zh-CN">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>下班倒计时</title>
  <style>
    * {
      margin: 0;
      padding: 0;
      box-sizing: border-box;
    }

    body {
      display: flex;
      justify-content: center;
      align-items: center;
      flex-direction: column;
      height: 100vh;
    }

    .countdown {
      display: flex;
      flex-direction: column;
      justify-content: space-evenly;
      color: #fff;
      text-align: center;
      width: 324px;
      height: 400px;
      background-color: #c74141;
      box-shadow: 0 10px 10px rgba(0, 0, 0, .5);

      .date {
        font-size: 20px;
      }

      .title {
        font-size: 46px;
      }

      /* 时钟数字盒子：.time（倒计时）与 .dismissed（下班时间）两处共用 */
      .item {
        position: relative;
        display: inline-flex;
        justify-content: center;
        align-items: center;
        width: 46px;
        height: 46px;
        background-color: #000;
        border-radius: 4px;
        font-size: 24px;
        font-variant-numeric: tabular-nums;

        &:not(:last-child)::after {
          content: ':';
          position: absolute;
          left: calc(100% + 5px);
          /* 显式垂直居中，不依赖 flex 静态位置的浏览器实现差异 */
          top: 50%;
          transform: translateY(-50%);
          color: #fff;
        }
      }

      .time {
        display: flex;
        justify-content: center;
        align-items: center;
        gap: 16px;
      }

      .dismissed {
        /* 与 .time 一致的布局：数字、冒号、文字水平居中排列 */
        display: flex;
        justify-content: center;
        align-items: center;
        gap: 4px;
        font-size: 32px;

        /* 覆盖共用 .item 的黑盒样式：只保留数字和冒号 */
        .item {
          width: auto;
          height: auto;
          background-color: transparent;
          font-weight: 700;
        }

        /* 冒号紧贴数字，呈 18:30:00 的紧凑时间格式
           （选择器保持 :not(:last-child) 以匹配原规则优先级，确保覆盖生效） */
        .item:not(:last-child)::after {
          position: static;
          left: auto;
          transform: none;
          color: #fff;
          margin: 0;
        }
      }

    }
  </style>
</head>

<body>

  <div class="countdown">
    <div class="date">
      今天是<span class="year">2012</span>年<span class="month">2</span>月<span class="day">13</span>日
    </div>
    <h2 class="title">下班倒计时</h2>
    <p class="time">
      <span class="item hour">23</span>
      <span class="item minute">30</span>
      <span class="item second">30</span>
    </p>
    <p class="dismissed">
      <span class="item end-hour">18</span>
      <span class="item end-minute">30</span>
      <span class="item end-second">00</span>
      下班
    </p>
  </div>

  <script>
    // 下班（结束）时间，集中配置，避免散落在多处硬编码
    const END_HOUR = 18
    const END_MINUTE = 30
    const END_SECOND = 0

    // 获取元素对象，并封装到 el 对象中
    const el = {
      year: document.querySelector('.year'),
      month: document.querySelector('.month'),
      day: document.querySelector('.day'),
      hour: document.querySelector('.hour'),
      minute: document.querySelector('.minute'),
      second: document.querySelector('.second'),
      endHour: document.querySelector('.end-hour'),
      endMinute: document.querySelector('.end-minute'),
      endSecond: document.querySelector('.end-second'),
    }

    // 渲染下班时间：直接由 END_* 配置生成，只执行一次，
    // 改配置这里自动同步，不会出现"倒计时目标"与"展示的下班时间"两套数据各写各的
    el.endHour.innerText = pad(END_HOUR)
    el.endMinute.innerText = pad(END_MINUTE)
    el.endSecond.innerText = pad(END_SECOND)

    /**
     * 补零函数：保证始终显示两位，不会出现 "9:3:0" 这种宽度跳变
     * @param {*} n 数字
     */
    function pad(n) {
      return String(n).padStart(2, '0')
    }

    /**
     * 获取目标日期时间
     * 若今天的目标时间已过，则顺延到明天，避免出现负数倒计时
     * @param {Date} now 当前时间
     * @returns {Date} 目标时间
     */
    function getTargetDate(now) {
      /* 获取当前日期时间 */
      const target = new Date(now)
      /* 设置时分秒 */
      target.setHours(END_HOUR, END_MINUTE, END_SECOND, 0)
      /* 如果当前时间已过，则顺延到明天，避免出现负数倒计时 */
      if (target.getTime() <= now.getTime()) {
        target.setDate(target.getDate() + 1)
      }
      /* 返回目标日期时间 */
      return target
    }

    /**
     * 渲染函数
     */
    function render() {
      /* 获取当前日期时间 */
      const now = new Date()

      /* 设置年月日 */
      el.year.innerText = now.getFullYear()
      el.month.innerText = now.getMonth() + 1
      el.day.innerText = now.getDate()

      // 边界处理：剩余时间最小为 0，且只在渲染时读取一次 Date.now，避免同一帧内两次取时产生偏差
      const diff = Math.max(0, getTargetDate(now).getTime() - now.getTime())
      /* 获取目标日期时间和当前日期时间的间隔总秒数 */
      const totalSeconds = Math.floor(diff / 1000)

      /* 设置时分秒 */
      el.hour.innerText = pad(Math.floor(totalSeconds / 3600))
      el.minute.innerText = pad(Math.floor(totalSeconds / 60) % 60)
      el.second.innerText = pad(totalSeconds % 60)
    }

    /* 调用一次渲染函数 */
    render()

    /* 开启定时器 */
    let timerId = null
    timerId = setInterval(() => {
      if (timerId !== null) {
        render()
      }
    }, 1000)

    // 页面离开事件
    window.addEventListener('beforeunload', () => {
      if (timerId !== null) {
        clearInterval(timerId)
      }
    })
  </script>
</body>

</html>
```

# 第二章：节点操作

## 2.1 概述

* `DOM树` 是将 `HTML文档` 以 `树状结构` 直观的表现出来，每个 `HTML标签(属性)` 都可以称为 `节点`。

::: details 点我查看 具体细节

* ① `DOM树`，也可以称为 `节点树` 。
* ② `节点`（Node）是 `DOM树` 中的单个点，包含：文档本身，`元素`（Element）、文本或注释。
* ③ 学习节点关系可以帮助我们更好的操作元素，如：查找元素、修改内容、添加节点或删除节点。

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-11-06/2026-11-06-13-19-44.png)

## 2.2 Node VS Element

* Node 是 DOM 中最基础的单位，而 Element 专指 HTML 标签对应的元素节点。

::: details 点我查看 具体细节

* ① 在实际开发中，如果主要操作 HTML 元素，更推荐使用 `parentElement`。 因为它的语义更明确，而且方便继续操作 `classList`、`style` 等元素属性。
* ② 在 Vue 3 等现代前端项目中，普通业务代码通常不需要频繁手动遍历 DOM，更多时候使用组件状态、模板引用和事件机制。

## 2.3 元素导航（查找元素）

* 如果获取到一个元素（Element）后，就可以根据这个元素去获取其余元素，即：元素导航。

::: details 点我查看 具体细节

* ① 学习 DOM 原理时，先理解 `Node` 和 `Element` 的继承关系。
* ② 普通 HTML 元素导航，优先使用 `parentElement`。
* ③ 查找符合条件的祖先元素，优先考虑 `closest()`。
* ④ 需要完整 DOM 节点结构时，再使用 `parentNode`。

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-11-06/2026-11-06-13-52-53.png)

## 4.2 录入模块

* 需求：点击录入按钮，可以将数据录入进去，并将数据渲染到下方的表格中。

> [!NOTE]
>
> * ① 声明一个空的对象数组，如下所示：
>
> ```js
> const arr = [
>     {
>         stuId: 1, 
>         uname: '张三',
>         age:18,
>         gender:'男',
>         salary:18000,
>         city:'北京'
>     },
>     {},
>     ...
> ]
> ```
>
> * ② 对表单注册 submit 事件，并取消默认提交。
> * ③ 创建新的对象，里面存储表单中获取过来的数据，并将添加到数组中。
> * ④ 重置表单，即：清空表单输入的数据。
> * ⑤ 定义渲染数据的函数，即：遍历数组，动态生成 tr ，向里面填充 td 数据，并追加给 tbody （需要先清空 tbody ，为了放置多次生成多条数据）。



* 示例：

::: code-group

```html [index.html	
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <meta http-equiv="X-UA-Compatible" content="ie=edge" />
  <title>学生信息管理</title>
  <link rel="stylesheet" href="css/index.css" />
</head>

<body>
  <h1>新增学员</h1>
  <form class="info" autocomplete="off">
    姓名：<input type="text" class="uname" name="uname" />
    年龄：<input type="text" class="age" name="age" />
    性别:
    <select name="gender" class="gender">
      <option value="男">男</option>
      <option value="女">女</option>
    </select>
    薪资：<input type="text" class="salary" name="salary" />
    就业城市：<select name="city" class="city">
      <option value="北京">北京</option>
      <option value="上海">上海</option>
      <option value="广州">广州</option>
      <option value="深圳">深圳</option>
      <option value="曹县">曹县</option>
    </select>
    <button class="add">录入</button>
  </form>

  <h1>就业榜</h1>
  <table>
    <thead>
      <tr>
        <th>学号</th>
        <th>姓名</th>
        <th>年龄</th>
        <th>性别</th>
        <th>薪资</th>
        <th>就业城市</th>
        <th>操作</th>
      </tr>
    </thead>
    <tbody>
      <!-- 
        <tr>
          <td>1001</td>
          <td>欧阳霸天</td>
          <td>19</td>
          <td>男</td>
          <td>15000</td>
          <td>上海</td>
          <td>
            <a href="javascript:">删除</a>
          </td>
        </tr> 
        -->
    </tbody>
  </table>
  <script>
    /* 1. 声明空的数组 */

    /* 2. 获取元素 */
    const el = {
      formEl: document.querySelector('.info'),
      tbodyEl: document.querySelector('tbody')
    }


    /* 3. 对 form 表单使用事件委托，即：添加提交事件 */
    el.formEl.addEventListener('submit', (event) => {
      //取消默认提交
      event.preventDefault()
      // 创建 FormData 对象，用于收集表单数据
      const formData = new FormData(el.formEl)
      // 检查是否存在空字段
      for (const [key, value] of formData) {
        if (typeof value === 'string' && !value.trim()) {
          alert(`${key} 不能为空`);
          return
        }
      }
      // 获取表单提交的数据，并封装到对象中
      const data = {
        stuId: arr.length,
        uname: formData.get('uname'),
        age: Number(formData.get('age')),
        gender: formData.get('gender'),
        salary: Number(formData.get('salary')),
        city: formData.get('city')
      }
      // 将数据保存到对象数组中
      arr.push(data)
      // 重置表单
      event.target.reset()
      // 渲染数据到表格
      render()
    })

    /* 4. 定义渲染的函数 */

      el.tbodyEl.innerHTML = ''
      // 遍历数组，并将数据填充到 tbody 中
      arr.forEach((item) => {

        `
      })
    }

  </script>

</body>
```
