## 3.2 业务分析

* ① 其实，就是针对本地存储中数组数据的维护，如下所示：

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-11-08/2026-11-08-09-49-10.png)

* ② 点击录入按钮，将数据添加到本地存储中，并将本地存储中的数据渲染到下方的表格中，即：新增业务。
* ③ 点击删除按钮，删除本地存储中指定的数据，并将本地存储中的数据渲染到下方的表格中，即：删除业务。
* ④ 尽量减少 dom 的操作，而采取操作数据的形式，来驱动页面的渲染，即：增加和删除都是针对本地存储中数据的操作，然后根据本地存储中的数据去渲染页面。

## 3.3 渲染业务

* 需求：根据持久化数据渲染页面。

> [!NOTE]
>
> * ① 对 localStorage 的操作统一封装到类中。
> * ② 从 localStorage 中获取数组，并利用 map() 和 join() 方法实现字符串拼接，以便设置到 tobody 中，即：渲染页面。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<body>

  <h1>就业榜</h1>
  <table>
    <thead>
      <tr>
        <th>学号</th>
        <th>姓名</th>
        <th>年龄</th>
        <th>性别</th>
        <th>薪资</th>
        <th>就业城市</th>
        <th>操作</th>
      </tr>
    </thead>
    <tbody>
      <!-- 
        <tr>
          <td>1001</td>
          <td>欧阳霸天</td>
          <td>19</td>
          <td>男</td>

    /* 将存储逻辑单独封装到类中 */
    class Storage {
      #key

      constructor(key) {
        this.#key = key
      }

      getAll() {
        try {
          const data = localStorage.getItem(this.#key)
          if (data === null) {
            return []
          }
          const result = JSON.parse(data)
          return Array.isArray(result) ? result : []
        } catch (error) {
          console.error('读取本地数据失败：', error)
          return []
        }
      }

      save(data) {
        if (!Array.isArray(data)) {
          throw new TypeError('存储的数据必须是数组')
        }

        localStorage.setItem(
          this.#key,
          JSON.stringify(data)
        )
      }
    }

    /* 实例化 Storage */
    const storage = new Storage('students')

    /* 获取元素 */
    const el = {
      formEl: document.querySelector('.info'),
      tbodyEl: document.querySelector('tbody')
    }

    /* 定义渲染的函数 */
    function render() {
      // 通过数组的 map() 遍历数组，并进行字符串拼接，返回新的数组
      const newArr = storage.getAll().map((item, index) => {
        return `
          <tr>
            <td>${item.stuId}</td>
            <td>${item.uname}</td>
            <td>${item.age}</td>
            <td>${item.gender}</td>
            <td>${item.salary}</td>
            <td>${item.city}</td>
            <td>
              <a href="javascript:" data-id="${index}">删除</a>
            </td>
          </tr>
        `
      })
      // 将数组转换为字符串，并插入到 tbody 中
      el.tbodyEl.innerHTML = newArr.join('')
    }


    /* 页面加载时，渲染数据到表格 */
    render()

  </script>

</body>

</html>
```

> * ④ 渲染页面，并重置表单。

```html [index.html]
      event.preventDefault()

      const formData = new FormData(el.formEl)

      for (const [key, value] of formData) {
        if (typeof value === 'string' && !value.trim()) {
          alert(`${key} 不能为空`);
```
