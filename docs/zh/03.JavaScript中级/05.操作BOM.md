# 第一章：BOM

## 1.1 概述

* `BOM` 是 `浏览器对象模型`，是浏览器提供的一组对象，用于和浏览器窗口进行交互。

::: details 点我查看 具体细节

* ① BOM 是 Browser Object Model 的缩写，主要包括 window、location 等，如下所示：

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-11-08/2026-11-08-19-15-43.png)

* ② BOM 中的各个组成部分，如下所示：

| BOM 的组成部分   | 描述                                           |
| ---------------- | ---------------------------------------------- |
| :one: window     | 全局对象、方法、控制浏览器窗口相关的属性和方法 |
| :two: location   | 浏览器链接到对象的位置，即：URL                |
| :three: history  | 操作浏览器的历史记录。                         |
| :four: navigator | 用户代理（浏览器）的状态和标识。               |
| :five: screen    | 屏幕窗口信息（较少使用）。                     |
| :six: ....       | ...                                            |

## 1.2 window

### 1.2.1 概述

* window 对象是浏览器中最顶层的全局对象，如下所示：

::: details 点我查看 具体细节

* ① `window 对象` 是一个全局对象，即：JavaScript 的 `顶级对象`。
* ② 像 document、alert() 和 console.log() 等都是 window 对象的属性或方法。
* ③ 所有通过 `var` 定义的全局作用域的变量或函数都会变为 window 对象的属性和行为。
* ④ window 对象下的属性和方法，在调用的时候可以省略 window，如：console.log(xxx) 。
* ⑤ window 默认给我们提供了全局的函数和类，如：setTimeout、Math、Date、Object 等。

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-11-08/2026-11-08-18-56-36.png)

### 1.2.2 延时函数

* 格式：

```js
[window.]setTimeout(handler: TimerHandler, timeout?: number): number
```

> [!NOTE]
>
> * ① setTimeout 仅仅只执行一次，所以可以理解为就是把一段代码延迟执行，即：延时函数。
> * ② 清除延时函数和清除间隙函数一样，使用 clearXxx(timeId)，如：clearTimeout(timerId) 。
> * ③ 延迟函数需要等待，即：后面的代码会先执行。
> * ④ 每一次调用延时函数都会创建一个新的延时器。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <button class="btn">点我</button>

  <script>
    const btn = document.querySelector('.btn')
    btn.addEventListener('click', () => {
      setTimeout(() => {
        console.log('1秒后执行')
      }, 1000)
    })
  </script>

</body>

</html>
```

::: code-group

```html [index.html]
<!DOCTYPE html>

  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>
<body>
  
  <a href="#">
    支持成功<span class="num">5</span>秒后跳转
  </a>

  <script>
    /* 
      5 秒后跳转页面
      用户点击跳转；如果不点击，则 5 秒后自动跳转
     */
    const a = document.querySelector('a')
    const num = a.querySelector('.num')
    
    /* 设置间隙函数 */
    let count = 5
    const timer = setInterval(() => {
      count--
      num.innerHTML = count
      if (count === 0) {
        clearInterval(timer)
        location.href = 'https://www.baidu.com'
      }
    }, 1000)
  </script>
</body>
</html>
```

# 第二章：JSON

## 2.1 概述

* JSON 是一种非常重要的数据格式，是一种可以在服务器和客户端之间传输的数据格式。

::: details 点我查看 具体细节

* ① 虽然 JSON 被提出来的时候是主要应用 JavaScript 中，但是目前已经独立于编程语言，可以在各个编程语言中使用。

* ② JSON 的应用场景：
  * 网络数据的传输 JSON 数据，如：Ajax。
  * 项目的某些配置文件，如：package.json。
  * 非关系型数据库将 JSON 作为存储格式，如：MongoDB。

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-11-18/2026-11-18-15-31-43.png)

## 2.2 JSON 的基本语法

* JSON 主要由两种复合结构组成，如下所示：

| JSON 的组成          | 描述                           |
| -------------------- | ------------------------------ |
| :one: 对象（Object） | 使用 `{}` 表示，由键值对组成。 |
| :two: 数组（Array）  | 使用 `[]` 表示，由多个值组成。 |

* JSON 的核心语法规则，如下所示：

| JSON 核心语法规则                  | 描述                                   |
| ---------------------------------- | -------------------------------------- |
| :one: 对象使用 `{}`                | 对象由零个或多个键值对组成             |
| :two: 数组使用 `[]`                | 数组由零个或多个值组成                 |
| :three: 键必须使用双引号           | `"name"`，不能使用单引号               |
| :four: 键和值之间使用 `:`          | `"age": 18`                            |
| :five: 多个成员或元素使用 `,` 分隔 | 最后一个成员或元素后不能有逗号         |
| :six: 值必须是合法 JSON 类型       | 字符串、数字、布尔值、null、对象或数组 |

> [!NOTE]
>
> * ① JSON 的语法来源于 JavaScript 对象字面量，但它是一种独立于编程语言的数据格式。
> * ② 在前端向后端（服务端）传递数据时，需要将 JSON 对象转换为 JSON 字符串，即：序列化。
> * ③ 在后端（服务端）向前端传递数据时，需要将 JSON 字符串解析为 JSON 对象，即：反序列化。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>


  <script>

    /* JSON 对象 */
    const obj = {
      "name": "张三",
      "age": 18,
      "gender": "男",
      "isStudent": true,
      "hobbies": ["篮球", "足球", "游泳"],
      "address": {
        "province": "江苏省",
        "city": "南京市"
      }
    }

    /* 
     * 序列化：JSON 对象 --> JSON 字符串
     */
    const jsonStr = JSON.stringify(obj)
    console.log(typeof jsonStr, jsonStr)
    /* 
     * 反序列化：JSON 字符串 --> JSON 对象
     */
    const parsedObj = JSON.parse(jsonStr)
    console.log(typeof parsedObj, parsedObj)

  </script>

</body>

</html>
```

# 第三章：本地存储

## 3.1 概述

* 本地存储可以实现将数据保存到浏览器中，以实现页面刷新不丢失数据等效果，如下所示：

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-11-08/2026-11-08-18-56-12.png)

## 3.2 常用方法

* 格式：

```js
localStorage.setItem(key: string, value: string): void // 存储数据
localStorage.getItem(key: string): string | null // 查询数据
localStorage.removeItem(key: string): void // 删除数据
localStorage.clear(): void // 清空所有数据
```

> [!NOTE]
>
> * ① 数据可以长期保留在本地浏览器中，刷新页面或关闭页面，数据也不丢失。

## 3.3 综合练习

* 需求：将 localStorage 进行封装，以便处理简单类型或复杂类型。

> [!NOTE]
>
> * ① 使用面向对象的思想对 localStorage 的常规方法来进行封装。

> * ③ 在进行获取的时候，从 localStorage 中获取 JSON 字符串，再通过 JSON.parse(xxx) 转换为 JSON 对象。

::: code-group

```js [storage.js]
class Storage {
  #key
  #storage

  constructor (key, isLocal = true) {
    // 尽早校验 key，避免数据静默写入 "undefined" 键
    if (typeof key !== 'string' || key.trim() === '') {
      throw new TypeError('key 必须是非空字符串')
    }
    this.#key = key
    // 隐私模式或禁用 Cookie 时，访问 localStorage 属性本身会抛 SecurityError
    try {
      this.#storage = isLocal ? localStorage : sessionStorage
    } catch (error) {
      throw new Error('当前环境不支持 Web Storage（可能已被浏览器禁用）', { cause: error })
    }
  }

  // 读取数据：key 不存在或解析失败时返回默认值
  get(defaultValue = null) {
    try {
      const data = this.#storage.getItem(this.#key)
      if (data === null) {
        return defaultValue
      }
      return JSON.parse(data)
    } catch (error) {
      console.error('读取本地数据失败：', error)
      return defaultValue
    }
  }

  save(data) {
    try {
      const serialized = JSON.stringify(data)
      // undefined 无法被 JSON 序列化，存进去也读不回来，直接拦截
      if (serialized === undefined) {
        throw new TypeError('存储的数据必须是可 JSON 序列化的值')
      }
      this.#storage.setItem(this.#key, serialized)
    } catch (error) {
      // 统一处理序列化失败（循环引用）与存储空间不足（QuotaExceededError）
      console.error('写入本地数据失败：', error)
      throw new Error('数据写入本地存储失败，请检查数据是否可序列化或存储空间是否已满')
    }
  }

  // 清空当前 key 下的所有数据
  clear() {
    this.#storage.removeItem(this.#key)
  }

}
```
