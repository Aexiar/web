# 第一章：事件流

## 1.1 概述

* 学习事件流，可以帮我们解决一些疑惑，如：点击子盒子为什么会弹 2 次的问题，如下所示：

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-11-04/2026-11-04-11-16-37.png)



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    .father {
      position: relative;
      width: 300px;
      height: 300px;

    }

    父盒子
```

## 1.2 事件流

### 1.2.1 概述

* `事件流` 指的是事件完整执行过程中的 `流动路径`，如下所示：

::: details 点我查看 具体细节

* ① 当事件被触发时，会经历两个阶段：捕获阶段和冒泡阶段。
* ② 捕获阶段：当一个元素的事件被触发时，会从 DOM 的根元素开始依次调用 `同名事件`（从外到里）。
* ③ 冒泡阶段：当一个元素的事件被触发时，`同名事件` 会在该元素的祖先元素中被 `依次触发`（从里到外）。

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-11-04/2026-11-04-11-45-21.png)

### 1.2.2 事件捕获

* 格式：

```js
元素对象.addEventListener('事件类型',事件处理函数,是否使用捕获机制)
```

> [!NOTE]
>
> * ① 捕获阶段：当一个元素的事件被触发时，会从 DOM 的根元素开始依次调用 `同名事件`（从外到里）。
> * ② addEventListener 的第三个参数代表 `是否使用捕获机制`，其是一个布尔类型，true 代表捕获阶段触发（不常用）。
> * ③ addEventListener 的第三个参数代表 `是否使用捕获机制`，其是一个布尔类型，false 代表冒泡阶段触发（常用，默认值）。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    .father {
      position: relative;
      width: 300px;
      height: 300px;
      background-color: pink;
    }

    .son {
      /* 子盒水平垂直居中 */
      position: absolute;
      top: 50%;
      left: 50%;
      transform: translate(-50%, -50%);
      width: 100px;
      height: 100px;
      background-color: aqua;
    }
  </style>
</head>

<body>

  <div class="father">
    父盒子
    <div class="son">
      子盒子
    </div>
  </div>


  <script>
    /* 获取父元素和子元素 */
    const father = document.querySelector('.father')
    const son = father.querySelector('.son')
    /* body 元素添加点击事件 */
    document.body.addEventListener('click', (e) => {
      alert(`我是body`)
    }, true)
    /* 父元素注册点击事件 */
    father.addEventListener('click', (e) => {
      alert(`我是父盒子`)
    }, true)
    /* 子元素注册点击事件 */
    son.addEventListener('click', (e) => {
      alert(`我是子盒子`)
    }, true)
  </script>

</body>

</html>
```

### 1.2.4 阻止冒泡

* 格式：

```js
e.stopPropagation()
```

> [!NOTE]
>
> * ① 因为默认就有冒泡模式的存在，很容易就导致事件会影响到父元素。如果想将事件限制在当前元素内，就需要 `阻止事件冒泡`。
> * ② 阻止事件冒泡，就需要让当前 `事件对象` 去调用 `stopPropagation()` 方法。
> * ③ `e.stopPropagation()` 可以阻断事件流转传播，不光在冒泡阶段有效，捕获阶段也有效。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    .father {
      position: relative;
      width: 300px;
      height: 300px;
      background-color: pink;
    }

    .son {
      /* 子盒水平垂直居中 */
      position: absolute;
      top: 50%;
      left: 50%;
      transform: translate(-50%, -50%);
      width: 100px;
      height: 100px;
      background-color: aqua;
    }
  </style>
</head>

<body>

  <div class="father">
    父盒子
    <div class="son">
      子盒子
    </div>
  </div>


  <script>
    /* 获取父元素和子元素 */
    const father = document.querySelector('.father')
    const son = father.querySelector('.son')
    /* body 元素添加点击事件 */
    document.body.addEventListener('click', (e) => {
      alert(`我是body`)
    })
    /* 父元素注册点击事件 */
    father.addEventListener('click', (e) => {
      alert(`我是父盒子`)
    })
    /* 子元素注册点击事件 */
    son.addEventListener('click', (e) => {
      // 阻止事件冒泡
      e.stopPropagation()
      alert(`我是子盒子`)
    })
  </script>

</body>

</html>
```

### 1.2.5 阻止默认行为

* 格式：

```js
e.preventDefault()
```

> [!NOTE]
>
> 某些情况下需要 `阻止` 元素 `默认行为` 的 `发生`，如：阻止超链接的跳转，阻止表单域的提交。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    body {
      padding-top: 200px;
      display: flex;
      flex-direction: column;
      justify-content: center;
      align-items: center;
      gap: 10px;
    }
  </style>
</head>

<body>

  <a href="https://www.baidu.com">百度一下</a>
  <a href="https://www.deepseek.com" class="deepseek">deepseek</a>

  <script>
    /* 获取deepseek链接元素 */
    const deepseek = document.querySelector('.deepseek')
    /* deepseek 添加点击事件 */
    deepseek.addEventListener('click', function (event) {
      // 阻止默认行为
      event.preventDefault()
      // 弹框
      alert('deepseek链接被点击了！')
    });
  </script>


</body>

</html>
```

# 第二章：事件委托

## 2.1 概述

* `事件委托`（Event Delegation）是 JavaScript 中注册事件的常用技巧，如下所示：

::: details 点我查看 具体细节

* ① 内部原理：利用 `事件冒泡` 的特点，即：给 `父元素` 注册事件，当我们触发子元素的时候，会冒泡到父元素身上，从而触发父元素的事件。
* ② `事件委托`，也被称为 `事件委派` 或 `事件代理`。
* ② 之所以使用 `事件委托`，就是为了 `减少注册次数`，提高程序性能。

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-11-04/2026-11-04-12-52-42.png)

## 2.2 语法

* 格式：

```js
父元素.addEventListener('事件类型', function(e){
    // 通过 e.target.TagName 获取真正触发事件的元素
    const el = e.target.TagName
})
```

> [!NOTE]
>
> * ① 给 `父元素` 注册事件，通过 `事件冒泡` 特点，当触发子元素的时候，会冒泡到父元素身上，从而触发父元素的事件。
> * ② 通过 `e.target.TagName` 来获取真正触发事件的元素。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    .box {
      display: flex;
      justify-content: center;
      align-items: center;
      height: 50vh;
    }
    button {
      margin: 10px;
      cursor: pointer;
    }

    .active {
      background-color: red;
    }
  </style>
</head>

<body>

  <div class="box">
    <button class="active">第1个</button>
    <button>第2个</button>
    <button>第3个</button>
    <button>第4个</button>
    <button>第5个</button>
  </div>

  <script>
    /* 获取父元素 box */
    const box = document.querySelector('.box')
    /* 给父元素添加点击事件，即：事件委托 */
    box.addEventListener('click', (e) => {
      // 通过 e.target.tagName 获取真正触发事件的元素
      if (e.target.tagName === 'BUTTON') {
        // 清除 active 类
        const activeBtn = box.querySelector('.active')
        activeBtn.classList.remove('active')
        // 添加 active 类
        e.target.classList.add('active')
      }
    })
  </script>

</body>

</html>
```

>

> * ③ 需要使用 `e.target.TagName` 来获取哪个 a 元素被点击。

## 3.3 页面加载事件（了解）

### 3.3.1 load 事件

* 格式：

```js
window.addEventListener('load',function(){
    ...
})
```

> [!NOTE]
>
> * ① 当整个页面 + 所有外部资源（图片、CSS 、JavaScript、...）全部加载完毕时触发。
> * ② 为什么要学？
>   * 有些时候需要等页面资源全部加载完毕，再做一些事情。
>   * 一些上古代码特别喜欢将 script 写在 head ，会导致 dom 元素找不到；为了解决这个问题，就可以将 js 代码写到 load 事件的回调函数中。
> * ③ 最好给 window 添加 load 事件，因为所有资源都加载完毕是浏览器窗口或浏览器上下文的状态，而不是文档树的某个节点的状态。
> * ④ 不能给 document 添加 load 事件，document 只是代表 DOM 文档本身。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>页面加载事件</title>
  <style>
    .box {
      width: 200px;
      height: 200px;
      background-color: rgb(175, 76, 76);
      text-align: center;
      align-content: center;
      margin-bottom: 20px;
      color: #fff;
    }

    .btn {
      width: 200px;
      height: 50px;
      border-radius: 50px;
      outline: none;
      border: none;
      cursor: pointer;
      /* 好看的背景颜色 */
      background-color: rgb(82, 68, 68);
      color: #fff;
      /* 阴影 */
      box-shadow: 0 0 10px rgba(0, 0, 0, 0.2);
    }
  </style>
  <script>
```

## 4.1 概述

## 4.2 移除 L0 事件监听

* 格式：

```js
元素对象.onXxx = null
```

> [!NOTE]
>
> 对于 on 事件方式，直接使用 null 覆盖，就可以实现事件的解绑。



* 示例：

::: code-group

## 4.3 移除 L2 事件监听

* 格式：

```js
removeEventListener(事件类型, 事件处理函数, [获取捕获或者冒泡阶段])
```

> [!NOTE]
>
> * ① 对于  addEventListener 方式注册的事件，必须使用 removeEventListener 来进行移除。
> * ② 匿名函数无法使用 removeEventListener  来进行解绑，因为拿不到引用地址。



* 示例：

::: code-group

```html [index.html]

    body {
      padding-top: 200px;
      display: flex;
      flex-direction: column;
      justify-content: center;
      align-items: center;
      gap: 10px;
    }
  </style>
</head>

<body>

  <button class="L0">移除L0事件监听</button>
  <button class="L2">移除L2事件监听</button>

  <script>

    /* 获取元素 */
    const btnL2 = document.querySelector('.L2')
    /* 具名函数 */
    function handleClick() {
      /* 弹框 */
      alert('我被点击了')
      /* 移除事件监听 */
      btnL2.removeEventListener('click', handleClick)
    }
    /* 注册事件监听 */
    btnL2.addEventListener('click', handleClick)

  </script>
```

## 4.4 两种注册事件的区别

* 传统 on 事件（L0）VS 事件监听注册（L2），如下所示：

::: details 点我查看 具体细节

| 注册事件类型             | 特点                                                         |
| ------------------------ | ------------------------------------------------------------ |
| :one: 传统 on 事件（L0） | 同一个对象，后面注册的事件会覆盖前面注册（同名事件）。       |
| ^^                       | 直接使用 null 覆盖，就可以实现事件的解绑。                   |
| ^^                       | 只有冒泡阶段，没有捕获阶段。                                 |
| :two: 事件监听注册（L2） | 语法：addEventListener(事件类型，事件处理函数，是否使用捕获)。 |
| ^^                       | 后面注册的事件不会覆盖前面注册的事件（同名事件）。           |
| ^^                       | 必须使用 removeEventListener(事件类型，事件处理函数，获取捕获或者冒泡阶段) 实现事件解绑。 |
| ^^                       | 可以通过第三个参数去确定是在 `冒泡` 阶段或者 `捕获` 阶段执行。 |
| ^^                       | `匿名函数无法被解绑`。                                       |

## 5.1 概述

## 5.2 语法

* 格式：

```js
/* 获取元素的尺寸大小 */
元素对象.offsetWidth // 获取元素的宽度
元素对象.offsetHeight // 获取元素的高度

/* 获取元素在页面中的位置 */
元素对象.offsetTop  // 获取元素距离父元素顶部的距离
元素对象.offsetLeft  // 获取元素距离父元素左侧的距离
```

> [!NOTE]
>
> * ① `offset 家族` 可以获取 `元素的尺寸大小` 和 `元素在页面中的位置`。
> * ② 对于大小，使用 offsetWidth 和 offsetHeight 来获取；对于位置，使用 offsetLeft 和 offsetTop 来获取。
>
> ::: details 点我查看 具体细节
>
> | offset 家族              | 描述                                                         |
> | ------------------------ | ------------------------------------------------------------ |
> | :one: 元素的尺寸大小     | offsetWidth 和 offsetHeight                                  |
> | ^^                       | 获取元素的宽高（元素自身设置的 width 和 height + padding + border），类似于 box-sizing: border-box |
> | ^^                       | 返回的是 `数字`，不带单位，且是 `只读` 属性                  |
> | :two: 元素在页面中的位置 | offsetLeft 和 offsetTop                                      |
> | ^^                       | 获取元素距离自己定位父级元素的左、上距离，类似于绝对定位     |
> | ^^                       | 如果父级都没有定位则以 `浏览器文档` 为准                     |
> | ^^                       | 返回的是 `数字`，不带单位，且是 `只读` 属性                  |
>
> :::
>
> * ③ 也可以通过 e.getBoundingClientRect() 方法，获取其大小和相对于视口的位置。



* 示例：

::: code-group

## 5.4 总结

* scroll VS offset VS client ，如下所示：

| 前缀     | 记忆口诀       | 主要用途                                                     |
| -------- | -------------- | ------------------------------------------------------------ |
| `scroll` | 滚了多少       | 获取或设置滚动距离（scrollLeft 和 scrollTop ）               |
| `offset` | 在哪儿、有多大 | 获取布局位置（offsetLeft 和 offsetTop）和外部尺寸（offsetWidth 和 offsetHeight） |
| `client` | 里面有多大     | 获取内部可视区域尺寸（clientWidth 和 clientHeight）          |

```html [index.html]
  <script>
    /* ===== 4. 侧边栏楼层导航（核心：offsetTop 计算位置） ===== */
    const sidebarEl = document.getElementById('sidebar')
    const heroEl = document.querySelector('#carousel')
    const backTopBtn = document.querySelector('.back-top')

    // 注意：楼层模块是上面 JS 渲染出来的，必须在其之后再查询
    const floorEls = goodsWrapEl.querySelectorAll('.goods')
    const floorLinkEls = sidebarEl.querySelectorAll('a.item')

    // 点击楼层：事件委托，整个侧边栏只绑一个监听，将来加楼层也不用改 JS
    // （不能用 e.target.tagName === 'A' 判断：点中 svg/span 时 target 不是 a，
    //   要用 closest 从点击处向上找楼层链接；"顶部"是 button，匹配不到，天然排除）
    sidebarEl.addEventListener('click', (e) => {
      const link = e.target.closest('a.item')
      if (!link) return
      // 阻止 a 链接默认的锚点跳转（瞬间跳、无动画）
      e.preventDefault()
      // dataset.id 是字符串，转成数字再当数组下标；写错时直接忽略，避免读 undefined 报错
      const index = Number(link.dataset.id)
      if (!floorEls[index]) return
      /* 滚动到目标位置：减 80 避开吸顶导航，且恰好落在本楼层的触发区间内 */
      document.documentElement.scrollTo({
        top: floorEls[index].offsetTop - 80,
        behavior: 'smooth',
      })
    })

    /* 给页面添加滚动事件 */
    window.addEventListener('scroll', () => {
      /* 获取页面滚动的距离 */
      const top = document.documentElement.scrollTop

      // 滚过轮播图中点就显示侧边栏：
      // showLine = 轮播图顶边位置 + 轮播图高度的一半 = 轮播图中点的页面坐标
      // （用 floorEls[0].offsetTop 会等到热门推荐顶边贴到视口顶，那时已经滚到电脑数码了，太晚）
      const showLine = heroEl.offsetTop + heroEl.offsetHeight / 2
      /* 侧边栏切换或隐藏 */
      sidebarEl.classList.toggle('show', top >= showLine)

      // 高亮当前楼层：滚动位置越过哪个模块的 offsetTop，就高亮哪个
      // 高亮只有一个写入者（滚动位置），点击时不手动改高亮，
      // 动画途中高亮始终跟随真实位置，不会出现"点了又弹回去"的抖动
      // 提前量 200 小于楼层间距（约 220px），点击落点（offsetTop - 80）恰好落在本楼层的触发区间内
      let activeIndex = 0
      floorEls.forEach((el, i) => {
        if (top >= el.offsetTop - 200) {
          activeIndex = i
        }
      })
      floorLinkEls.forEach((link, i) => {
        link.classList.toggle('active', i === activeIndex)
      })
    })

    /* 返回顶部 */
    backTopBtn.addEventListener('click', () => {
      document.documentElement.scrollTo({ top: 0, behavior: 'smooth' })
    })
  </script>
```
