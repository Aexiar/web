# 第一章：事件流

## 1.1 概述

* 学习事件流，可以帮我们解决一些疑惑，如：点击子盒子为什么会弹 2 次的问题，如下所示：

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-11-04/2026-11-04-11-16-37.png)



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    .father {
      position: relative;
      width: 300px;
      height: 300px;
      background-color: pink;
    }

      /* 子盒水平垂直居中 */
      position: absolute;
      top: 50%;
      left: 50%;

      height: 100px;
      background-color: aqua;
    }
  </style>
</head>

  <div class="father">
    父盒子

    })
  </script>
```

## 1.2 事件流

### 1.2.1 概述

* `事件流` 指的是事件完整执行过程中的 `流动路径`，如下所示：

::: details 点我查看 具体细节

* ① 当事件被触发时，会经历两个阶段：捕获阶段和冒泡阶段。
* ② 捕获阶段：当一个元素的事件被触发时，会从 DOM 的根元素开始依次调用 `同名事件`（从外到里）。
* ③ 冒泡阶段：当一个元素的事件被触发时，`同名事件` 会在该元素的祖先元素中被 `依次触发`（从里到外）。

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-11-04/2026-11-04-11-45-21.png)

### 1.2.2 事件捕获

* 格式：

```js
元素对象.addEventListener('事件类型',事件处理函数,是否使用捕获机制)
```

> [!NOTE]
>
> * ① 捕获阶段：当一个元素的事件被触发时，会从 DOM 的根元素开始依次调用 `同名事件`（从外到里）。
> * ② addEventListener 的第三个参数代表 `是否使用捕获机制`，其是一个布尔类型，true 代表捕获阶段触发（不常用）。
> * ③ addEventListener 的第三个参数代表 `是否使用捕获机制`，其是一个布尔类型，false 代表冒泡阶段触发（常用，默认值）。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    .father {
      position: relative;
      width: 300px;
      height: 300px;
      background-color: pink;
    }

    .son {
      /* 子盒水平垂直居中 */
      position: absolute;
      top: 50%;
      left: 50%;
      transform: translate(-50%, -50%);
      width: 100px;
      height: 100px;
      background-color: aqua;
    }
  </style>
</head>

<body>

  <div class="father">
    父盒子
    <div class="son">
      子盒子
    </div>
  </div>


  <script>
    /* 获取父元素和子元素 */
    const father = document.querySelector('.father')
    const son = father.querySelector('.son')
    /* body 元素添加点击事件 */
    document.body.addEventListener('click', (e) => {
      alert(`我是body`)
    }, true)
    /* 父元素注册点击事件 */
    father.addEventListener('click', (e) => {
      alert(`我是父盒子`)
    }, true)
    /* 子元素注册点击事件 */
    son.addEventListener('click', (e) => {
      alert(`我是子盒子`)
    }, true)
  </script>

</body>

</html>
```

### 1.2.4 阻止冒泡

* 格式：

```js
e.stopPropagation()
```

> [!NOTE]
>
> * ① 因为默认就有冒泡模式的存在，很容易就导致事件会影响到父元素。如果想将事件限制在当前元素内，就需要 `阻止事件冒泡`。
> * ② 阻止事件冒泡，就需要让当前 `事件对象` 去调用 `stopPropagation()` 方法。
> * ③ `e.stopPropagation()` 可以阻断事件流转传播，不光在冒泡阶段有效，捕获阶段也有效。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    .father {
      position: relative;
      width: 300px;
      height: 300px;
      background-color: pink;
    }

    .son {
      /* 子盒水平垂直居中 */
      position: absolute;
      top: 50%;
      left: 50%;
      transform: translate(-50%, -50%);
      width: 100px;
      height: 100px;
      background-color: aqua;
    }
  </style>
</head>

<body>

  <div class="father">
    父盒子
    <div class="son">
      子盒子
    </div>
  </div>


  <script>
    /* 获取父元素和子元素 */
    const father = document.querySelector('.father')
    const son = father.querySelector('.son')
    /* body 元素添加点击事件 */
    document.body.addEventListener('click', (e) => {
      alert(`我是body`)
    })
    /* 父元素注册点击事件 */
    father.addEventListener('click', (e) => {
      alert(`我是父盒子`)
    })
    /* 子元素注册点击事件 */
    son.addEventListener('click', (e) => {
      // 阻止事件冒泡
      e.stopPropagation()
      alert(`我是子盒子`)
    })
  </script>

</body>

</html>
```

### 1.2.5 阻止默认行为

* 格式：

```js
e.preventDefault()
```

> [!NOTE]
>
> 某些情况下需要 `阻止` 元素 `默认行为` 的 `发生`，如：阻止超链接的跳转，阻止表单域的提交。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    body {
      padding-top: 200px;
      display: flex;
      flex-direction: column;
      justify-content: center;
      align-items: center;
      gap: 10px;
    }
  </style>
</head>

<body>

  <a href="https://www.baidu.com">百度一下</a>
  <a href="https://www.deepseek.com" class="deepseek">deepseek</a>

  <script>
    /* 获取deepseek链接元素 */
    const deepseek = document.querySelector('.deepseek')
    /* deepseek 添加点击事件 */
    deepseek.addEventListener('click', function (event) {
      // 阻止默认行为
      event.preventDefault()
      // 弹框
      alert('deepseek链接被点击了！')
    });
  </script>


</body>

</html>
```

# 第二章：事件委托

## 2.1 概述

* `事件委托`（Event Delegation） 是JavaScript中注册事件的常用技巧，如下所示：

::: details 点我查看 具体细节

* ① 内部原理：利用 `事件冒泡` 的特点，即：给 `父元素` 注册事件，当我们触发子元素的时候，会冒泡到父元素身上，从而触发父元素的事件。
* ② `事件委托`，也被称为 `事件委派` 或 `事件代理`。
* ② 之所以使用 `事件委托`，就是为了 `减少注册次数`，提高程序性能。

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-11-04/2026-11-04-12-52-42.png)

## 2.2 语法

* 格式：

```js
父元素.addEventListener('事件类型', function(e){
    // 通过 e.target.TagName 获取真正触发事件的元素
    const el = e.target.TagName
})
```

> [!NOTE]
>
> * ① 给 `父元素` 注册事件，通过 `事件冒泡` 特点，当触发子元素的时候，会冒泡到父元素身上，从而触发父元素的事件。
> * ② 通过 `e.target.TagName` 来获取真正触发事件的元素。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    .box {
      display: flex;
      justify-content: center;
      align-items: center;
      height: 50vh;
    }
    button {
      margin: 10px;
      cursor: pointer;
    }

    .active {
      background-color: red;
    }
  </style>
</head>

<body>

  <div class="box">
    <button class="active">第1个</button>
    <button>第2个</button>
    <button>第3个</button>
    <button>第4个</button>
    <button>第5个</button>
  </div>

  <script>
    /* 获取父元素 box */
    const box = document.querySelector('.box')
    /* 给父元素添加点击事件，即：事件委托 */
    box.addEventListener('click', (e) => {
      // 通过 e.target.tagName 获取真正触发事件的元素
      if (e.target.tagName === 'BUTTON') {
        // 清除 active 类
        const activeBtn = box.querySelector('.active')
        activeBtn.classList.remove('active')
        // 添加 active 类
        e.target.classList.add('active')
      }
    })
  </script>

</body>

</html>
```

## 2.3 综合练习

* 需求：将 tab 切换案例改为事件委托写法。

> [!NOTE]
>
> * ① 给 a 元素的 `父元素` 添加鼠标经过事件，采取 `事件委托` 方式，即：mouseover 。
> * ② 给每个 a 元素添加自定义属性 `data-id="0|1|..."` ，以便点击时能知道到底哪个 a 被点击了。
> * ③ 需要使用 `e.target.TagName` 来获取哪个 a 元素被点击。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta http-equiv="X-UA-Compatible" content="IE=edge">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>全选文本框</title>
  <link rel="stylesheet" href="./css/index.css">
</head>

<body>
  <div class="tab">
    <div class="tab-nav">
      <h3>每日特价</h3>
      <ul>
        <!-- 使用 data-id 属性来存储索引值 -->
        <li><a href="javascript:;" data-id="0" class="active">精选</a></li>
        <li><a href="javascript:;" data-id="1">美食</a></li>
        <li><a href="javascript:;" data-id="2">百货</a></li>
        <li><a href="javascript:;" data-id="3">个护</a></li>
        <li><a href="javascript:;" data-id="4">预告</a></li>
      </ul>
    </div>
    <div class="tab-content">
      <div class="item active"><img src="./images/tab00.png" alt="" /></div>
      <div class="item"><img src="./images/tab01.png" alt="" /></div>
      <div class="item"><img src="./images/tab02.png" alt="" /></div>
      <div class="item"><img src="./images/tab03.png" alt="" /></div>
      <div class="item"><img src="./images/tab04.png" alt="" /></div>
    </div>
  </div>

  <script>
    const tabNav = document.querySelector('.tab-nav')
    const tabContent = document.querySelector('.tab-content')

    // 使用事件委托来实现 tab 栏切换
    tabNav.addEventListener('click', (e) => {
      // 通过 e.target.TagName 获取真正触发事件的元素 a
      if (e.target.tagName === 'A') {
        // 移除所有链接的 active 类
        tabNav.querySelector('.active').classList.remove('active')
        // 当前链接的 active 类
        e.target.classList.add('active')
        // 隐藏所有内容项
        tabContent.querySelector('.active').classList.remove('active')
        // 显示对应的内容项
        console.log(e.target.dataset.id)
        tabContent.querySelectorAll('.item')[e.target.dataset.id].classList.add('active')
      }
    });
  </script>

</body>

</html>
```

## 3.1 鼠标进入/离开事件

* 鼠标进入事件或鼠标离开事件有两套，如下所示：

| 鼠标进入或离开事件  | 区别         | 备注       |
| ------------------- | ------------ | ---------- |
| mouseover 鼠标进入  | 存在事件冒泡 | 偶尔会使用 |
| mouseout 鼠标离开   | ^^           | ^^         |
| mouseenter 鼠标进入 | 没有事件冒泡 | 经常会使用 |
| mouseleave 鼠标离开 | ^^           | ^^         |




* 示例：

::: code-group

```html [index.html]

      width: 300px;
      height: 300px;
      background-color: pink;

      /* 子盒水平垂直居中 */
      position: absolute;
      top: 50%;
      left: 50%;
      transform: translate(-50%, -50%);
      width: 100px;
      height: 100px;
      background-color: aqua;
    }
  </style>
</head>

<body>

  <div class="father">
    父盒子
    <div class="son">
      子盒子
    </div>
  </div>


  <script>
    /* 获取父元素和子元素 */
    const father = document.querySelector('.father')
    const son = father.querySelector('.son')
    /* 鼠标进入事件：mouseover 存在事件冒泡 */
   /*  father.addEventListener('mouseover', (e) => {
```
