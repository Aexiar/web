# 第一章：事件监听

## 1.1  概述

* 之前的代码都是自动执行的；但是，我们希望一段代码在 `某个特定的时机` 去执行，如下所示：

::: details 点我查看 具体细节

* ① 点击按钮可以弹出警告框。
* ② 鼠标经过可以显示下拉菜单。
* ③ ...

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-11-03/2026-11-03-08-55-39.png)

* `事件` 是程序在运行时，发生的特定动作或特定的事情，如：`点击` 按钮、`鼠标经过` 菜单等。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-11-03/2026-11-03-09-00-42.png)

* `事件监听` 就是让程序检测是否有事件产生，一旦事件触发，就立即调用一个函数做出响应，即：`绑定事件` 或 `注册事件`。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/web/2026-11-03/2026-11-03-09-03-32.png)

## 1.2 事件监听

* 格式：

```js
元素对象.addEventListener('事件类型', 事件处理函数)
```

> [!NOTE]
>
> * ① 事件源（who）：哪个元素的事件被触发了，即：谁被触发？
> * ② 事件类型（when）：用什么方式触发，如：鼠标单击 click、鼠标经过 mouseover，即：什么情况下触发？
> * ③ 事件处理函数（what）：将要做的事放到事件处理函数里面，即：要做什么？



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>

  <button class="box">点我</button>

  <script>

    const box = document.querySelector('.box')
    box.addEventListener('click', (e) => {
      console.log('按钮被点击了！')
    })

  </script>

</body>

</html>
```

## 1.3 事件监听版本

### 1.3.1 概述

* 事件监听 L0 版本 🆚 事件监听 L2 版本，如下所示：

::: details 点我查看 具体细节

| 事件监听的版本          | 范例                                                | 备注                                                         |
| ----------------------- | --------------------------------------------------- | ------------------------------------------------------------ |
| L0（L 是 Level 的缩写） | 元素对象.onclick = function(){}                     | on 方式 `同名事件` 会被覆盖，原因是赋值方式                  |
| L2（L 是 Level 的缩写） | 元素对象.addEventListener('事件类型', 事件处理函数) | addEventListener 方法可以绑定多次，拥有事件的更多特性，推荐使用 |

## 2.2 鼠标事件

* 格式：

```js
// 点击事件
元素对象.addEventListener('click', 事件处理函数)

// 鼠标经过（进入）
元素对象.addEventListener('mouseenter', 事件处理函数)

// 鼠标离开（离开）
元素对象.addEventListener('mouseleave', 事件处理函数)
```



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    body {
      display: flex;
      justify-content: center;
      align-items: center;
      height: 80vh;
    }

    .box {
      width: 300px;
      height: 300px;
      background-color: pink;
      text-align: center;
      align-content: center;
    }
  </style>
</head>

<body>

  <div class="box">我是盒子</div>

  <script>
    /* 获取元素 */
    const boxEl = document.querySelector('.box')

    /* 添加点击事件 */
    boxEl.addEventListener('click', (e) => {
      console.log('盒子被点击了')
    })

    /* 添加鼠标进入事件 */
    boxEl.addEventListener('mouseenter', (e) => {
      console.log('鼠标进入了盒子')
    })

    /* 添加鼠标离开事件 */
    boxEl.addEventListener('mouseleave', (e) => {
      console.log('鼠标离开了盒子')
    })
  </script>

</body>

</html>
```

## 2.3 焦点事件

* 格式：

```js
// 获取焦点事件
元素对象.addEventListener('focus', 事件处理函数)

// 失去焦点事件
元素对象.addEventListener('blur', 事件处理函数)
```



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>
<body>
  
  <input type="text">

  <script>
    const input = document.querySelector('input')
    input.addEventListener('focus', () => {
      console.log('获取焦点')
    })
    input.addEventListener('blur', () => {
      console.log('失去焦点')
    })
  </script>

</body>
</html>
```

## 2.4 键盘事件

* 格式：

```js
// 键盘弹起事件
元素对象.addEventListener('keyup', 事件处理函数)

// 键盘按下事件
元素对象.addEventListener('keydown', 事件处理函数)
```

> [!NOTE]
>
> 可以通过 `e.key` 来获取按下了那个键。



* 示例：

::: code-group

```html [index.html]

  <script>
    const input = document.querySelector('input')

    })
    input.addEventListener('keyup', (e) => {
      console.log('键盘弹起', e.key)
    })
  </script>

</html>
```

## 2.6 综合练习

### 2.6.1 综合练习一

* 需求：轮播图点击切换。

> [!NOTE]
>
> * ① 右侧按钮点击，顺序切换图片，并且无缝切换。
> * ② 左侧按钮点击，顺序切换图片，并且无缝切换。
> * ③ 自动播放图片。
> * ④ 鼠标经过，暂停播放图片；鼠标离开，继续播放图片。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8" />
  <meta http-equiv="X-UA-Compatible" content="IE=edge" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>轮播图点击切换</title>
  <link rel="stylesheet" href="./css/index.css">
</head>

<body>
  <div class="slider">
    <div class="slider-wrapper">
      <img src="./images/slider01.jpg" alt="对人类来说会不会太超前了？" />
    </div>
    <div class="slider-footer">
      <p>对人类来说会不会太超前了？</p>
      <ul class="slider-indicator">
        <li class="active"></li>
        <li></li>
        <li></li>
        <li></li>
        <li></li>
        <li></li>
        <li></li>
        <li></li>
      </ul>
      <div class="toggle">
        <button class="prev" type="button" aria-label="上一张">&lt;</button>
        <button class="next" type="button" aria-label="下一张">&gt;</button>
      </div>
    </div>
  </div>
  <script>
    // 1. 初始数据
    const sliderData = [
      { url: './images/slider01.jpg', title: '对人类来说会不会太超前了？', color: 'rgb(100, 67, 68)' },
      { url: './images/slider02.jpg', title: '开启剑与雪的黑暗传说！', color: 'rgb(43, 35, 26)' },
      { url: './images/slider03.jpg', title: '真正的jo厨出现了！', color: 'rgb(36, 31, 33)' },
      { url: './images/slider04.jpg', title: '李玉刚：让世界通过B站看到东方大国文化', color: 'rgb(139, 98, 66)' },
      { url: './images/slider05.jpg', title: '快来分享你的寒假日常吧~', color: 'rgb(67, 90, 92)' },
      { url: './images/slider06.jpg', title: '哔哩哔哩小年YEAH', color: 'rgb(166, 131, 143)' },
      { url: './images/slider07.jpg', title: '一站式解决你的电脑配置问题！！！', color: 'rgb(53, 29, 25)' },
      { url: './images/slider08.jpg', title: '谁不想和小猫咪贴贴呢！', color: 'rgb(99, 72, 114)' },
    ]

    /* 获取元素 */
    const sliderEl = document.querySelector('.slider')

    // 自动播放间隔（毫秒），集中配置便于统一调整
    const AUTOPLAY_DELAY = 1000

    /**
     * 轮播图工厂（高阶函数）
     * 渲染与切换全部封装进闭包：index 与 DOM 引用都是私有的，
     * 外部只能通过返回的 next / prev / goTo 操作，避免全局计数器被意外修改
     * @param {HTMLElement} rootEl 轮播容器
     * @param {Array<{url: string, title: string, color: string}>} data 轮播数据
     */
    function createSlider({ rootEl, data }) {
      // 一次性缓存 DOM 引用，避免每次切换都重新查询
      const imgEl = rootEl.querySelector('.slider-wrapper img')
      const footerEl = rootEl.querySelector('.slider-footer')
      const titleEl = footerEl.querySelector('p')
      const indicatorEls = footerEl.querySelectorAll('.slider-indicator li')

      // 闭包中的计数器，外部无法直接访问
      let index = 0

      /* 渲染：依据闭包内的 index 更新图片、标题、背景色与指示器高亮 */
      function render() {
        // 获取数组对应索引处的元素
        const { url, title, color } = data[index]

        // 更新图片和样式
        imgEl.src = url
        imgEl.alt = title
        // 用 textContent 代替 innerHTML：省去 HTML 解析开销，也避免标题含标签时被注入执行（XSS）
        titleEl.textContent = title
        footerEl.style.backgroundColor = color

        // 处理高亮效果：统一遍历切换，不依赖「当前必须存在 .active」
        indicatorEls.forEach((dot, dotIndex) => {
          dot.classList.toggle('active', dotIndex === index)
        })
      }

      /* 切换：统一取模收敛越界（next 超出长度 / prev 小于 0），实现无缝衔接播放 */
      function goTo(target) {
        index = (target + data.length) % data.length
        render()
      }

      // 高阶函数：接收步长，返回一个闭包切换函数（调用方只关心方向，不关心索引）
      const stepBy = (step) => () => goTo(index + step)

      // 自动播放定时器 id：null 表示当前未启动
      let timerId = null

      /* 启动自动播放 */
      function start() {
        // 先清理旧定时器，避免重复启动时多个定时器叠加导致越切越快
        stop()
        timerId = setInterval(() => goTo(index + 1), AUTOPLAY_DELAY)
      }

      /* 暂停自动播放 */
      function stop() {
        if (timerId !== null) {
          clearInterval(timerId)
          timerId = null
        }
      }

      // 初始化渲染：首屏图片、标题、背景色、高亮都由数据驱动，避免与 HTML 硬编码不一致
      render()

      return {
        goTo,
        next: stepBy(1),
        prev: stepBy(-1),
        start,
        stop,
      }
    }

    const slider = createSlider({ rootEl: sliderEl, data: sliderData })

    /* ① 右侧按钮点击，顺序切换图片，无缝衔接播放 */
    document.querySelector('.next').addEventListener('click', slider.next)

    /* ② 左侧按钮点击，顺序切换图片，无缝衔接播放 */
    document.querySelector('.prev').addEventListener('click', slider.prev)

    /* ③ 自动播放：鼠标移入暂停，移出继续 */
    // 用箭头函数包一层，避免事件对象被当作参数传入 start / stop
    sliderEl.addEventListener('mouseenter', () => slider.stop())
    sliderEl.addEventListener('mouseleave', () => slider.start())
    slider.start()
  </script>
</body>

</html>
```

### 2.6.2 综合练习二

* 需求：小米搜索框。

> [!NOTE]
>
> * ① 开始下拉菜单需要隐藏。
> * ② 表单获取焦点 focus，则显示下拉菜单，并且搜索框变色（添加类）。
> * ③ 表单失去焦点 blur，则隐藏下拉菜单，并且搜索框恢复原来颜色（删除类）。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8" />
  <meta http-equiv="X-UA-Compatible" content="IE=edge" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>轮播图点击切换</title>
  <link rel="stylesheet" href="./css/index.css">
</head>

<body>
    <div class="mi">
        <input type="search" placeholder="小米笔记本">
        <ul class="result-list">
            <li><a href="#">全部商品</a></li>
            <li><a href="#">小米11</a></li>
            <li><a href="#">小米10S</a></li>
            <li><a href="#">小米笔记本</a></li>
            <li><a href="#">小米手机</a></li>
            <li><a href="#">黑鲨4</a></li>
            <li><a href="#">空调</a></li>
        </ul>
    </div>

    <script>
        // 1. 获取元素
        const input = document.querySelector('[type=search]')
        const ul = document.querySelector('.result-list')
        // console.log(input)
        // 2. 监听事件 获得焦点
        input.addEventListener('focus', function () {
            // ul显示
            ul.style.display = 'block'
            // 添加一个带有颜色边框的类名
            input.classList.add('search')
        })
        // 3. 监听事件 失去焦点
        input.addEventListener('blur', function () {
            // ul隐藏
            ul.style.display = 'none'
            // 移除带有颜色边框的类名
            input.classList.remove('search')
        })
    </script>
</body>

</html>
```

## 3.2 语法

* 格式：

```js
元素对象.addEventListener('事件类型', function(e){} )
```

> [!NOTE]
>
> * ① 在注册事件的时候，回调函数中的 `第一个参数` 就是 `事件对象`。
> * ② 通常事件对象，会命名为 e、event 等。
> * ③ 事件对象的常用属性和方法，如下所示：
>
> | 分类     | 属性 / 方法         | 作用                                 |
> | -------- | ------------------- | ------------------------------------ |
> | 通用事件 | `type`              | 获取事件类型，如：`click`、`keydown` |
> | ^^       | `target`            | 获取实际触发事件的元素               |
> | ^^       | `currentTarget`     | 获取当前绑定事件监听器的元素         |
> | 鼠标事件 | `clientX`           | 获取鼠标相对于浏览器视口的 X 坐标    |
> | ^^       | `clientY`           | 获取鼠标相对于浏览器视口的 Y 坐标    |
> | ^^       | `pageX`             | 获取鼠标相对于整个文档的 X 坐标      |
> | ^^       | `pageY`             | 获取鼠标相对于整个文档的 Y 坐标      |
> | 键盘事件 | `key`               | 获取按下的键，如 `Enter`、`Escape`   |
> | 事件控制 | `preventDefault()`  | 阻止事件的默认行为                   |
> | ^^       | `stopPropagation()` | 阻止事件继续传播                     |



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>
<body>
  
  <script>
    /* 如果是键盘事件，那么事件对象中就包含 key 属性 */
    document.body.addEventListener('keyup', (e) => {
      /* 获取键盘按下的键值 */
      console.log(e.key)
    })
  </script>

</body>
</html>
```

## 4.1 排他思想

* 排他思想是一种思路，目的是突出显示某个元素。

> [!NOTE]
>
> * ① 有多个元素，当鼠标经过的时候，只有 `当前元素` 会添加高亮样式，其余的元素移除样式。
> * ② 记忆口诀就是：`排` 除其 `他` 人，保留我 `自己` 。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    .active {
      background-color: red;
    }

    button {
      cursor: pointer;
    }
  </style>
</head>

<body>

  <button>按钮1</button>
  <button class="active">按钮2</button>
  <button>按钮3</button>
  <button>按钮4</button>
  <button>按钮5</button>

  <script>

    /* 鼠标经过 button 元素，当前 button 元素背景色变为红色 */
    const btns = document.querySelectorAll('button')
    /* 遍历所有 button 元素，去掉 active 类名*/
    btns.forEach(item => {
      // 给每个元素添加鼠标经过事件
      item.addEventListener('mouseenter', () => {
        // 排他思想，去掉所有元素的 active 类名
        btns.forEach(btn => {
          btn.classList.remove('active')
        })
        // 只留下当前元素的 active 类名
        item.classList.add('active')
      })
    })

  </script>

</body>

</html>
```

## 4.2 tab 栏切换

* 需求：鼠标经过不同的选项卡，底部可以显示不同的内容。

> [!NOTE]
>
> * ① 核心就是类的切换，设置一个 active 类，可以让当前元素高亮。
> * ② 鼠标经过当前选项卡的时候，先移除其余元素身上的 active 类，再给当前元素添加 active 类。
> * ③ 后期可以使用事件 `委托机制` + `HTML 自定义属性` 来简化代码。



* 示例：

::: code-group

```html [index.html]
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta http-equiv="X-UA-Compatible" content="IE=edge">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>评论回车发布</title>
  <link rel="stylesheet" href="./css/index.css">
</head>

<body>
  <div class="tab">
    <div class="tab-nav">
      <h3>每日特价</h3>
      <ul>
        <li><a class="active" href="javascript:;">精选</a></li>
        <li><a href="javascript:;">美食</a></li>
        <li><a href="javascript:;">百货</a></li>
        <li><a href="javascript:;">个护</a></li>
        <li><a href="javascript:;">预告</a></li>
      </ul>
    </div>
    <div class="tab-content">
      <div class="item active"><img src="./images/tab00.png" alt="" /></div>
      <div class="item"><img src="./images/tab01.png" alt="" /></div>
      <div class="item"><img src="./images/tab02.png" alt="" /></div>
      <div class="item"><img src="./images/tab03.png" alt="" /></div>
      <div class="item"><img src="./images/tab04.png" alt="" /></div>
    </div>
  </div>

  <script>
    const tabNav = document.querySelector('.tab-nav')
    const tabContent = document.querySelector('.tab-content')
    const tabNavLis = tabNav.querySelectorAll('li')
    const tabContentItems = tabContent.querySelectorAll('.item')

    /* 遍历 tab 栏的 li */
    tabNavLis.forEach((item, index) => {
      // 给每个 li 添加鼠标事件
      item.addEventListener('mouseenter', (e) => {
        // 清除之前选中的导航
        document.querySelector('.tab-nav .active').classList.remove('active')
        // 选中当前导航
        item.querySelector('a').classList.add('active')
        // 先去除所有 tab-content 中的 active
        document.querySelector('.tab-content .active').classList.remove('active')
        // 给对应的 tab-content 中的 item 添加 active
        tabContentItems[index].classList.add('active')
      })
    })
  </script>
```
